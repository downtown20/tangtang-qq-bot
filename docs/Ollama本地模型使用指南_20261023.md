# 本地 Qwen3-VL-8B 使用指南（Ollama）

> 2026-10-23/24 实测记录。本机 RTX 5070 12GB + Ollama 0.35.0。
> 相关：`stickers_cg/_tag/tag_cg_qwen.py`（离线打标器，走 transformers 而不是 Ollama）、
> 根目录 `本地模型.bat`（双击即用的聊天入口）。

## 一、先搞清楚两件事

**① 这个模型是完整的 LLM，不只是识图器。**
`models/qwen3-vl-8b/config.json`：文本塔 = Qwen3-8B（36 层、hidden 4096、262K 上下文），
视觉塔 27 层 ViT + 576M 投影器。纯文本对话、推理、写代码、翻译都是本职工作。

**② 同一个模型，两种跑法差 70 倍。**

| 跑法 | 权重 | 实测生成速度 | 300 字回复 |
|---|---|---|---|
| transformers bf16（`tag_cg_qwen.py` 打标器） | 17GB，溢出到 CPU | **1.0 token/s** | ≈ 5 分钟 |
| Ollama `qwen3-vl:8b-instruct-q4_K_M` | 6.2GB，100% GPU | **100 token/s** | ≈ 3 秒 |

## 二、模型选择（关键）

Ollama 库的 qwen3-vl 有明确分支（`https://ollama.com/library/qwen3-vl/tags`）：

| tag | 状态 | 结论 |
|---|---|---|
| `qwen3-vl:8b` | 本机 2026-08 拉的旧 tag：模板只有 `{{ .Prompt }}`、**强制思考**（回答 content 为空，全在 thinking 里） | 别用 |
| `qwen3-vl:8b-instruct-q4_K_M` | **已装并验证**：正确模板、不思考、视觉+工具正常、6.2GB | **日常用这个** |
| `qwen3-vl:8b-instruct-q8_0` | 精度更高（~9.4GB），12GB 卡 + 小上下文可全 GPU | 质量敏感时 |
| `qwen3-vl:8b-thinking-*` | 强制思考版 | 需要长推理时 |

判断一个 tag 是不是"强制思考"：

```powershell
ollama show qwen3-vl:8b --template   # 只有 {{ .Prompt }} = 模板残缺
ollama show qwen3-vl:8b-instruct-q4_K_M   # Capabilities 里没有 thinking
```

安装：`ollama pull qwen3-vl:8b-instruct-q4_K_M`（约 6.2GB，落盘在 `D:\frequentAPP`，C 盘不受影响）

## 三、环境变量（已写入用户级，已重启 Ollama 生效）

```powershell
[Environment]::SetEnvironmentVariable('OLLAMA_FLASH_ATTENTION','1','User')   # flash attention
[Environment]::SetEnvironmentVariable('OLLAMA_KV_CACHE_TYPE','q8_0','User')  # KV 缓存半精度
[Environment]::SetEnvironmentVariable('OLLAMA_NUM_PARALLEL','1','User')      # 单并发省显存
[Environment]::SetEnvironmentVariable('OLLAMA_MAX_LOADED_MODELS','1','User') # 一次只驻留一个模型
[Environment]::SetEnvironmentVariable('OLLAMA_KEEP_ALIVE','30m','User')      # 30 分钟不卸载
[Environment]::SetEnvironmentVariable('OLLAMA_CONTEXT_LENGTH','16384','User')# 请求不带 num_ctx 时的默认上下文
```

实测：重启后不发 `num_ctx` 时服务端给的默认上下文是 **32768**（Ollama 0.35 自身行为，
不是 16384），显存 7.9GB、100% GPU。想压低显存占用就在请求里显式传小一点的 `num_ctx`。

改完必须**重启 Ollama**（托盘退出再打开，或 `taskkill /IM "ollama app.exe" /F` 后重新启动）。

## 四、怎么用

### 4.1 双击（最简单）

根目录 `本地模型.bat`：检查 Ollama 服务 → 检查模型 → 进入交互式聊天（带 `--verbose` 显示速度），
`/bye` 退出。也可以带一次性问题：`本地模型.bat "1+1等于几"`。

### 4.2 命令行

```powershell
ollama run qwen3-vl:8b-instruct-q4_K_M "用一句话解释什么是光合作用"
ollama run qwen3-vl:8b-instruct-q4_K_M "描述这张图" D:\qq-小糖糖\stickers\xxx.jpg
```

### 4.3 HTTP API

端点 `http://127.0.0.1:11434`，两套接口：`/api/chat`、`/api/generate`，
以及 OpenAI 兼容的 `/v1/chat/completions`。

带图片（base64）：
```powershell
$img = [Convert]::ToBase64String([IO.File]::ReadAllBytes('D:\qq-小糖糖\stickers\xxx.jpg'))
$body = @{
  model   = 'qwen3-vl:8b-instruct-q4_K_M'
  prompt  = '这张图里是什么？用一句话描述'
  images  = @($img)
  stream  = $false
  options = @{ num_ctx = 16384; num_predict = 300; temperature = 0.7 }
} | ConvertTo-Json -Depth 6
Invoke-RestMethod -Uri 'http://127.0.0.1:11434/api/generate' -Method Post `
  -Body ([Text.Encoding]::UTF8.GetBytes($body)) -ContentType 'application/json; charset=utf-8'
```

多轮对话：
```powershell
$body = @{
  model    = 'qwen3-vl:8b-instruct-q4_K_M'
  messages = @(
    @{ role='system'; content='你是一个中文助手，回答简洁' },
    @{ role='user';   content='你好' }
  )
  stream   = $false
  options  = @{ num_ctx = 16384; temperature = 0.7; top_p = 0.8 }
} | ConvertTo-Json -Depth 6
```

### 4.4 工具调用（function calling）

Capabilities 含 `tools`，实测可用：
```powershell
$tools = @(@{ type='function'; function=@{ name='get_weather'; description='查城市天气';
  parameters=@{ type='object'; properties=@{ city=@{ type='string' } }; required=@('city') } } })
```
→ 问「帮我查一下北京现在天气」，返回 `tool_calls: get_weather(city="北京")`（0.2 秒）。

## 五、实测数据（本机，2026-10-24）

| 项目 | 结果 |
|---|---|
| 文本：解释天空为什么蓝 | 3 句准确（含瑞利散射 + 日出日落补充），99 token / 1.0s = **100.2 tok/s** |
| 视觉：一张表情包 | 识别出蓝发橙眼、惊讶表情、图上文字「这么强？」及用法，**1075 prompt token**（图片约 1000），1.3 秒 |
| 工具调用 | `tool_calls` 正确解析，20 token / 0.2s = 105 tok/s |
| 显存（请求里 num_ctx 16384） | **6.6GB，100% GPU** |
| 显存（不传 num_ctx，服务端默认 32768） | **7.9GB，100% GPU** |
| 冷加载 | 约 3.4 秒（有 keep_alive 后不再重复加载） |

**图片很吃 token**：一张 23KB 小图 = 1075 prompt token。多图/多轮要加大 `num_ctx`（默认只有 4096，
已通过环境变量提到 16384）。

## 六、和糖糖 bot 共存

- bot 启动后 BGE + reranker 常驻约 **6GB** 显存；
- 8B + 16K 上下文需要 **6.6GB**；
- 12GB 卡同时跑 → Ollama 会被挤掉部分层（`ollama ps` 的 `PROCESSOR` 显示 `35%/65% CPU/GPU`），速度腰斩但能跑；
- 要全速：先让 bot 空闲/暂停，或把 `num_ctx` 降到 8192。

## 七、常见问题

**Q: 回答是空的，只有 thinking？**
A: 你在用旧 tag `qwen3-vl:8b`（模板残缺 + 思考版）。换 `qwen3-vl:8b-instruct-q4_K_M`。

**Q: 每次都要等几秒才出字？**
A: 冷加载。已设 `OLLAMA_KEEP_ALIVE=30m`；`ollama ps` 的 `UNTIL` 列确认驻留。

**Q: 速度只有几百 token/s 变慢？**
A: `ollama ps` 看 `PROCESSOR`。出现 `XX%/YY% CPU/GPU` 就是显存不够，按第六节处理。

**Q: 想用原始 bf16 精度？**
A: 不划算。17GB 权重在 12GB 卡上必然溢出 CPU，速度掉到 1 token/s（打标器现状）。
Q4_K_M 对描述类任务损失很小；要更高精度用 `q8_0`。
