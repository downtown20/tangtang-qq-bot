**本轮修掉的（主人自己发现的那个 bug）**：

> 「两个饥渴度不是滑块，是输入框，而且输入框不允许输入 0.0 几的数，
> 只允许输入 0.几的数，你注意核对」

核对结果是一个**双层 bug**，比「输不进去」更严重：

1. `<input type="number">` 的 DOM **存不下小数/负数的中间态**。DevTools 实测：
   `"0"` → `"0"`，`"0."` → **`""`**，`"-"` → **`""`**，`"0.08"` → `"0.08"`。
   也就是敲小数点的瞬间 `input.value` 是空串。
2. 旧实现 `value={String(value)}` + `onChange={coerce}` 拿到空串就 `coerce("")=0`，
   再把 value 重置成 `"0"` → 用户看到小数点消失，最终只能得到 `0.8` 或 `8`。

**后果不只是不方便**：`config.yaml` 里 `behavior.interjection_thirst` 实测是 `0`
（默认值应为 `0.08`）——**他想调低频率，结果被静默写成了「完全关掉」**。

修法：`type="text"` + `inputMode` + 本地 draft（只在「看起来是完整数字」时提交）
+ 失焦兜底提交，抽成 `SettingsFields.tsx` 导出的 `NumberField`，
`SettingsFields` / `SpecialMode`（两处）/ `Tuning` 全部复用。
闸门 `tests/test_desktop_number_input_contract.py`，变异 `变异/数字输入.json` **4/4 真红**。

### 3.2 前端改动必须重新部署，否则主人看不到
```bash
cd desktop && npx tsc --noEmit      # 必须干净
cd desktop && npx vite build        # 产出 dist/assets/index-*.js
```
然后把 `desktop/dist` 复制到 `desktop/release/小糖糖桌面端/resources/app/dist`，
并**清掉目标 assets 里不在新构建里的旧文件**（不清会残留旧 js，index.html 引用新的、
旧的还占着，排查时会被误导）。用 Python 写个小脚本做：

```python
import shutil, time
from pathlib import Path
DESK = Path(r"D:\qq-小糖糖\desktop")
APP = DESK / "release" / "小糖糖桌面端" / "resources" / "app"
bak = Path(r"D:\qq-小糖糖\_backups") / ("桌面端dist_%s_说明" % time.strftime("%Y%m%d_%H%M"))
bak.mkdir(parents=True, exist_ok=True)
shutil.copytree(APP / "dist", bak / "dist", dirs_exist_ok=True)      # 先备份
shutil.copytree(DESK / "dist", APP / "dist", dirs_exist_ok=True)
shutil.copytree(DESK / "dist-electron", APP / "dist-electron", dirs_exist_ok=True)
keep = {p.name for p in (DESK / "dist" / "assets").glob("*")}
for f in (APP / "dist" / "assets").glob("*"):
    if f.name not in keep:
        f.unlink()
```

**核对方式**：源码构建的 js 与 release 里的 js **sha256 必须一致**。

## 5. 今天学到的两条（还没写进 CLAUDE.md 教训表）

1. **「存在性断言」当不了守护**：`assert "source_group_id=None" in src` 只证明有，
   不证明全。私聊路径有两处 recall，改一处它照样绿（`变异_scope.json` 的 S1
   就是这么假绿的）。**凡是「这个配置/字段存在」的断言，都要问一句
   「如果它只对了一半，会红吗」**。
2. **「只用一次」的数值函数是两个系统在偷偷共用**：`interjection_thirst` 看起来像
   「插话饥渴度」，实际只喂给群聊引擎；私聊那条路压根不读它。**改一个参数之前，
   先 grep 它被谁读**（`grep -rn "参数名"`），不要从名字推断语义。
