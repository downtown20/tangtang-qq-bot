## 四、验证桌面端前端的方法（这份要记牢，教训 #57）

```powershell
# 1) 起后端桥（记下 BRIDGE_READY 里的 port/token）
python tools/desktop_bridge.py --port 5301

# 2) 起**纯 React** dev server（不要用 vite.config.ts —— 它会 spawn 一个
#    devtools 抓不到的 Electron 窗口）
cd desktop; npx vite --config vite.probe.config.ts    # → http://localhost:5188

# 3) chrome-devtools 打开时用 navigate_page 的 initScript 注入 window.desktop stub：
#    getBridgeInfo 返回 {info: {port, token}}，其余方法给空实现
# 4) 然后真的点：点开/点外/Esc/改值/保存/重载/量 getBoundingClientRect
```

**只跑 `tsc --noEmit` + `vite build` 不算验证**（教训 #57：类型检查和打包都不管
「点一下会怎样」）。
