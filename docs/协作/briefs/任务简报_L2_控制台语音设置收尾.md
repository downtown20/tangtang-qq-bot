- **emotional_tts 是死配置**：agent/ 全目录零引用（voice.py/handler.py/cosy_voice.py 均无），仅控制台 UI 写 config.yaml——历史残留，**不控制 GPT-SoVITS**（GPT-SoVITS 情绪 = 参考音频重演，见 L1 面板）。→ 删 UI + config 字段。
