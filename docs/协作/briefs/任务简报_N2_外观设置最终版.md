## 1. 主人全部需求（历轮明确过的约束——必须全部满足，缺一即返工）

1. **设置页「外观」只保留三项**：主题、配色方案、自定义颜色。**不要任何提示/说明/注释文字**（不出现 hint 行、尾注、解释小字）；不要「更多」折叠；不要字体大小入口（保持 config 默认 13）。
2. **主题**：只给**浅色 / 深色两档**（不要「跟随系统」）。切换控件用**左右滑动滑块**（主人原话「通过滑轮的效果左右选择」——横向滑杆，左浅右深），视觉圆润（胶囊轨道 + 圆形滑块 thumb），当前档有明确视觉反馈。
3. **配色方案**：10 套固定方案（数据源 `agent/theme_palettes.py` 的 `SCHEMES` + `SCHEME_ORDER`，勿改色值）。色卡**纯圆**（不要椭圆/方形/胶囊），尺寸约 30-34px；布局**5×2 两行**、每格**色卡下方配名字小字**（主人认可预览版的这种排布）；选中态用细环/描边表达（当前实现用 border 环——可保留但形状必须正圆）。
4. **自定义颜色**：一个**彩虹渐变圆卡**作为入口（当前实现已有），点击弹出**现代取色面板**（已有 `agent/color_panel.py`：矩形 HSV 色板 + 色相条 + 圆形当前色预览 + HEX 输入 + 6 预设色卡——此面板主人已审核认可，**勿改其结构**）；面板选色即时应用到整体主题。
5. **改动即时生效**（内存 + 主题刷新），持久化由设置页统一「保存设置」按钮（走现有 `_save_config` 机制）。
6. **比例与密度参照「预览版」**（主人认可文件：`tools/外观预览器.py`——运行可见，右控制面板是其认可的观感：紧凑间距、muted 小标签、无赘余）。正式版在设置页内实现时**注意比例**：控件不孤悬、行距紧凑、与设置页其它分区协调。
7. 背景图功能已退役（纯色主题）——不要恢复任何背景图入口。
8. 深浅两套黑白中性底 + 配色点缀的主题模型（theme_palettes 已实现：中性层不染色、accent 由 seed 派生、低饱和自动中性）——保持并沿用，勿另起炉灶。
9. 整页风格（按钮/lucide 图标/圆角/柔角弹层）是主人已通过的现状——**不得回退或改动外观区之外的东西**。
