### 9.2 发现的其它问题（只报告，不越界去修）

**① [重要] 项目文档里那条 pyflakes 验证命令，在 pwsh 下会静默缩小扫描范围——82 个文件只真扫了 2 个**

- 命令：`python -m pyflakes agent/*.py onebot/*.py main.py 糖糖控制台_qt.py | grep -i undefined`
- 在 **pwsh** 下 `agent/*.py` / `onebot/*.py` **不会被展开**，pyflakes 收到字面量路径，直接报：
  ```
  python.exe : agent/*.py: Invalid argument
  onebot/*.py: Invalid argument
  ```
  → 这两个目录**整个被跳过**，只剩 `main.py` 与 `糖糖控制台_qt.py` 被扫。
- 实测对比（同一份代码）：
  - 不展开（照文档原样在 pwsh 跑）：**pyflakes 输出 19 行**
  - 显式展开 82 个文件：**pyflakes 输出 116 行**，其中 undefined 命中 **0**
- 危害：**这条命令仍然报「undefined = 0」，但 80/82 的文件根本没被看过**——假绿。这正是 CLAUDE.md 教训 #30「检查器写了但从没生效」的同一族：**跑起来没报错 ≠ 真的扫了**。默认在 Git Bash 下会展开所以一直没暴露；换成 pwsh / CI / subprocess 调用就静默变弱。
- 建议（未实施，属他人 scope）：把验证固化成一个脚本（如 `tools/体检.py` 内），由 Python 自己 `glob` 展开文件列表，不再依赖 shell 展开。

**② [重要] `stignore`（无点）与 `.stignore` 是两份内容相同的副本，改动必然漂移**
