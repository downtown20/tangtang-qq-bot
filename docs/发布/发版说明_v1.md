## 快速开始

1. 解压 `tangtang-v1.06.00.zip`，双击 **`安装糖糖.bat`**，勾选需要功能
   - 默认已勾好：聊天+高质量记忆 / 唱歌 / 图形控制台
   - 想让她开口说话 → 勾「发语音+听懂语音消息」（模型约 6.5 G，自动下载）
   - 想让她看懂图 → 勾「本地识图」（约 2.5 G；也可走云端千问 VL，零下载）
2. 双击 **`启动控制台.bat`**，填机器人 QQ 号、你自己的 QQ 号、模型 API Key
3. 控制台里点「启动 SnowLuma」扫码登录 → 点「启动糖糖」

> **还差一步**：SnowLuma 是第三方 QQ 协议端，许可协议不允许随本项目分发。
> 需从 [官方发布页](https://github.com/SnowLuma/SnowLuma/releases) 下载 Windows x64 版，
> 解压到 `SnowLuma/` 目录下。安装程序开头会提醒；也可用任意其他 OneBot 11 实现替代。

断网直接重跑 `安装糖糖.bat`，已下载的部分不会重来；事后补装同样重跑、勾上对应项。

## 本次更新

- **perf(安装包)** 主包 1128 M → **702 M**。`songs/audio/` 的 40 首是 40kHz 单声道
  PCM16（712 M，占整包 67%），而唱歌通过 `[CQ:record]` 发出、即 QQ 语音消息，
  QQ 侧会转成 SILK 低码率编码——存无损是白背。改为 128kbps mp3
- **fix(翻唱)** 自动安装通道接上：控制台「一键全流程」发现缺件时，可直接下载模型包
  （Release 附件）并**在本机创建**人声分离环境。此前 HuTao 模型/索引的下载地址是空的，
  弹窗只会说「待作者提供」
- **fix(翻唱)** RVC 的 Python 依赖补进安装器「唱歌」组
  （`pyworld` / `torchfcpe` / `librosa`；`fairseq` 只有源码包、装上才算完整）
- **fix(翻唱)** 新增 import 自检——装了不等于能用。`faiss` 与 NumPy 2 的 ABI 冲突那次，
  文件都在、动态库加载不了，只看文件存在与否查不出来

更早版本见 `docs/发布/更新日志.md` 与[历史 Release](../../releases)。

## 关于 `tangtang-singing-models.zip`

做新翻唱时才需要。**点歌播放不需要它**——41 首成品已随包自带。

包内是精简过的 RVC 推理代码与 HuTao 模型（原目录 12.8 G，只保留推理要用的 96 个文件）。
**不必手动下载**：控制台「一键全流程」发现缺件时会自己拉取并解压。
人声分离用的 4 个模型（约 2.5 G）也不在这里——`audio-separator` 首次用到时自己下载。
