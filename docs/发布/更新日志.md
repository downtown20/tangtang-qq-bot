# 更新日志

## v1.5（2026-09-20）

- **fix(唱歌)** 歌唱工作室依赖链卡在 NumPy 2——`faiss` / `pyworld` / `numba` 都是
  NumPy 1.x 时代编译的，`from infer.modules.vc.modules import VC` 直接 ImportError。
  requirements 改钉 `numpy>=1.23.5,<1.24` + `faiss-cpu==1.7.4`
- **fix(唱歌)** RVC 索引在中文路径下静默加载失败——faiss 的 C++ 端用窄字符 `fopen`，
  绝对路径含中文时打不开；索引不生效也不报错，只是音色相似度降低。改为传相对路径
- **fix(控制台)** 「打开目录」四个按钮原先只弹「找不到目录：`<路径>`」，
  未说明原因与下一步。现按功能分别说明，并在歌唱工作室顶部预告缺失组件
- **fix(控制台)** 密钥管理第二项 `千问 VL API Key` → `识图 API Key`（选本地识图不需要 Key）
- **fix(安装器)** 「唱歌」选项说明补上「仅播放，不含翻唱制作工具」
- **chore** 新增翻唱制作组件 `tangtang-singing-models.zip`（可选）

## v1.4（2026-09-19）

- **fix(知识库)** 知识库索引重新随包。v1.3 把它整个剔除，代价是每个用户首次启动
  多等 6.8 秒重算 BGE 向量；改为在清理干净的快照上现场重建，保证与源文件同源
- **fix(发布)** 索引的 `-wal` / `-shm` 边车未进忽略表，被 copytree 搬进快照
