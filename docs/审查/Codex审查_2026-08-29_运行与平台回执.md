## Important：平台迟到回执不可安全直连

- 位置：`napcat/ws_client.py:633-758,1190-1260`、`agent/store.py:6909-6990`。
- 证据：OneBot HTTP `send_*` 标准响应只有 `message_id`，当前请求没有 echo；NapCat
  `message_sent` 无 echo，当前 `_event_route` 返回 `None`；反向 WS 只校验 localhost，
  无连接级 token/nonce。运行探针确认 3001 未接入可用回执消费。

  `v2:` event_key 复用会把自发消息伪装成入站，且本机进程可伪造 raw frame。
- 最小修复：新增 `agent/platform_receipts.py` 与 ADR-006，定义独立 `out:v1` event_key、
  持久 transport request、精确 outbox/self/channel/target/payload hash、唯一合法
  signed-int32 IDs、时间窗和 synthetic 默认拒绝；当前不改路由、不启用 late-confirm。
  新增 13 条契约回归，并在零调用审计中登记 feature-off 的唯一 allowlist 理由。
