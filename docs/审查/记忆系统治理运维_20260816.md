# 记忆系统治理运维手册（2026-08-16 治理工程交付）

> 背景：特摄事故（错误事实「特摄仙人/时政兴趣」被画像合成洗白、全链路无纠正写回）。
> 治理工程分 7 批完成：0 基线 → 1a 关系游标 → 1b 注入收口 → 2 纠正真值闭环 →
> 2b 事故定向清洗 → 3 合成生命周期 → 4 提取质量 → 5 读侧治理 → 6 机械治理。
> 设计与审查记录见 docs/审查/记忆系统审查简报_20260816.md、记忆系统Codex审查_20260816.md。

## 一、真值状态语义（新增）

| 字段 | 位置 | 语义 |
|---|---|---|
| `status` | memories / cluster_facts | `active`=有效；`retracted`=被否定；`superseded`=被纠正/新世代替代 |
| `notes_dirty` | people | 1 = 画像已被纠正失效、禁止注入，等后台重合成清零 |

铁律：
- **撤销不改 importance**——importance 是相关性不是真值（setter 钳最小值 1）
- 所有读路径默认只取 active；`include_retracted=True` 仅清洗/诊断用
- 合成快照是派生数据：profile_synthesis 每人是 singleton，fact_synthesis 是完整世代
  ——每次合成事务化替换旧世代（旧行标 superseded + 删 embedding）

## 二、纠正闭环（糖糖可用工具）

- `correct_memory(subject_qq, wrong_fact, corrected_fact)` / `forget_memory(subject_qq, fact)`
- 权限：纠正关于自己的事实=本人；纠正第三人=仅主人
- 流程：保守匹配（LIKE + BGE>0.7）→ 标 status → 簇事实撤销+摘要清空 → notes 标 dirty
  → 主调用结束后后台重合成（绕过冷却一次）→ 成功清 dirty
- 自忆门控：纠正回合的确认回复不进糖糖自忆（防跨主体污染）
- 契约：协议已进系统提示词——被纠正事实必须调工具写回，写回前不许说「记住了」

## 三、画像合成生命周期（新增约束）

- 成功冷却 24h（kv `profile_syn_at:{qq_id}`）；纠正路径绕过一次
- 触发计数只算 active 非合成行（`count_active_fact_memories`）——不再自激
- 合成输入排除：合成行自身 + 低置信度（<0.75）semantic 记忆不参与
- 输出契约：prompt 禁开头语 + 入库前缀兜底剥离；失败不覆盖旧画像

## 四、提取质量分层（新增约束）

- 置信度：字段缺失→拒绝；显式 0.7→低可信候选（不进画像/自动注入，检索带 `~` 标记）
- 禁用条款（主提取与事实簇共用）：玩笑/测试语句/引用转述/否定方向/无上下文单句标签
- 提取批次带 #id 与糖糖相邻回复（语境）——单句玩笑不再零语境入库
- 事实簇：独立游标（kv `fact_cluster_last_chat_id`）+ 证据 id（evidence_ids）+ 实际插入计数
- 检索打分：confidence 进分（0.55 与 1.0 不再同权）；corrected 加权 1.4；
  合成行（origin=summarized）不强化

## 五、治理工具

| 工具 | 用途 | 用法 |
|---|---|---|
| `tools/cleanup_memory_incident_20260816.py` | 事故定向清洗（幂等，可重跑） | `--apply` 执行；dry-run 默认 |
| `tools/cleanup_memory_mechanical.py` | 全库机械治理：完全重复、孤儿 embedding、90 天前旧世代快照；矛盾/元话术出审核清单不自动改 | `--apply` 执行；清单在 data/审核清单/ |

日常节奏：每月跑一次机械治理（dry-run → 审清单 → --apply）；
审核清单里的矛盾对用 correct_memory 工具或人工 DB 处理。

## 六、健康检查（新增两项，daily）

- `memory_truth`：元话术污染（notes 含「增量更新」等前缀）/ 合成占比 >30% / dirty 画像未清算
- `feedback_pipeline`：feedback 表是否有消费记录（消费点=每日播报 `_report_stats_with_feedback`）

## 七、数据恢复

- 事故行基线：docs/审查/事故数据基线_20260816.md
- 全量测试：371 通过（治理后）——`python -m pytest tests/ -q`

## 八、重启上线检查单

1. bot 重启（全部治理代码生效——status 列/注入收口/纠正工具）
2. 主人第一条消息 → 画像重合成触发 → 人工验收新画像（应无特摄/时政）
3. 观察 24h：健康检查 memory_truth / feedback_pipeline 无告警
4. 验证纠正闭环：主人随便纠正一条 → 确认 DB status 变化 + 「记住了」前有工具调用
