## 2. 缺陷清单（四段式）

### 🔴 D1 — 日期年份被正则吃掉

- **位置**：`agent/memory.py:1631`（`synthesize_profile` 解析 `KEY_FACTS`）
- **证据**：
  ```python
  line = _re.sub(r'^[\s\-•·\d.]+\s*', '', line).strip()
  ```
  阳性对照（真跑该正则）：

  | 输入 | 输出 |
  |------|------|
  | `2026年10月5日休学一年后回归学校…` | **`年10月5日休学一年后回归学校…`** |
  | `- 在雷霆服务器当过管理员…` | `在雷霆服务器当过管理员…` ✅ 原意成立 |
  | `3. 住在校外…` | `住在校外…` ✅ 原意成立 |

  受损范围：`memories` **33 条**（全为 `key='fact_synthesis'`）、**`people.notes` 13 份**；最早 2026-08-16，最近 **2026-10-13 仍在产生**。全仓扫描同款字符类**仅此一处**。
- **根因**：字符类 `[\s\-•·\d.]+` 锚不住「列表标记」，会吃掉行首任意连续数字。注释写的是「支持 - 开头或数字开头的列表」，实现却在吃裸数字。
- **最小修复**：
  ```python
  # 只剥列表标记，不剥裸数字（\d{1,3} 刻意排除 4 位年份与点分日期）
  line = _re.sub(r'^\s*(?:[-•·]\s*|\d{1,3}[.、)]\s*)\s*', '', line).strip()
  ```

### 🔴 D2 — 提取 96.9% 产出空数组

- **位置**：`agent/memory.py:1265-1314`（提取 system prompt）
- **证据**：219 / 225 `success_empty`，`raw_length=2`（`[]`），`protocol_ok=true`；日志 `stage=llm_succeeded elapsed_ms=1557.6` 证明 LLM 真被调用；跨 3 个群、含纯文本窗口，样本充分。
- **根因（定性）**：**提示词层面的过度抑制**。禁项列表 10 类，收尾两句是「如果消息中没有有意义的新信息，返回空数组 []」「宁缺毋滥」——模型被引导到几乎不开口。
- **最小修复建议**（按优先级）：
  1. 把「宁缺毋滥」的绝对化措辞改为**分档期望**（明确「一次 10 条消息里通常有 0–3 条可提取」）
  2. 给禁项加**反例对照**（现在是纯负面清单，没有正例锚定边界）
  3. 加**空产出率告警**：`success_empty` 连续 N 次 → health_check 报警（现在 96.9% 空却无人报）

### 🔴 D3 — `valid_from` 100% 为空

- **位置**：`memories.valid_from`（22,107 行全部为空）
- **证据**：`SELECT COUNT(*) FROM memories WHERE valid_from=''` = 22,107
- **根因**：列已建、从未写入——「真值生命周期」设计中的生效时间维度**没有生产者**。
- **最小修复**：要么在写入路径填 `event_time`，要么**删列**并在文档中说明该维度未启用。**留着不写比删掉更坏**：任何按它做的分析都必然得出「所有记忆同时生效」。

### 🟠 D4 — 75.8% 的记忆没有证据链

- **位置**：`memory_evidence`（23,257 行）vs `memories`（22,107 行）
- **证据**：只有 5,352 条记忆有证据行（24.2%）；`backfill` 99.9% 无证据、`corrected` 100% 无证据
- **根因**：证据链是**后加的**（2026-09-02 后新写入的都是 verified）；存量记忆从未补链，且**没有补链工具**。
- **最小修复**：为存量补链需要原文，可从 `chat_log` 按 `source_group_id` + 时间窗重建——但需先确认值不值得（见「处置建议」）。

### 🟠 D5 — 回填通道已死

- **位置**：`extraction_cursors`（forward 510 / backfill 319）
- **证据**：319 个 backfill 游标**全部 ≤ 对应 forward**，候选恒为 0
- **根因**：forward 永远追得上，backfill 的启动条件（前进游标与回填游标跨度 ≥30 条）**永远不成立**
- **最小修复**：要么让 backfill 以「历史空白区」为输入而不是「前向滞后」，要么明确废弃并删掉这 319 个游标（现在它们是**误导性状态**）

### 🟠 D6 — 阶段复核机制形同虚设
