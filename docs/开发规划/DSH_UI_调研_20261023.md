## 1. 整体布局

### 1.1 三栏 Grid

证据：`dsh-client-ui-layout/lib/client.js` L38-47 `computeColumns()`、L321 `gridTemplateColumns`、L396

```js
const s = sidebar === 0 ? collapsedWidth : clampWidth(sidebar, 264, 420);   // collapsedWidth=56
const available = viewport - s - 400;                                       // 中列至少 400
const r = rightbar === 0 || available < 300 ? 0
        : Math.min(available, clampWidth(rightbar, 300, viewport * RIGHTBAR_MAX_RATIO)); // 0.7
// L321: grid-template-columns: ${sidebar}px minmax(${rightbar===0?0:400}px,1fr) minmax(0px,${rightbarMax}px)
```

| 区域 | 规则 | 值 |
|---|---|---|
| 左侧栏 | `clampWidth(sidebar, 264, 420)` | **264–420，默认 280**（L396） |
| 左侧栏收起 | `collapsedWidth` | **56** 图标轨；Windows/macOS 桌面端传 **0**（L242） |
| 中间区 | `minmax(400px, 1fr)` | ≥400 |
| 右侧面板 | `clampWidth(rightbar, 300, vw*0.7)` | **300 起，≤视口 70%**；`RIGHTBAR_MAX_RATIO=.7`（L15） |
| 右面板默认 | `rightbar:null / rightbarShown:false` | **默认关闭**（L399-401）；`vw<1024` 收窄侧栏（L434） |
| 框架行 | `grid-template-rows: minmax(0,1fr) auto` | 主体+底部 |
| 侧栏宽度变量 | `setProperty("--dsh-windows-sidebar-width", …)` | L320 |

| 字段 | 文案 | 校验/说明 |

### 4.4 「输入 API KEY 后获取所有模型」：接口与交互

**调用链（4 段全证）**：
1. 按钮 `fetchModels`「获取可用模型」→ `fetchModels()`（`ModelListEditor.js` L946，按钮 L1037-1045）
2. `operations.discoverModels(settingsNs, {provider?, baseURL?, api?, apiKey?})`（`operations.js` L3194-3203）→ `ctx.remote.llm.discoverModels(...)`
3. Host：`@Remote('discoverModels') async remoteDiscoverModels(settingsNs, request, signal)` → 分派适配器（`dsh-tool-cordis/lib/types/api-catalog.js` L229-240）
4. 适配器 HTTP（`dsh-llm-pi-ai/lib/index.js` L2233-2320 注释即规范）：

| 协议 | 请求 | 鉴权 |

## 7. 复刻建议

1. **核心 5 值**：`#151517` 底 / `#2c2c2e` 卡 / `#1b1b1c` 侧栏 / `#f9fafb` 主文字 / `#7aaaff` 强调；圆角 4/8/12/16/20/28 六档。
2. **布局**：三栏 grid——侧栏 280（264–420，收起 56）、中列 `minmax(400px,1fr)`、右栏 300–70vw 且默认关；Windows 自绘标题栏 40px。
3. **设置页照搬模态**：800 宽（`min(800, vh-…)`）、28 圆角、左 188 导航 + 40px 导航格 + 遮罩 `#00000080`。
4. **分类按 order**：账号(-10) → 通用(0) → 模型(10) → 插件(15) → Agent 预设(20)；外观/快捷键/语言放通用分区子项。
5. **模型设置三件套**：provider 卡列表（凭据圆点）→ 虚线大按钮「添加提供商」（目录/自定义二选一）→「获取可用模型」多选弹窗（搜索+全选+添加所选）。
6. **获取模型接口**：OpenAI 兼容 `GET {baseURL}/models`（Bearer）；Anthropic `GET /v1/models`（x-api-key+anthropic-version）；内置目录 provider 不发网络请求。
7. **模型切换器**放 composer 内：28px 次级按钮 + 两级菜单（模型 / 推理档位）。
