> 2026-08-01 | 最终版

---

## 一、怎么用

### 最简单：双击 `separate_vocals.bat`

文件位置：`tools\separate_vocals.bat`

- **双击** → 输入音频文件路径 → 回车 → 自动处理
- **拖音频文件**到图标上 → 自动处理
- **拖文件夹**到图标上 → 处理文件夹里所有音频
- **拖多个文件**到图标上 → 逐个处理

输出位置：原文件旁边的 `separated/` 文件夹，文件名以 `_FINAL.wav` 结尾。

全程约 15 分钟一首歌（CPU 处理，4 步流水线）。关掉窗口即可取消。

### 进阶：命令行

```bash
cd <项目根目录>

# 处理一首歌
venv_demucs\Scripts\python tools/separate_vocals.py "歌曲.wav"

# 指定输出目录
venv_demucs\Scripts\python tools/separate_vocals.py "歌曲.wav" -o "输出文件夹"

# 保留中间文件（调试用）
venv_demucs\Scripts\python tools/separate_vocals.py "歌曲.wav" --keep
```

## 二、流水线说明

```
原始歌曲
  ↓ ① MDX23C-InstVoc HQ         提取人声
  ↓ ② Denoise RoFormer          去噪 (SDR 27.99)
  ↓ ③ Bleed Suppressor          去漏音（残留伴奏）
  ↓ ④ VR-DeEcho-DeReverb        去混响
  ↓
最终干声 ✅
```

每步约 2-6 分钟。全程 CPU，不需要 GPU。

## 三、安装（仅需一次）

### 1. 创建虚拟环境

```bash
cd <项目根目录>
py -3.10 -m venv venv_demucs
```

### 2. 安装依赖

```bash
venv_demucs\Scripts\python -m pip install torch==2.5.1 torchaudio==2.5.1 --index-url https://download.pytorch.org/whl/cpu
venv_demucs\Scripts\python -m pip install audio-separator onnxruntime
```

## 四、踩坑记录

### 坑 1：自己写 API 分离沙哑

用 soundfile 加载 + 手动归一化，和官方 CLI 的 torchaudio 流水线不同。**用官方 SDK。**

### 坑 2：dev PyTorch 破坏数值精度

RTX 5070 (Blackwell sm_120) 只能用 dev PyTorch 2.14+cu130，但 dev 版会破坏人声分离质量。解决：人声分离单独用 venv 在 CPU 跑。

### 坑 3：Bleed Suppressor 的 stem 命名

`(Bleed)` = 干净人声，`(Instrumental)` = 去掉的漏音。别搞反。
