### 🆕 新发现问题

**自忆写死路径**：以 `bot_qq` 为 key 存储的自我记忆（承诺/推荐/观点），embedding 写入完整但**没有代码读取**。self_state.py 和 reflection.py 都不调用 `recall(bot_qq)`。和错误十二（BGE embedding 死代码）同一模式。

**双重 BGE 计算**：`recall()` 做一次 BGE 粗排，`_bge_pick_memories` 重新从 DB 读 embedding 再做一次。同一批候选被 embed 两次。

**Reranker 路径重复**：`_bge_pick_memories` 和 `recall()` Phase 1.5 各有一套 Reranker 调用，做同一件事但路径不同。
