## 唱歌系统架构（最终态）

```
用户点歌 → handler.py 检测
  → SongLibrary 搜索曲库 + 段落
  → LLM 选段 + 回复 [SING:段落名]
  → handler 解析标记
  → 发送 songs/audio/歌名/段落名.wav
  → 无音频则 TTS 降级
```
