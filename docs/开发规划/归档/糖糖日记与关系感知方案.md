# 糖糖日记 + 关系感知方案

> 2026-08-01 | 两个轻量功能

---

## 一、糖糖知道"谁和谁关系好"

### 问题

群聊不是 1v1。A 经常提到 B、A 和 B 经常一起出现——糖糖应该感知到"A 和 B 关系不错"，但不是 stalking，只是在自然对话中体现。

### 方案

在 `RelationshipField` 中新增 `mentions: dict[str, int]`：

```python
# 浪浪的关系场
mentions: {"忽热忽冷": 5, "小明": 2}
# 浪浪在对话中提到忽热忽冷 5 次，提到小明 2 次
```

**记录时机**：窗口内消息处理时，检测对方消息中的 @提及或人名：

- `[CQ:at,qq=xxx]` → 找到被 @ 的人 → 记录到发送者的 mentions
- 自然语言中叫出名字（"小明你昨天..."）→ jieba 分词 + people 表匹配

**注入时机**：对话窗口上下文注入时，如果对方有高频 mentions，轻描淡写一句：

```
（ta 在群里和小红、小明 聊得比较多）
```

LLM 可以在合适时自然接话："你上次和小红聊的那个电影..."

### 限制

- 只记录 ≥3 次的 mentions（避免噪音）
- 最多存 5 个人
- 不跨群
- 不在私聊中注入（私聊不需要知道对方在群里的社交关系）

### 改动

| 文件 | 改动 | 行数 |
|------|------|:--:|
| `agent/self_state.py` | RelationshipField 新增 mentions 字段 + 持久化 | ~5 行 |
| `agent/conversation_tracker.py` | 窗口内检测 @ 和人名提及 | ~15 行 |
| `agent/handler.py` | 注入 mentions 到上下文 | ~5 行 |

总计 ~25 行，零 LLM 成本。

## 二、糖糖的日记本

### 问题

反思系统每天凌晨生成 journal_entry，但没人看。糖糖的 self_narrative 一直为空——她不知道"我最近过得怎么样"。

### 方案

反思整合时（Phase D），把 journal_entry 写入 `self_narrative.recent_experiences` 和 `things_i_learned`。下次有人问她"你最近怎么样""你这几天在忙什么"时，LLM 能从叙事中找到真实的近期经历。

**具体改动**（`reflection.py` 的 `_apply_reflection` 方法中，已有 journal_entry 变量，只需多加一行）：

```python
# 已有的代码生成了 journal_entry
if result.journal_entry:
    self._self_state.self_narrative.recent_experiences.append(
        f"日记({datetime.now().strftime('%m-%d')}): {result.journal_entry[:120]}"
    )
```

**日记示例**（LLM 反思产出）：
```
"今天和浪浪聊了很多音乐的事，帮他找了几首日语歌。
 和忽热忽冷聊了 DeepSeek 论文，感觉他挺认真的。
 在群里主动说了两次话，一次有人理了，一次没人理——下次换个方式试试。"
```

**注入时机**（扩宽——不只是被动回答，而是主动分享）：

| 场景 | 触发 | 注入方式 |
|------|------|---------|
| 被问"过得怎么样" | jieba 检测"最近+怎么样/如何/干嘛" | 取最近 2 条日记 |
| 安慰/心理陪伴 | 检测到对方情绪低落 + 糖糖回复 | "我最近有时候也觉得..."（取情感相关的日记片段） |
| 对方分享日常 | 对方说自己的事（>15 字），正常回复后 | 偶尔附一句"我这边最近..."（概率 30%） |
| 窗口对话 >5 条 | 深度对话中 | 取最近 1 条日记轻描淡写融入 |
| 自治消息 | 主动发起时 | 从日记中选一条作为话题锚点 |

**核心原则**：不是每次都说——糖糖偶然想起自己的一件事，顺便分享一下。频率控制在每小时最多 1 次。

**日记片段选择**：从最近 3 条日记中随机选一条 30-100 字的，LLM 自己判断是否适合当前对话——不适合就不提。

### 改动

| 文件 | 改动 | 行数 |
|------|------|:--:|
| `agent/reflection.py` | 反思后写入 narrative | ~3 行 |
| `agent/handler.py` | 各场景检测 + 注入 | ~20 行 |

总计 ~23 行，不额外调 LLM。
