# 自治消息优化方案

> 2026-07-31 | 解决驱动力触发的消息割裂和公式化

## 问题

糖糖自治循环触发的消息有三个问题：

### 割裂
"大家最近有没有什么想让我帮忙看的插图？之前有人问过但我没及时回，现在补上～"
——群友正在聊别的话题，糖糖突然插入无关内容，像群发广告。

### 公式化
"之前有人问过但我没及时回，现在补上" —— 像是在写工作周报，不是猫娘在聊天。
每轮自治消息都是同样的模板：解释动机 + 邀请互动。

### 不顾及当前氛围
群里正在活跃聊天 → 突然插入一条正式的问题。群里已经安静了半小时 → 发的消息字数太多太正式。

## 方案

### 1. 注入群聊上下文

自治消息生成时，注入最近 5 条群聊消息作为上下文：

```
【群聊最近在聊什么（供参考，不用复述）】
浪浪：今天画的插图怎么样
忽热忽冷：还行，就是颜色偏暗了
浪浪：我调一下试试
```

LLM 看到上下文后自然产生的话题衔接：
- ❌ "大家最近有没有什么想让我帮忙看的插图"（公式化）
- ✅ "哎呀，看到你们在聊插图的事，我帮不上忙但是想看～"（自然衔接）

### 2. 自然化语气

把现在的 system_prompt 从"解释你为什么来"改成"你就是想来说句话"：

```
现在：
  你有一种内在的冲动想主动做点什么...
  如果驱动力是「社交渴望」：想想有没有谁好久没出现了...
  如果驱动力是「表达冲动」：分享一个想法、感受...

改后：
  你就是想在群里说句话。不用解释你为什么来，
  不用铺垫。像朋友突然想起一件事跟你分享一样自然。
  一句就好，最多两句。
```

### 3. 时机分级

根据群聊活跃度调整消息风格：

| 状态 | 判断 | 消息风格 |
|------|------|---------|
| 活跃 | 5 分钟内有消息 | 简短接话，1 句，融入当前话题 |
| 安静 | 30 分钟内有消息 | 自然发起，2 句，可以说点自己的事 |
| 沉寂 | 30+ 分钟无消息 | 适当长一点，3 句，抛一个开放式话题 |

### 4. 不重复自己

维护最近 3 条自治消息的缓存。新消息不与旧消息雷同（BGE 相似度 > 0.6 就换说法）。

### 5. 冷场感知

**问题**：自治消息发出后没人回——糖糖不疼不痒，下次还是照样发。

**方案**：

自治消息发出后，启动一个 2 分钟"等待回应"窗口：

```
发送自治消息 → 等 2 分钟 →
  有人回复 → 回避欲 -0.05，该群自治权重 +1 ✅
  没人理  → 回避欲 +0.10，该群自治权重 -1 ❌
            → 下次驱动力到了，优先选别的群
```

群自治权重降到底（-3）→ 这个群暂停自治消息，只被动回复。直到有人 @ 糖糖。

**实现**：
- `ConversationTracker` 新增 `_autonomous_pending: dict[str, float]` —— {group_id: 发送时间}
- 下次自治循环检查时，先看上次发了有没有人回应
- 没人回应 → 回避欲加成 + 该群降权
- 有人回应 → 正常

### 6. 冷场后的态度变化

如果同一群连续 2 次自治消息被无视：
- LLM 消息变得更短更随意："唔...你们在聊什么呀"而不是正式的长消息
- 如果还是没人理 → 第 3 次开始不再主动发
- 如果有人回应 → 重置计数，恢复热情

**改动**

| 文件 | 改动 | 行数 |
|------|------|:--:|
| `agent/handler.py` `_check_autonomous_action` | 改 prompt + 注入上下文 + LLM冷场判断 + 窗口检测 | ~60 行 |
| `agent/conversation_tracker.py` | 自治窗口追踪 | ~15 行 |

总共 ~75 行，两个文件。LLM 冷场判断每次 ~0.001 元。
