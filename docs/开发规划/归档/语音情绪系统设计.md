# 语音情绪系统顶层设计

> 2026-07-28 · GPT-SoVITS + 丛雨 400 条音频 → 情绪驱动语音

---

## 一、核心发现

### GPT-SoVITS 的情绪传递机制

参考音频的情感会**直接传递**到生成语音中。嘶吼的参考 → 嘶吼的输出；悲伤的参考 → 悲伤的输出。不需要调参数——选对参考音频就完成了一半。

### 丛雨音频现状

400 条 WAV，9 个场景文件夹（mur001~mur009），每条 1-10 秒，44100Hz，干净无 BGM。但没有情绪标签——不知道哪条是开心、哪条是难过。

### 解决方案

用 **SenseVoiceSmall**（阿里达摩院，支持日语情绪识别）自动给 400 条音频打情绪标签。按 GPT-SoVITS 最佳实践，每个情绪选 5 秒以上、质量最好的参考音频。

## 二、糖糖需要的情绪维度

| 情绪 | 场景 | 参考音频要求 | 语速 |
|------|------|------------|------|
| **开心 happy** | 被夸、打招呼、分享有趣的事 | 音调高、轻快活泼 | +5% |
| **兴奋 excited** | 惊喜、激动、群里有好玩的事 | 音调很高、语速快 | +8% |
| **撒娇 coquettish** | 对主人、亲密的人 | 软糯、拖长音 | -5% |
| **难过 sad** | 安慰人、深夜陪伴 | 低沉、语速慢 | -8% |
| **温柔 gentle** | 认真聊天、关心问候 | 平稳柔和 | 正常 |
| **傲娇 tsundere** | 被戳穿、害羞嘴硬 | 假装生气、语调起伏 | +3% |
| **日常 normal** | 普通聊天、插话 | 中性自然 | 正常 |

## 三、技术架构

```
丛雨 400 条音频
      ↓
SenseVoiceSmall（日语情绪识别）
      ↓
按 7 种情绪分组，每组建一个 GPT-SoVITS speaker
      ↓
voice.py 新增 gpt-sovits provider
      ↓
LLM 回复 → [VOICE: [开心] 文本] → 匹配 happy speaker → GPT-SoVITS API
```

### 文件结构

```
cosyvoice3/speakers/  → 不再使用（CosyVoice 仅保留默认音色）
gpt-sovits/
├── api_v2.py          ← 常驻服务（端口 9880）
└── speakers/
    ├── happy/ref.wav      ← 丛雨开心音频
    ├── excited/ref.wav    ← 丛雨兴奋音频
    ├── coquettish/ref.wav ← 丛雨撒娇音频
    ├── sad/ref.wav        ← 丛雨难过音频
    ├── gentle/ref.wav     ← 丛雨温柔音频
    ├── tsundere/ref.wav   ← 丛雨傲娇音频
    └── normal/ref.wav     ← 丛雨日常音频
```

### voice.py 改动

```python
GPT_SOVITS_URL = "http://127.0.0.1:9880"

EMOTION_GPT_SPEAKER = {
    "开心": "happy", "兴奋": "excited", "撒娇": "coquettish",
    "害羞": "tsundere", "得意": "tsundere",
    "难过": "sad", "伤心": "sad",
    "温柔": "gentle", "认真": "gentle", "悄悄话": "gentle",
    "生气": "normal", "愤怒": "normal", "无语": "normal",
    "鼓励": "happy", "搞笑": "excited",
}

async def _gpt_sovits_tts(text, speaker="normal"):
    ref = f"<项目根>/gpt-sovits/speakers/{speaker}/ref.wav"
    r = await http.post(f"{GPT_SOVITS_URL}/tts", json={
        "text": text, "text_lang": "zh",
        "ref_audio_path": ref, "prompt_lang": "ja",
        "prompt_text": "", "batch_size": 1,
        "media_type": "wav", "streaming_mode": False
    })
    return r.content  # WAV bytes
```

## 四、实施步骤

### 第一步：自动标注情绪（30 分钟）
- 装 SenseVoiceSmall
- 跑 400 条音频，输出每条的情绪标签
- 人工抽查 20 条验证准确率

### 第二步：挑选参考音频（30 分钟）
- 每个情绪选 2-3 条质量最好的
- 用 GPT-SoVITS 合成测试，选出效果最好的那条
- 注册为 speaker

### 第三步：对接 voice.py（1 小时）
- 加 `gpt-sovits` provider
- 情绪 → speaker 映射
- 缓存（相同文本+情绪不重复合成）
- config.yaml 切到新 provider

### 第四步：联调测试
- 各种情绪场景各测一轮
- 听感评估：音色像不像丛雨、情绪对不对

## 五、质量验收标准

| 维度 | 标准 |
|------|------|
| 音色一致性 | 7 种情绪听起来是同一个人（丛雨），不是 7 个不同的人 |
| 情绪准确性 | 开心=轻快、难过=低沉、傲娇=嘴硬——不能串味 |
| 文本匹配度 | 中文文本+日语口音=自然萌，不能听起来像机器翻译 |
| 延迟 | TTS < 5 秒（GPT-SoVITS 参考值 ~3 秒/句） |
