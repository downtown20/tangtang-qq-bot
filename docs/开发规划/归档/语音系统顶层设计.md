# 语音系统顶层设计 v3

> 2026-07-28 · 方向修正：语音 = 角色扮演工具，不是情感陪伴工具

---

## 核心原则

**声音决定人格。切换声音 = 切换角色。**

- 丛雨音色 → 丛雨人格（傲娇、日语口音、游戏角色感）
- 糖糖自己的音色 → 糖糖人格（猫娘、俏皮）
- 凑企鹅音色 → 搞笑/鬼畜人格（搞笑效果）
- 不同角色互不干扰，不需要统一成"糖糖的感觉"

---

## 语音的三种用途

### 1. 角色扮演（主用途）
- 群友想让糖糖用丛雨的声音说话 → `/语音 角色 丛雨`
- 群友想让糖糖用搞笑声音说话 → `/语音 角色 企鹅`
- LLM 根据当前角色自动调整说话风格
- 每个角色对应一个 GPT-SoVITS speaker（参考音频）

### 2. 搞笑/鬼畜（效果用途）
- 特定触发词 → 用特定搞笑声音回复
- 凑企鹅、电音、加速等效果
- 不需要语义完整，只需要搞笑效果
- `/语音 效果 企鹅`

### 3. 语音消息（工具用途）
- `/语音` → 用当前角色发一条语音消息
- 纯工具，不说废话，不装打字

## 技术实现

### 角色切换
```
/语音 角色 丛雨  →  self.voice.current_speaker = "murasaki"
/语音 角色 糖糖  →  self.voice.current_speaker = "tangtang"
```

切换后 LLM 自动感知——可以在 system prompt 告知当前角色。

### 效果触发
```
/语音 效果 企鹅  →  用 penguin speaker 发一条搞笑语音
```

### 语音消息
```
/语音  →  当前角色发一条语音（取 LLM 回复第一句）
```

## 与之前设计的关键区别

| | 旧设计 v2 | 新设计 v3 |
|---|---|---|
| 语音目标 | 传递糖糖的情绪 | 传递角色的个性 |
| 音色策略 | 统一糖糖音色 | 多角色独立音色 |
| 情绪标签 | 复杂多情绪 | 简化单标签或不加 |
| LLM 关系 | 语音是糖糖的延伸 | 语音是独立的角色 |
| 文本来源 | LLM 专门生成 | LLM 回复截取第一句 |
| 质量要求 | 每句都要好 | 搞笑效果容错高 |
