# 运行模式简化 (2026-08-03)

## 现状

控制台 Settings 页有一个"运行模式"下拉框：

```
行为 → 运行模式: [全能模式] [简约模式]
```

### 全能模式
- 本地识图 (MiniCPM-V) + 本地语音 (GPT-SoVITS)
- 控制台自动启动 GPT-SoVITS 服务（`start_for_full_mode()`）
- `llm.vision.provider = "local"`

### 简约模式
- 云端识图 (千问VL) + 本地语音 (GPT-SoVITS)
- 不启动本地服务
- `llm.vision.provider = "api"`

### 实现
- UI 定义：`糖糖控制台_qt.py:1243-1245`
- 切换逻辑：`_on_run_mode_changed()` (line 3451-3459) — 只改 vision provider
- 服务启动：`main.py` 调用 `handler.start_services()` → `service_manager.start_for_full_mode()`

## 为什么该移除

1. **识图已有独立选择**：`llm.vision.provider` 可以单独选 local/api，运行模式只是冗余地覆盖它
2. **语音已有独立选择**：voice.provider 可以选 edge-tts / gpt-sovits / cosyvoice，和模式无关
3. **实际行为不符**：简约模式也启动 GPT-SoVITS（因为 _ensure_gpt_sovits 不管模式），模式变成了只影响识图 provider 的一个开关，名不副实
4. **违反单一职责**：一个下拉框覆盖另一个独立设置的值，用户在识图设置里改了 provider 后，切模式又给覆盖回去

## 改造方案

### 删除
- `run_mode` 配置项和 UI 控件
- `_on_run_mode_changed()` 方法
- `start_for_full_mode()` — 去掉"全能模式专属"概念

### 保留/拆分
- 识图 provider → 独立选择（已有）
- 语音 provider → 独立选择（已有）
- GPT-SoVITS 启动 → 改为"检测 voice.provider == gpt-sovits 时自动启动"，不跟模式挂钩

### 不改
- config.yaml 的 `behavior.run_mode` 可以用别的字段替代或直接废弃（向后兼容保留解析）
