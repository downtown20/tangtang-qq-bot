# 控制台 UI 质感升级方案（2026-09-05）

> 目标：**只加质感与过渡动画，不重构布局与交互**。布局框架（侧边导航 + 页面栈 + 卡片体系）经评审保留。
> 本文件是方案——实施前需主人审阅档位与范围。

---

## 一、现状诊断（本地取证）

控制台已有不错底子，粗糙感来自三件事：

| 现状 | 证据 | 后果 |
|---|---|---|
| **零动画** | `_navigate()` 直接 `setCurrentIndex`（[糖糖控制台_qt.py:703](../../糖糖控制台_qt.py#L703)）；全文件无 `QPropertyAnimation/QEasingCurve` | 页面硬切、hover 瞬变、状态卡数值跳色（[L4195](../../糖糖控制台_qt.py#L4195) 等 3 处 setStyleSheet 换色） |
| **无层次** | 卡片平铺无投影无描边分层；hover 仅换色 | 界面「平」，无浮起/焦点感 |
| **细节散乱** | 42 处内联 `setStyleSheet` 直写色值（`#555`、`#f0a060`…），绕过主题系统 | 主题换色不全、维护难 |

**已有资产（别推翻）**：完整「樱 noc」调色板常量（[L117-130](../../糖糖控制台_qt.py#L117)）、动态 QSS 生成器（[L135](../../糖糖控制台_qt.py#L135)，支持 accent/背景/字号/透明度配置）、侧边 navBtn checked 粉条指示、卡片圆角体系雏形。

**动画接入点高度集中**（改造可控）：页面切换 1 处、QSS 生成 1 处、状态卡更新 ~3 处、窗口初始化 1 处。

## 二、一个必须先破除的误区

**Qt QSS 没有时间概念**：`transition` / `animation` / `box-shadow` / `opacity` 渐变全不是 QSS 能力（QSS 只实现 CSS2.1 子集），写了会被静默忽略；`:hover` 只能瞬时切换。

→ 一切平滑过渡必须走 **Qt Animation Framework**（QPropertyAnimation / QVariantAnimation + QEasingCurve + 动画组）。QSS 只负责静态样式。这是方案地基。

## 三、调研结论（外部调研摘要，来源见文末）

1. **组件库性价比**：qfluentwidgets 是唯一真值得看的库（功能/文档断层第一），但侵入性高、官方建议钉 PySide6 6.7.2 避新版样式问题、GPLv3+商用付费——适合整框架采用或单页 pilot，**不适合向既有 QSS 应用渐进掺入**。qdarkstyle/qt-material 只是全局换肤且维护趋缓。**结论：不引第三方组件库，自研动画 helper。**
2. **性能纪律（决定成败）**：
   - `QGraphicsOpacityEffect`/`QGraphicsDropShadowEffect` 是**离屏 CPU 整块重绘**（实测可达每帧百毫秒级）→ 用后即删（`setGraphicsEffect(None)`）、同时存在 ≤2-3 个、不挂列表项
   - 动画期间避免逐帧重排版（几何动画是卡顿源）
   - 动画对象必须持引用防 GC 回收
3. **视觉范式抄 Win11 Fluent 而非 Material**：中文 Windows 运维工具与系统观感协调 —— 控件圆角 4px / 卡片与浮层 8px、暗色下**用 1px 描边 `rgba(255,255,255,0.06-0.08)` 代替阴影分层**、文字三级（90%/60%/45% 透明度）、控件高 32px、间距走 4 的倍数、微软雅黑 + 字号层级（12 辅助 / 14 正文 / 20 区块标题 / 28 大标题）。
4. **缓动选型**：位移/滑入 `OutCubic/OutQuad`；淡入淡出 `InOutQuad/Cubic`；**回避 Bounce/Elastic**（廉价玩具感）。时长：hover 100-200ms、页面切换 200-350ms、首屏入场 300-500ms。
5. **不做清单**（值与不值）：滚动视差 ✗（QWidget 视口重绘模型成本收益不成比）；列表常驻刷新动画 ✗（数据运维列表会成噪音，只做仪表盘首屏一次性入场 ✓）；卡片展开/折叠 ✓（设置页分组可用，动画中固定内容高度防逐帧重排）。

## 四、推荐路线：A 档（纯 QSS 令牌化 + 自研动画 helper）

### 分四批渐进实施，每批独立验证、可回滚

**批 1 — 设计令牌收敛与视觉打磨**（无动画，先立质感骨架）
- 调色板常量旁补 `RADIUS_CONTROL=4 / RADIUS_CARD=8 / CONTROL_H=32 / SPACING_4` 等令牌；QSS 引用令牌（已是动态生成，改造小）
- Fluent 化细节：控件圆角 4px、卡片 8px；卡片/侧边栏补 1px 高光描边（暗色分层替代阴影）；控件高 32px；文字三级透明度；间距 4 倍数
- 清 42 处内联色值中的高可见处（日志页 filter 等）→ 走令牌/QSS（低优先，随批处理）
- **验证**：截屏对比、换 accent 色/背景后视觉自检；新增测试 `tests/test_ui_theme_tokens.py` 断言令牌常量存在与 QSS 关键规则（圆角/描边）生成正确

**批 2 — 动画基础设施（新模块 agent/ui_anim.py，约 300-400 行）**
- `animate(widget, prop, end, ms, easing)`：持引用 + finished 清理的薄封装（QPropertyAnimation/QVariantAnimation 通用）
- `fade_in(widget, ms)`：QGraphicsOpacityEffect 淡入，**finished 后立即 setGraphicsEffect(None)**（守性能纪律）
- `slide_in / page transition` 辅助
- `hover_engine`：**全局事件过滤器**（enter/leave 跟踪 → 对注册过过渡规则的控件起颜色插值动画）——服务导航按钮、主按钮、卡片 hover；200 行内、只服务关键控件
- **验证**：`tests/test_ui_anim.py` 单测（动画启动/结束状态、effect 清理、hover 规则注册）

**批 3 — 页面切换与状态动效（用户可感知的大头）**
- 自研 `AnimatedStackedWidget`（子类 QStackedWidget，float 代理属性滑屏 200-300ms OutCubic；动画期间锁换页防中途切换）；或保守版：新页淡入 120-200ms（旧页瞬退，视觉也干净）
- 接入点唯一：`_navigate()` L703 替换为带动画版本
- 状态卡数值色变平滑（在线/离线/统计 3 处 setStyleSheet 换色点 → 颜色插值动画）
- 窗口启动 windowOpacity 0→1（250ms，走合成器无离屏代价）
- **验证**：手动切页/停启 bot 观察无残影无卡顿；`_navigate` 行为测试保持绿

**批 4 — 首屏入场微动效**
- 仪表盘状态卡首次入场：QSequentialAnimationGroup 按 index×30-50ms 交错淡入+上移 8px（一次性，刷新不重播）
- 主按钮按压反馈（`:pressed` 内容下移 1px，QSS 即可，不做动画）
- **验证**：首启体验观察；确认状态定时刷新（5s 周期 _refresh_stats）不触发重播

### B 档（可选 pilot，本期不做）
qfluentwidgets 单页验证观感：需先决策 PySide6 钉版本（官方建议 6.7.2）与 GPLv3 分发约束。A 档完成后如仍想要完整 Fluent 体验再评估。

## 五、风险与控制

| 风险 | 对策 |
|---|---|
| 动画卡顿（离屏 effect 滥用） | 性能纪律三铁律进 docstring；opacity 用后即删；单测断言清理 |
| 页面切换中途狂点 | 动画期间锁导航；finished 后解锁 |
| QSS 改动破坏既有布局 | 批 1 只改数值不动结构；每批后人工过 4 页 + 跑既有测试（动画只加不改行为，现 354+ 测试应全绿） |
| 与「发送链路/机器闸门」类契约无关 | 本方案不触碰 handler/memory 等核心链路，无跨模块风险 |
| 高分屏/重排版抖动 | Qt6 DIP 不手乘 DPR；动画中禁重排版（docstring 标注） |

**不做**（防蔓延）：滚动视差、弹跳缓动、列表常驻动画、换肤库、QML、重构设置页表单布局。
