## 三、基础层 = 黑白灰中性（CC Switch 明度微差层级公式）

深色与浅色各一套**中性 token**（不随配色变），配色只染 accent 系：

| token | 深色 | 浅色 | 说明 |
|---|---|---|---|
| 窗口底 | `#17171a` | `#f6f6f7` | 最底 |
| 侧栏 | `#101013` | `#ececee` | 最深/次浅 |
| 卡片 | `#1f1f23` | `#ffffff` | 高一档 |
| hover 底 | `#27272b` | `#f0f0f2` | 悬浮 |
| 边框 | `#333338` | `#e2e2e6` | 弱描边 |
| 主文字 | `#ececef` | `#1b1b1f` | 90% |
| 次文字 | `#a1a1aa` | `#565661` | 60% |
| 弱文字 | `#6b6b74` | `#8f8f98` | 45% |
| 成功/警告/危险 | 固定两套 | （不随配色） | 语义色 |

> 层级靠「明度微差 + 弱描边」而非对比边框（CC Switch 高级感核心）；日志/输入底色随层。

## 四、accent 派生（seed → 全量 accent 值，Python 色算即可，无需 M3）

每 seed 派生：`base`（原文）、`hover`（向白/黑混 12%）、`active`（混 20%）、`soft`（8-10% 透明底，深浅各自适配）、`on`（accent 上文字色：按亮度自动黑/白）。低饱和 seed（饱和度 ≤12%，如自定义灰）自动走「中性模式」不染色（Motrix content 规则）。

## 五、悬浮缩放与动效（CC Switch 参数落 PySide6）

- **圆形色卡 hover**：放大 1.15 并浮起——布局间距预留放大余量（不挤邻居）；选中态 2px 主色圆环 + 白 ✓
- **按钮/卡片 hover**：延续现有「边框染主色」+ 阴影近似（Qt 无 box-shadow，用 1px 高光描边已实现）
- **时长基准**：hover 过渡 100-150ms；即时取色反馈即时；不引入 Bounce（项目铁律）
- 减少动效尊重：`QStyleHints` 检测系统减弱动效设置（存在则跳过入场动画）

## 六、技术实施落点

1. **色板数据**：新建 `agent/theme_palettes.py`——`NEUTRAL[light/dark]` 两套 token 表 + `SCHEMES`（10 seed）+ `derive_accent(hex)`（hover/soft/on 派生 + 低饱和中性规则）——**单一事实源**，附单元测试（派生数学/低饱和分支）
2. **QSS 生成重构**：`_build_stylesheet` 从「读 appearance 逐色」改为「resolve 主题 → 完整色板 dict → 生成」，现有 QSS 模板内部变量名不动（PINK/CARD_BG 等改为从色板取，模板语法不变——改动面小）
3. **配置键**（config.yaml → appearance）：
   - `theme_mode: "dark"|"light"|"auto"`（新增，默认 dark 延续现观感）
   - `color_scheme: "rose_mist"|"amber"|…|"custom"`（默认 `rose_mist` 品牌雾玫瑰）
   - `custom_color: "#hex"`（默认 #e2a1bc）
   - 旧键（accent_color/main_bg_color/…/opacity 系）**标记废弃**，向后兼容：存在旧键且无新键时按旧键渲染（升级平滑）；保存时迁移
4. **UI**：`_build_appearance_section` 重构——主题下拉（含跟随系统，`QStyleHints.colorScheme` 侦测）+ 10 色卡行（QPushButton 圆形 QSS + 选中环/对勾，悬停放大+tooltip）+ 自定义行（QColorDialog 触发 + hex QLineEdit 校验，非法回退）+「更多」折叠（背景图/透明度保留为高级项）
5. **跟随系统**：`auto` 时启动读系统深浅 + `paletteChanged`/定时器监听系统切换实时刷新（Qt 无原生主题 change 信号——用 `QApplication.paletteChanged` 近似）
6. 测试：`tests/test_theme_palettes.py`（10 seed 派生不抛错、低饱和中性、两套中性完整）；契约测试保持绿
7. 发布构建：scrub_cfg appearance 替换为新键默认（theme_mode=dark + rose_mist）

## 七、决策点（请主人拍板）

1. **默认配色**：开箱默认 = 深色 + 雾玫瑰（延续现观感）？还是深色 + 岩石灰（纯黑白灰「高级工具感」）？
2. **10 套第 10 席**：玫红 `#F43F5E` 还是 Motrix 原樱花粉 `#EC4899`（与雾玫瑰同族偏甜）？
3. **旧外观项去留**：背景图/逐色透明度等旧控件收进「更多」折叠保留，还是直接删除（背景图功能保留代码但 UI 隐藏）？
4. **保存模型**：外观选择即时生效 + 保存按钮落盘（控制台现状风格）——还是外观项独立即存（Motrix 风格，改动即写 config）？
