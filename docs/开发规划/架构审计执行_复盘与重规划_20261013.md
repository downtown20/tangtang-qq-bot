### 2.4 哪条经验能改进当前规划（本轮提炼，全部来自实测）

1. **「效果必须自带观测点」**（源自 C4）。**凡改动行为参数，必须同时提交观测点（日志行或 DB 查询），否则不得记为完成。** 这是本轮最有价值的一条：R1 改了驱动力机制、R2 改了承诺写入端，两次都没有留下能证伪自己的观测。
2. **「检查器要查 AST，不要查文本」+「安全检查必须做阳性对照」**（教训 #30/#31、R1 F2、R3 全程实践）。推广为：**任何新闸门落地时必须同时给出阴性对照与阳性对照**，否则视为未完成。
3. **「测量方式本身可能是错的」**（教训 #1.1、R2 G6、R3 E1/E2）。推广为：**任何「0 次 / 全绿 / 零命中」结论都必须先做一次阳性对照**，证明该测量能报红。
4. **「先取证再动手」**（R3 全程）。推广为：**每个 Stage 的第一个任务必须是只读复现**。
5. **「跨机同步会污染生产判定」**（本轮 C1 新增）。推广为：**状态判定必须按机器来源区分**，口径写进文档。
