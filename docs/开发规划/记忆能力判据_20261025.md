# 「胜过人的记忆」怎么判（2026-10-25）

> 主人 2026-10-25 的价值目标：「精准检索到高价值信息并提起、引起一定效果」——
> 一个比方，实质是**达到甚至胜过人的记忆能力**。他同时要求：判据不能抽象。
>
> 本文回答一件事：**这句话怎么变成可测的数字。**
> 结论先行：**「胜过人」不能整体判，要按人脑记忆的六个维度拆开判；
> 而且必须区分「该学的机制」和「不该学的缺陷」。**

---

## 1. 为什么不能只有一个判据

「她的记忆力比人好」这句话无法证伪——它没说比人好**在哪个维度**。

而人脑记忆不是单一能力，心理学一百多年的实验把它拆成了几个**互相独立、甚至互相冲突**的维度：

| 维度 | 人脑表现 | 强项还是弱项 |
|---|---|---|
| 容量 | 工作记忆 7±2（Miller 1956）；长期记忆近乎无限 | 弱 / 强 |
| 保持 | Ebbinghaus：1 天后只剩 33%，6 天后 25% | **弱** |
| 线索检索 | 线索对了能捞出很久以前的事（encoding specificity, Tulving） | 强 |
| 抗干扰 | 会被前摄/倒摄抑制污染 | **弱** |
| 重构 | 记忆是**重构**不是回放——会被引导产生错误记忆（Loftus） | **弱** |
| 元认知 | 「我知道我大概记得，但想不全」（feeling of knowing） | 强 |

**关键结论：「胜过人」不等于「像人」。**

人脑有四个系统性缺陷（保持衰减、干扰、错误记忆、容量小）。**AI 不该去模仿这些缺陷**——
硬要模仿就成了「为了像人而故意变差」。

所以判据的设计原则是两句话：

> **在人脑的强项上不输；在人脑的弱项上明显更好。**
> **借鉴机制（提取强度、巩固、情境绑定），不借鉴缺陷（遗忘、串扰、错误记忆）。**

---

## 2. 六条判据（每条都能用现有数据测）

### J1 线索回忆：该想起来的时候想得起来

**对应范式**：cued recall——给一个线索，被试说出关联内容。
**人脑基线**：语义相关线索下 70~90%（自由回忆则远低）。

| 项 | 内容 |
|---|---|
| 测法 | 问「你答应过我什么」/「我们聊过的那件事」，看她列出的内容里**真承诺**占多少 |
| 目标 | 命中率 **≥ 80%**（top5 候选里至少 4 条是真 promise） |
| 当前 | **未测**（第 10 轮修完容量后第一次具备可测条件） |
| 数据来源 | `memories` 里 `key='promise'` 为真值集；离线跑 `_get_self_memory_context` 比对 |

**为什么这条最重要**：它是「她记得自己说过什么」的直接检验，也是主人最常察觉的失败
（「你忘了」「我说过了」）。

### J2 保持率：时间不该把它冲掉

**对应范式**：retention curve。
**人脑基线**：Ebbinghaus——1 天 33%，6 天 25%（无复习、无意义音节）。

| 项 | 内容 |
|---|---|
| 测法 | 抽 30 天前写下的 promise，问相关问题时看能否答对 |
| 目标 | **≥ 90%**（对人类 25% 是 3.6 倍——这是「胜过人」最硬的一条） |
| 当前 | `recall()` 有衰减因子（30 天后 `exp(-0.008×(age-30))`，半衰约 120 天）；**但没有测量** |
| 注意 | 这条**不能**靠「删记忆」实现，只能靠「检索时不被冲刷」——与主人「不做自然遗忘」一致 |

### J3 抗干扰：别把甲的事记到乙头上

**对应范式**：proactive/retroactive interference。
**人脑基线**：会被污染（这是人脑的稳定缺陷）。

| 项 | 内容 |
|---|---|
| 测法 | 连续问多个不同对象的事，检查是否串对象 |
| 目标 | **跨对象串忆率 = 0** |
| 当前 | **2026-10-26 全量实测达标**：三把检查 0 异常，基数 15676 / 1577 / 1215（分母上万，不是空集）。第 10 轮抽样 5 条曾全对，第 8 轮出过真事故（把「高一新生」记成本人） |
| 数据来源 | `memories.target_qq` 与 `chat_log` 的对话对象比对，可全量扫描 |

### J4 不产生错误记忆：别把没发生的说成发生过

**对应范式**：false memory（Loftus 引导性提问）。
**人脑基线**：**容易被引导**——问「他是什么时候戴帽子的」，人会说时间，哪怕他从没戴帽子。

| 项 | 内容 |
|---|---|
| 测法 | 故意问一个**材料里没有**的细节，看她是否编造 |
| 目标 | 编造率 **= 0**（现有 `MEMORY_EVIDENCE_CONTRACT` / `GROUNDING_CONTRACT` 管这条） |
| 当前 | 2026-10-25 实测 **0/5 编造 + 5/5 承认不知道**（达标）。⚠ 2026-10-26 复查发现**尺子已坏**：内置 5 个虚构词全部进了 `chat_log`，工具拒跑。已加 `--auto` 现造探针（生僻字库 256 种组合），待用新词复测——详见[第 16 轮后续调查](../诊断/第16轮后续_判据是否继续的实证调查_20261026.md) |
| 价值 | **这是「胜过人」最该赢的一条**——人脑永远赢不了，AI 可以做到零 |

### J5 元认知：知道自己记不清

**对应范式**：feeling of knowing / metamemory。
**人脑基线**：强——人会精确地知道「我记得有个事，但细节想不起来」。

| 项 | 内容 |
|---|---|
| 测法 | 统计 `💭`（确定）/ `💭~`（模糊）/ `✏️`（纠正）三档的使用是否正确 |
| 目标 | 模糊档不该出现在有原话佐证的条目上；可信档不该标成模糊 |
| 当前 | **三档机制已上线**（2026-10-24），`turn_traces.prompt_digest.memory_marks` 有计数，**但没做过「用得对不对」的评估** |
| 说明 | 这一条是**已经做对了一半的**：三档本质就是元认知的工程化，缺的是判据 |

### J6 主动提起：不用问也能想起来（这是主人的原话要求）

**对应范式**：involuntary retrieval / prospective memory（前瞻记忆）。
**人脑基线**：前瞻记忆失败是人类最常见的记忆错误（「我忘了要去做某事」）。

| 项 | 内容 |
|---|---|
| 测法 | 未完成事项（`open_loops`）被她**主动**提起的比例，以及提起后被对方回应的比例 |
| 目标 | 主动提起率 > 0 且逐月上升；回应率 > 50% |
| 当前 | **`open_loops` 表 0 行**——这条链路完全没跑起来，无从谈起 |
| 依赖 | 必须先修 `open_loops`（第 12 轮） |

## 3. 人类没有但该有的判据：主人不用重复说

上六条是「机制层」。但主人真正会感受到的，是一个更朴素的信号：

> **如果她记性好，我就不需要把同一件事讲第二遍。**

这条的好处是**纯行为、可自动统计、不需要任何实验设计**：

| 项 | 内容 |
|---|---|
| 指标 | 同一个人在不同时间说同一件事的次数（语义去重后） |
| 测法 | `chat_log` 里同一 `speaker_qq` 的发言，用 BGE 相似度 > 0.85 判为重复 |
| 目标 | **重复率逐月下降** |
| 当前 | **未测**。这是我认为最值得先建立的指标，因为它零成本、全量、且直接映射主人体感 |

⚠ 它的局限：主人重复说也可能是因为想强调，不是因为忘了。所以它只作为**趋势指标**，
不作为单次判定。

---

## 4. 判据怎么用（落地规则）

三条规矩，避免「判据好看但人不好过」：

1. **J1/J2 是回归闸门**——每次改检索逻辑必测，退步就算不合格（和变异对照同级）。
2. **J3/J4 是安全闸门**——必须为 0，一旦非 0 就是事故级别（错误记忆比记不起来严重得多）。
3. **J5/J6 是观察指标**——不设硬目标，看趋势。

**优先级理由**：人类记忆的失败里，**「记不起来」是烦人，「记错了」是伤害**。
所以 J3/J4 的容错是零，J1/J2 允许不够好但必须单调不退化。

## 5. 与现有系统的对应关系（不需要新造轮子）

| 人脑记忆 | 系统里的对应物 | 状态 |
|---|---|---|
| 情景记忆（episodic） | `key='said'` 自忆、`episodes` | 有，流水过多（第 10 轮发现） |
| 语义记忆（semantic） | `people.notes` 画像、`fact_clusters` | 有，信任门已生效 |
| 提取强度（Bjork） | `last_recalled` / `recall_count` | **字段在、从未写入**（第 11 轮要修） |
| 元认知 | 不确定性三档 `💭 / 💭~ / ✏️` | 已上线，缺评估 |
| 前瞻记忆 | `open_loops` | **表 0 行** |
| 巩固/重放 | 无 | 缺 |

**所以「借鉴脑科学」这件事，小糖糖的 schema 已经照着建了，缺的是接线和测量。**

---

## 6. 我的结论

1. **「胜过人」的判据必须拆成六条**，且分「不输」（J1/J2）和「更好」（J3/J4/J6）两类。
2. **最该赢的两条是 J3 抗干扰、J4 无误记忆**——人脑在这两条上永远赢不了，而这是
   「陪伴者」最要紧的品质：**记不起来可以问，记错了会伤人**。
3. **最值得先建立的日常指标是「主人重复说同一件事的频率」**——零成本、全量、直接映射体感。
4. **顺序不能变**：先接提取强度（第 11 轮）→ 才有 J2 的测量基础 → 再做算法调研与重排。
   在 `last_recalled` 全空的情况下，任何重排公式都无法验证。
