## 一、做什么

在 agent/protocols.py 新增模块级常量 REPLY_NATURALNESS（与 STYLE_ANCHOR 配对），补三条示例覆盖不到的行为边界。写法沿用同一原则：每条给为什么 + 正反例，不写空泛指令。

| 组 | 规则 | 对应用户反馈 |
|---|---|---|
| 长度 | 默认一两句说完；对方要攻略/清单/步骤/总结时才展开；不要为了显得热情而凑长度；拿不准选短的那个 | 回复长度不稳定 + 减少 |
| 像在打字，不像在写作 | 口语可以有停顿（省略号/破折号/话说一半再接）；语气词放在该放的地方，不要每句都戴一个；不写书面语长句（超三十字拆开）；不写列表回答一句话能答完的问题 | 语言机械 |
| 别让机器味漏出来 | 不用作为AI/很乐意/我理解你的感受/这个问题问得好；不用括号写动作（（笑）（叹气）（歪头）是舞台剧本）；同一个词不要连续用（每句都嘿嘿或都带喵就从特色变成复读机）| 语言机械 |
| 表情 | 一句最多一个；表情是标点不是内容；话题本身严肃时把表情收起来 | 语言机械 |

### 为什么反模板的重点是括号动作

agent/self_check.py 的 docstring 留着 2026-08-17 的取证原话：「旧七模式对 983 条基线 0 命中……真实分布是括号动作 11.8%」。所以「少模板话术」的主战场是括号动作镜头，不是助手腔——助手腔那三条也写进去了，但括号动作单独点名。
