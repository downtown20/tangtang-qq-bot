> 完成日：2026-10-14 ｜ 状态：**已完成**

## 一、先回答那个问题：**不能**，而且原因很确定

我本来想找一条「不重启就生效」的路——如果有，我这半天的验证阻塞就解除了。
查了 `/人格 重载` 的实现，结论是否定的，证据有两条：

1. **全项目没有任何一处 `importlib.reload`**（AST 扫 `agent/` + `onebot/`，见测试 `TestNoModuleReload`）。
   Python 一旦导入模块就缓存它，`reload_role_card()` 读到的 `_protocols` 是**进程启动那一刻**的版本。
2. `reload_role_card()` 只做三件事：重读 `role_card.md`、重读 `config.yaml` 的 personality 段、
   用**内存里已有的代码**重建提示词缓存（`_compose_base`）。

⇒ **`/人格 重载` 能应用数据文件改动，不能应用代码改动。**
本轮 bot 启动于 06:09:50，`protocols.py` 08:09 才改——所以 T15/T16 的常量在运行进程里**根本不存在**，重载也读不到。

**这个结论本身有价值**：它把「需要重启」从一句经验判断变成了可复现的机制结论。

## 二、顺带发现的缺陷：成功报告大于实际效果

`agent/handler_commands.py:202` 原来返回：

```
✅ 人格已从 role_card.md 重新加载～
```

**它会让人以为任何提示词改动至此都已生效。** 实际只重载两个数据文件。

### 这不是文字瑕疵，是一个会误导测量的陷阱

现场推演：操作者改了 `protocols.py` 的提示词 → 跑 `/人格 重载` → 看到 ✅ →
**然后去测行为，测的是旧提示词，却以为测的是新的。**

**这与 T10/T11/T12 是同一族**：报告的成功范围大于实际的生效范围。
只是那三条在工具里，这条在**对话命令**里——而对话命令更容易被随手当验证手段用。

## 三、改法（1 处，1 个文件）

```python
return (
    "✅ 已重载 role_card.md + config.yaml（数据文件）\n"
    "⚠️ 代码改动（protocols.py / personality.py）不在重载范围内——需重启才生效"
)
```

配套 `logger.info` 一条（重载是低频操作，留痕不吵）。

**写的是边界，不是免责声明**：现在这条消息回答「这次重载到底覆盖了什么」，
而这正是操作者需要知道的下一个动作（要不要重启）。

### 没做的

- **没实现「提示词热重载」**。技术上可以做（`importlib.reload(protocols)` 后重建缓存，
  模块对象的引用在 reload 后仍有效），但它是**运行时换代码**：
  并发读到一个执行到一半的模块是真实风险，而收益只是省一次重启。
  按 §0.1 B3（一次一件事）与「不为省一步引入新故障模式」，本轮不做，只把边界说清。
- **没改 `/人格` 的其他分支**（重设 / +追加 / 覆盖）——它们改的是内存里的 `config.core`，
  行为本身是自洽的，不在这条缺陷里。

## 五、踩坑：写测试时我自己撞上了 T2.2 那个自指陷阱

第一版两条测试**全部失败，而且是我自己的错**：

1. `test_old_unqualified_message_is_gone` 用**文本搜索**找旧消息——
   而我在 T24 的**注释里**正好引用了那句旧消息来解释为什么要改它；
2. `test_no_importlib_reload_in_production_code` 搜 `importlib.reload` 字符串——
   而我那条注释写的正是「全项目没有一处 importlib.reload」。

**这就是 T2.2 记录的那个陷阱：检查器匹配到了自己的说明文字。**

**修法**：两条都改用 **AST**——AST 天然不含注释，只看到真正的字符串常量与真正的调用。
改完立刻 6/6 通过。

### 改 AST 后又暴露第三个错（判据太宽）

`importlib.reload` 的 AST 判据我第一版写成「任何 `.reload()` 调用」，
结果 `agent/handler.py:13123` 的 **`manager.reload()`（场景重载）**被误报。
收紧为「接收者是 `Name(id='importlib')`」后通过。
**判据要精确指向被测物，不是指向近似形状**——与 T2.1 白名单那次「名字不是证据、定义行才是」同族。
