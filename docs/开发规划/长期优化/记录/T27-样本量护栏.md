## 二、修法：两件事

### 1. 样本量护栏 `min_side=10`

```python
def compare_dialog_quality(split_ts: str, days: int = 7, min_side: int = 10) -> dict:
```

| 情形 | 行为 |
|---|---|
| 两侧都 >= min_side | 给差值，**并同排印出噪声参考** |
| 两侧都 >0 但有一侧 < min_side | **不给差值**，`delta_skipped` 写明两侧样本数与门槛 |
| 某一侧为 0 | **不给差值**（T21 原有契约，保留）|

### 2. 噪声参考（标准误）

窗口里新增 `se`（标准误 = 样本标准差 / √n，无偏用 n-1）；
给差值时同排印 `delta_noise = √(se_before² + se_after²)`。

**这样小样本的差值一眼就能看出远小于噪声**，不必等谁来提醒。

```
  差值  : 均值 -128.8, ...
  噪声  : ±72.0（两侧标准误合成）样本充足（...）
```

**`n=1` 时 `se` 是 `None` 而不是 `0`** —— 0 会被读成「无噪声」，那是把未知说成确定。

## 五、M3 第一次没变红 —— 第四次遇到，这次是「断言测不出边界」

M3 变异是「把 `delta_noise` 写死成 `0.0`」。**第一次跑，23 条全绿。**

按纪律先查「变异是否打中目标」——打中了（源码确实改了）。
再查断言为什么测不出来，发现**是我的造数有缺陷**：

```
stub 用常数长度（before 全是 100，after 全是 60）
  ⇒ 真值标准差 = 0，真值 SE = 0，真值 delta_noise = 0
  ⇒ 断言 `delta_noise >= 0` 在「写死 0」时照样成立
```

**断言写成了「不小于 0」，而真值恰好就是 0 —— 这种断言对变异免疫。**

修法：给 stub 加 `spread=True`，造出**已知离散度**的样本
（80,84,…,116，n=10 → 均值 98，标准差 12.11，标准误 3.83），
然后**数值级断言**：`abs(se - 3.83) < 0.05`、`abs(delta_noise - 5.42) < 0.05`。M3 立刻变红。

**这是本轮第四次「变异不变红」**（T9 / T18 / T3.3 / T21 各一次），
而四次的原因各不相同却同一族：**变异没打中目标、或打中了但断言测不到那条边界。**
两次都指向同一个动作：**先证明变异真的改了被测行为，再看测试有效性。**
