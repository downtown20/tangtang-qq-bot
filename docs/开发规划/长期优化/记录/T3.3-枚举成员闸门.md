## 二、口径（T0.4 收敛过，不是「任意大写赋值」的粗口径）

```python
Enum 子类的成员  +  类体内的全大写 NAME = ... 赋值
```

- 只取 **agent/ 的类**，不含模块级常量（模块级归函数闸门那条线管）；
- **排除下划线前缀**（公共/私有划分与方法闸门一致：`_class_public_methods` 也是 `not name.startswith('_')`）。

**证据模型与方法闸门一致**：成员必须经 **属性访问**（`Class.MEMBER`、实例 `.MEMBER`）或 **字符串字面量** 到达；
**不吃裸名**——裸标识符 `FOO` 只可能指向模块级常量或局部变量，不可能指向 `SomeClass.FOO`（T2.3 的教训）。

## 五、两个真实缺陷 —— 都是测试/探针逼出来的

### 缺陷 1：`isupper()` 对 `_PRIVATE_CONST` 也返回 True

我最初写的扫描器是 `tgt.id.isupper()`——**下划线不影响大小写判断**，
所以 `_PRIVATE_CONST` 会被当成公共成员。我自己的阴性对照
`assert ('agent/__planted__.py', '_PRIVATE_CONST') not in found` **当场变红抓到了它**。

修法：显式加 `and not tgt.id.startswith('_')`，与方法闸门的公共/私有划分对齐。

### 缺陷 2：`isupper()` 的上界**没有任何测试覆盖**（变异逼出来的）

我的 M2 变异是「放宽 `isupper`（去掉大小写判断）」——**第一次跑，测试没红**。
按纪律先证明「变异是否真的打中目标」，发现：

```
原始 _class_upper_members:  60 个成员
放宽后:                     65 个成员  ← 多出 5 个
但零引用数:                 5 → 5    ← 没变！
```

多出来的 5 个是 **Qt 信号对象**：
`agent/color_panel.py` 的 `colorChanged`/`hueChanged`/`posChanged`、
`agent/ui_anim.py` 的 `transitionStarted`/`transitionFinished`。
它们都不是零引用，所以闸门本体**看不见**这个改动。

⇒ **`isupper()` 的存在意义（排除 Qt 信号）从来没有测试钉住。**
补 `test_lowercase_class_attrs_are_not_members` 后，M2 立刻变红。

**这条是本轮最有价值的方法论收获**：变异不变红时，先查「变异是否真打中目标」——
这次它打中了，但**被测行为没覆盖那条边界**，于是变异揭示了真实的覆盖缺口。
