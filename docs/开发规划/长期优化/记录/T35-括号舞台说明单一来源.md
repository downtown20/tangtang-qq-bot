## 二、这个缺陷为什么值得修：它是「像在表演」的唯一可见入口

用户最初的反馈原话是「说话不自然、**像在表演**」。
而括号舞台说明**被四处权威同时禁止**：

| 出处 | 原话 |
|---|---|
| `role_card.md` | 情绪自然融进话里，**不用舞台剧式动作描写** |
| `agent/protocols.py:430`（REPLY_NATURALNESS）| **不用括号写动作。**（笑）（叹气）（歪头）是舞台剧本，不是聊天——你的情绪融在字里 |
| `config.yaml:158`（T14 才让它生效的 26 条规则之一）| **用括号写动作**——（笑）（眨眼）（叹气）——**会让你的回复读起来像舞台剧本而不是聊天**。群友不会在微信里发「（笑了笑）今天天气真好」 |
| `scenarios/seductive.yaml:29`（**连亲密模式**）| 色色时沉浸投入不端着——写你身体真实的反应……**你是猫娘，不是旁白** |

**没有任何一个文件允许它。** 连亲密模式的措辞（「不是旁白」）也是明确反旁白的。

⇒ 所以这不是「要不要改」的判断问题，**是项目已经做了决定、而没有任何机制执行它**。
而这个「没有机制」的原因就是上面那两个过窄且漂移的词表——**它让这个问题在遥测里近乎不可见**。

## 三、改什么（2 个文件，B2 ✅）

### 1. `agent/self_check.py`：建立**唯一定义**

```python
    STAGE_DIRECTION_RE = re.compile(
        r'（[^）]{0,30}(?:'
        r'耳朵|尾巴|猫耳|爪子|眼睛|眼神|眼角|眉毛|睫毛|鼻子|嘴角|嘴唇|舌头|'
        r'脖子|肩膀|腰|腿|脚|手指|手臂|指尖|头发|脑袋|脸|身体|胸口|呼吸|'
        r'笑|叹气|眨眼|歪头|摇头|点头|晃|抖|僵住|咬|舔|蹭|拍|揉|缩|闭眼|'
        r'抿|皱眉|呼噜|炸毛'
        r')[^）]{0,30}）'
    )
```

**判据**：括号较短（≤30 字）**且**含身体部位或表情/动作词 → 判为舞台说明。
纯命题式旁白（`（其实我昨天就知道了）`、`（明天下午三点）`）不含这些词 → 不误判。

**词表的两次调整（如实记录）**：
- 第一版我放了 52 个词，含 `挑`/`顿`/`扯`/`扬`/`抱` 等**单字近义词**；
  实测抓到一个假阳性 `（校服真没得挑这点我认…）`——`没得挑` 命中了 `挑`。
- 于是删掉最易混淆的 5 个字（`挑`/`顿`/`扯`/`扬`/`抱`——`抱` 会命中 `抱怨`）。
  实测 5.56% → **4.88%**，假阳性消失。

**为什么宁可宽**：这是**诊断口径**（只记 warning、不阻断）。
放宽的代价只是一条警告；漏报的代价是这类问题继续无人可见——**它已经藏了两个月**。

### 2. `agent/handler.py`：采集侧指向同一处

```python
bracket_action=len(
    self.self_check.STAGE_DIRECTION_RE.findall(committed_reply)),
```

两处不再各写一份词表。已加**单一来源闸门**测试钉住。

**本任务不改行为**：判定只产出 warning（`result.warnings`），采集只写遥测列。
**没有把警告升级为阻断**——那是行为改动（会改变她的声音），需要主人拍板。

## 六、变异脚本又栽在「把文件改坏」上（**同一天第三次**）

本轮变异脚本**连续三次**失败，全部是**构造替换文本时的引号/括号错误**，
而不是被测行为的问题：

1. 内层单引号没转义 → `SyntaxError: unmatched ')'`；
2. 替换块重复带上了收尾的 `    )` → `SyntaxError: unmatched ')'`；
3. 替换文本多加了一个 `len(`（外层已经开着）→ `SyntaxError: '(' was never closed`。

**每一次都表现为「跑出红」，但那是 collection error，不是断言失败。**

最终解法（值得固化为纪律）：

- **变异尽量用纯 ASCII 构造**（M1 直接换成 `re.compile("ZZZ_NEVER_MATCHES")`）；
- **需要旧文本时从锚点文件提取，不手打**（M2 的旧内联词表就是从 `.bak-20261014-T35` 读出来的）；
- **每个变异写盘前先 `ast.parse()`**，语法不合法就当场停下。

这与本轮第五次「假红」同源：**文件坏了不等于行为变了。**
