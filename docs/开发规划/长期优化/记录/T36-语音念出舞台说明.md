## 一、问题

`agent/voice.py:140` 与 `agent/handler.py:10995`（**同一个规则的两份拷贝**）都写：

```python
t = re.sub(r'（[^）]{1,15}）', '', t)   # 只处理 15 字以内的括号
```

`voice.py` 那段注释自己写着「（笑）（眨眼）= **会干扰朗读，所有 TTS 都去掉**」——
**意图是对的，上界太窄**。

| ≤15 字（会被剥掉）| **38（69.1%）** |

**受影响整条回复：15 / 882 条。** 会被 TTS 逐字朗读的样本：

```
（帽子拉下来盖住半张脸，从缝里瞥你一眼）
（整个人往后一缩，帽子直接拉下来把脸埋进去）

（把枕头扔回床头，帽檐还压着眼睛不肯露脸）
（帽子扣在头上，坐在床边晃着腿，看你半天不说话）
```

**与 T35 是同一个毛病**：这个界是拍出来的，**没量过真实的括号内部长度**。

---

## 三、修法（2 个文件，各改 1 个数字）

`{1,15}` → `{1,30}`（实测最大 23 字，留余量）。

**修复后实测：>30 字的括号剩 0 处** —— 不会再有任何旁白被念出来。

**代价（如实记录）**：16–30 字区间的括号会被一并剥掉，其中包含少数**真旁白**（例如
`（如果图里是什么会让你更难受的东西，先别自己一个人盯着看。）`）。
文字路径不受影响（`clean()` 不剥括号），只有语音朗读版本会少一句。
**取舍依据**：漏读 17 处「像是旁白」的舞台说明 vs 少读 2–3 处真旁白——
**前者是当场穿帮，后者只是少一句**。

## 四、本轮最有价值的部分：**证伪了自己上一轮的结论**

做这次测量时顺带发现 **T35 的检测词表有盲点**。
当时被 T35 判成「非舞台说明」的这批，看内容**明显是**舞台说明：

```
（重新坐回去，声音低下来，带点不自在地清了清嗓子）
（帽子一掀，凑过去盯着屏幕看了半天，最后叹了口气）
（帽檐往下一压，链锯在手里转了半圈，咔地一声停了）
```

**两个具体原因**：

1. **中文会插字**：词表里有 `叹气`，但真实写法是 **`叹了口气`** ——
   `叹` 与 `气` **不连续，匹配失败**。（同类：`看了看`、`坐了下来`）
2. **词表漏了常用动作**：`坐`、`凑`、`盯`、`掀`、`压`、`清嗓` 都不在表里。

⇒ **T35 报的 4.88% 本身也是低估**，真实值更高。

**没有顺手改词表**——那需要把「插字形式」单独处理并重新量一遍分布，
而本轮已经改了 2 个生产文件。**如实记下、登记为 T37**，比改一半然后声称修好要诚实。
