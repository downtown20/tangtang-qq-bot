# T38 · CQ 正则重复审计 —— **结论是不修**（有价值的否定结果）

> 完成日：2026-10-14 ｜ 状态：**已核查，结论：不修** ｜ 0 代码改动

---

## 一、起因

T36 顺带写的重复扫描器扫出 **31 组重复正则**，其中 `\[CQ:[^\]]+\]` 出现在 **17 处、跨 3 个文件**。
这是 T10（两个发布扫描器）/ T12（两处可用性判据）/ T25（clean 两份字符类）/ T35（舞台说明两份词表）
**同一个形状的候补** —— 那四次全是真的，所以这次值得查。

---

## 二、查了什么

AST 扫 `agent/` + `onebot/` + `main.py` 里所有**含 `CQ:` 的字符串常量**，按形态分组：

| 形态 | 处数 | 备注 |
|---|---|---|
| `\[CQ:[^\]]+\]` | **17** | 3 文件 |
| `[CQ:image,file=file:///` | 10 | 字面量前缀 |
| `[CQ:at,qq=` | 9 | 4 文件 |
| `\[CQ:image[^\]]*url=([^,\]]+)` | 8 | |
| `\[CQ:image[^\]]*file=([^,\]]+)` | 8 | |
| `\[CQ:[^\]]*\]` | 5 | 4 文件 |
| `\[CQ:at,qq=(\d+)\]` | 4 | |
| …另外 20 余种各 1–3 处 | | |

**共 30 余种写法。**

---

## 三、唯一的真语义分歧：`+` vs `*`

```python
A = re.compile(r'\[CQ:[^\]]+\]')   # 17 处用这个（+，至少 1 字符）
B = re.compile(r'\[CQ:[^\]]*\]')   # 5 处用这个（*，允许 0 字符）
```

| 输入 | A(`+`) | B(`*`) | |
|---|---|---|---|
| `[CQ:]` | False | **True** | **分歧** |
| `[CQ:at,qq=1]` | True | True | 同 |
| `[CQ:image,file=x]` | True | True | 同 |

⇒ **只有「空的 `[CQ:]`」能区分两者。**

## 四、实测量级：**这个分歧从不发生**

| 数据源 | `[CQ:]` 出现次数 | 参照 |
|---|---|---|
| `tangtang.log` | **0** | `[CQ:` 共 **0**（日志里根本没有）|
| `memory.db` `chat_log` | **0** | 含 `[CQ:` 的行 **12619** |

**⇒ 12619 行含 CQ 码的历史里，空 `[CQ:]` 一次都没出现过。**

**结论：这是可维护性债务，不是活缺陷。**

---

## 五、为什么不修（这是本轮的主要产出）

1. **没有可观测的收益**：修了它，12619 行历史里 0 行行为改变，用户侧 0 变化。
2. **代价与风险极高**：`CQ:` 处理是**消息主干**（收发、引用、图片、语音、@、文件、撤回），
   30 余种写法散在 5 个文件；统一它们要动 `handler.py`（735 KB）多轮，
   **远超 B2「每任务 ≤3 个文件」**，而回归面是**全部消息路径**。
3. **本项目自己的纪律**：§0.1 B5「只做北极星工作」——用户的目标是「回复自然、接近真人私聊」，
   CQ 正则统一对那个目标**零贡献**。

**这个否定结果本身有价值**：它挡住了对消息主干做一次大重构的冲动，
而那次重构的风险远大于收益。**查过、量过、然后决定不动，是结论，不是偷懒。**
