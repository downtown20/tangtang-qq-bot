## 三、X5（观测缺口 / RC5）核查：**点名的实例已闭环**

审计把 X5 归因到 **C3**——「`_apply_mood_report` 只在标签非空时记日志；她没写标记时静默 return False → 「0 次」无法区分「闸门没开」与「开了但她没写」」。
这是 RC5（失败路径不产生可观测事实）的又一次复发。

**实测：T1.2 已把这件事补上，分子分母都在。**

| 位置 | 日志 | 角色 |
|---|---|---|
| `handler.py:4021` | `🌡 心情自报协议已注入: 群-%s` | **分母**（群）|
| `handler.py:5118` | `🌡 心情自报协议已注入: 私聊-%s` | **分母**（私）|
| `handler.py:12382` | `💓 心情自报未写（协议已注入但她没写）` | 分子=0 的可证形态 |
| `handler.py:12386` | `💓 忽略白名单外的心情自报` | 无效自报 |
| `handler.py:12390` | `💓 心情自报 %s 无引擎可回灌` | 引擎缺失 |
| `handler.py:12392` | `💓 心情自报回灌: %s → %s` | **分子**（真遵从）|

**关键设计**（代码注释自己写明）：`心情自报未写` 只在 `injected=True` 时记——
否则每个成功回复都会多一行「她没自报」，那是纯噪声；**闸门没开这件事由注入日志的缺席直接可判**。

### 这个核查直接解释 T4.5 的 FAIL

T4.5 的判据是「注入回合数 / 实际回灌数」。**分母的观测点存在**（4021/5118），
但生产 15 天里**一次都没打印过**——因为闸门要求「对方在她上一条之后 60s/120s 内接着回」，
这个窗口从未满足。⇒ 与 T4.7 的结论完全一致：**问题不在观测缺失，而在分母结构性恒 0。**
