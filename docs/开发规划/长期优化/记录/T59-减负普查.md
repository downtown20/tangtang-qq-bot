## 0. 一句话

系统替她做的决定，**绝大多数不是「执行」而是「判断」**：判断这张图是什么、判断这条消息什么情绪、
判断她该记得什么、判断这一轮该给她看多少材料、判断她要不要点赞/戳人/插话。
其中 **发送、归账、持久化、权限** 四类必须留在系统侧（§2）；其余 **语义判断类** 都可以收回给她——
而且大部分**工具已经在手边**（`analyze_image` / `search_memories` / `search_knowledge` / `search_facts` / `send_stickers` …），
缺的只是「系统别再替她先做一遍」。
