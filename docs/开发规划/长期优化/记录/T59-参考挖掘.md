## 一、消息单元 / 多模态聚合与去重

### M1 · 触发单元 ≠ 消息单元（时间维度的折叠）  ✅ **已借鉴（且糖糖更强）**
- **出处**：`N/nekro_agent/services/message_service.py:113-169`；配置 `N/nekro_agent/core/config.py:1174-1177`（`AI_DEBOUNCE_WAIT_SECONDS = 0.9`，"防抖等待时长中继续收到的消息只会触发最后一条"）

- **本项目落点**：糖糖同族实现见 §0（`message_batcher.py`，2s 批窗 + 1.5s @防抖）。**缺口不在时间维度**：`batcher` 只聚合**窗口内**的消息，窗口外到达的纯媒体（如"文字已被回复 → 120s 后再发一张图"）仍自成一次发言（`T59-识图与消息身份.md:11-15`，18/18 复现第二次回复）。→ 落点 = T59 P0-① 的**媒体维度**发言单元（同发送者 + 纯媒体 + `MEDIA_ATTACH_WINDOW_S`，`agent/protocols.py:173` 已见落地）。
  **不要抄 debounce 本身**：`CLAUDE.md §六` 群聊窗口契约禁止按时间/长度/随机做二次门控。

## 四、图片 / 表情包语义判定的分工

### M15 · 适配器只标平台事实，语义交给视觉模型
