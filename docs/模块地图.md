# 小糖糖模块地图

这是一张给接手者的代码地图。`agent/` 当前有 74 个业务模块（不含包初始化文件）；下面按职责分为七层。建议从入口层的 `handler.py` 开始，再按一次消息经过的模块向下阅读。

## 1. 入口、路由与发送边界

- `handler.py` — 消息处理总枢纽，协调入站消息、上下文、LLM 回合、工具与发送。
- `handler_commands.py` — 将精确 `/命令` 从主处理器拆出的命令路由器。
- `inbound_event.py` — 规范化入站事件及其幂等键、原始内容和分段事实。
- `interaction_contract.py` — 定义入站事件、LLM 回合和主动事件之间的不可变交互事实。
- `message_batcher.py` — 在短窗口内聚合连续或并发消息，减少重复生成。
- `action_contract.py` — 定义动作请求、结果和身份校验的纯数据契约。
- `action_plan.py` — 冻结一个回合及其有序子动作的计划数据。
- `action_executor.py` — 按顺序执行子动作、校验回执并隔离单项失败。
- `send_actions.py` — 统一文本、转述和自然改写等外部发送动作及回执。
- `platform_receipts.py` — 校验平台送达回执，避免把请求成功误当作已送达。

## 2. 对话决策、人格与上下文

- `personality.py` — 加载角色卡和配置兜底，构建基础人格提示。
- `protocols.py` — 集中维护困难对话、上下文来源标记等行为协议。
- `scenario.py` — 为群或对象加载替换型、叠加型对话场景。
- `context_builder.py` — 在 Token 预算内投影持久状态和当前相关背景。
- `conversation_tracker.py` — 管理对话窗口、旁观、退让、语气和跨窗口摘要。
- `mood.py` — 维护可持久化的精力、心情与耐心状态。
- `mood_tracker.py` — 跟踪特定对象的情绪趋势并在异常时通知调用方。
- `reply_pipeline.py` — 清洗模型输出，处理贴图、@、分句与发送前加工。
- `self_check.py` — 在发送前执行规则化质量检查并记录结果。

## 3. 记忆、关系与持续状态

- `store.py` — SQLite 的唯一数据访问层，管理项目持久数据。
- `memory.py` — 负责短期与长期记忆的提取、召回、合成和生命周期处理。
- `memory_access.py` — 以纯策略控制不同会话可读取的记忆与聊天范围。
- `relationship.py` — 定期合成“我们之间”的关系档案并供上下文使用。
- `self_state.py` — 保存关系场、自我叙事、价值倾向和体验缓冲等持续状态。
- `reflection.py` — 在后台整理互动，生成摘要、日记和状态更新。
- `perception.py` — 评估回复后的反馈倾向，为关系和反思提供信号。
- `personalization.py` — 根据已保存的信息提供生日祝福与个人偏好能力。
- `knowledge.py` — 加载知识文档、切块并提供面向对话的检索。
- `knowledge_index.py` — 保存知识文档、分块和可选向量的 SQLite 索引元数据。
- `embeddings.py` — 加载 BGE 中文语义向量模型并提供编码能力。
- `reranker.py` — 用 Cross-Encoder 对初步检索结果进行精排，并支持降级。
- `extraction_policy.py` — 统一决定记忆提取任务的数量与时间准入条件。
- `extraction_telemetry.py` — 记录记忆提取任务各阶段的指标和结构化日志。
- `metrics.py` — 轻量收集记忆与运行健康指标，并异步落库。
- `group_style.py` — 统计群聊表达特征并周期性总结群内话题。

## 4. 自治、时间与主动互动

- `handler_autonomy.py` — 作为 Mixin 提供主动发起、冷场处理与自治循环。
- `drives.py` — 维护会随时间积累、竞争并通过行动释放的内在驱动力。
- `interjection.py` — 在群聊窗口外评估合适的主动搭话机会。
- `proactive_decision.py` — 记录主动事件的 LLM 决策结果，衔接状态机与持久化。
- `scheduler.py` — 提供一次性和周期性日程调度及 JSON 持久化。
- `tasks.py` — 保存并执行重启后仍有效的提醒与延迟消息任务。
- `daily_report.py` — 定时汇总群聊活跃数据并生成每日播报。
- `album_patrol.py` — 实现群相册点赞相关的批量互动任务。
- `catch_up.py` — 在重启或掉线后补读错过的群聊消息并形成摘要。
- `health_check.py` — 检查运行组件是否真正产出预期结果，并输出可读诊断。
- `opinion.py` — 管理由主人发起的意见征集、私聊邀请与回复收集流程。

## 5. 能力与工具模块

- `skills.py` — 注册工具函数并生成供 LLM 使用的原生 Tool Calling 定义。
- `calculator.py` — 提供精确数学计算工具。
- `convert.py` — 提供温度、距离、重量、面积、体积和货币等单位换算。
- `sensory.py` — 提供时间、日期和天气查询能力。
- `web_search.py` — 提供联网搜索能力。
- `translate.py` — 提供多语言翻译能力。
- `file_reader.py` — 从文本、Markdown、Office、PDF、CSV 和 JSON 文件中提取文本。
- `games.py` — 提供猜数字、抽签等群聊互动小游戏。
- `image_gen.py` — 接入图片生成服务，供模型按需调用。
- `image_share.py` — 定时检索并分享图片到群聊。
- `sticker.py` — 维护本地表情包与情绪标签索引，并按情绪选择素材。
- `vision_router.py` — 在本地和云端图片理解后端之间路由并降级。
- `vision_local.py` — 通过本地服务调用 MiniCPM-V 图片理解能力。
- `asr.py` — 下载、转码并识别 QQ 语音消息。
- `voice.py` — 处理文本预处理、分句、音色和缓存等语音合成流程。
- `cosy_voice.py` — 调用本地 CosyVoice3 语音服务的轻量客户端。
- `songs.py` — 管理歌曲歌词段落、查询和预录音频播放。
- `diff_singer.py` — 封装历史歌声合成 REST 接口；发布版本不将其作为主仓能力承诺。

## 6. 运行时基础设施

- `async_io.py` — 用有界线程池适配同步 I/O，避免阻塞事件循环或无限排队。
- `model_lock.py` — 串行化 Transformer 模型加载，避免并发加载产生不完整权重。
- `paths.py` — 集中处理跨机器可移植的项目路径。
- `service_manager.py` — 管理本地语音等外部服务的启动与停止。
- `telemetry.py` — 提供跨异步任务的关联 ID、日志格式和轻量上下文。
- `text_utils.py` — 提供适合中文边界的文本匹配工具。

### 控制台 UI 基建（被 `糖糖控制台_qt.py` 使用，不在消息链路上）

- `theme_palettes.py` — 外观主题色板的单一事实源：黑白灰中性层 + 10 套配色方案，中性层不染色、配色只染 accent。
- `icons.py` — lucide 线性图标工厂：运行时给 SVG 染色再渲染成 QIcon，按 (名称, 颜色, 尺寸) 缓存。
- `ui_anim.py` — Qt 动画小工具集。铁律：Qt QSS 没有时间概念（transition/animation/box-shadow 全部静默失效），一切平滑过渡走 Qt Animation Framework。
- `color_panel.py` — 现代取色面板（HSV 色板 + 白环指示），供外观设置的自定义配色使用。

## 7. 协议适配、脚本与测试

- `onebot/ws_client.py` — SnowLuma / OneBot 11 反向 WebSocket 与 HTTP API 适配器，负责事件接收、会话队列和消息发送。
- `onebot/__init__.py` — 协议适配包初始化文件。
- `tools/` — 按用途收纳安装配置、运行诊断、记忆维护与迁移、语音/素材准备、质量评测和发布辅助脚本；执行前请先阅读各脚本说明和参数。
- `tests/` — pytest 测试套件，覆盖核心模块行为、持久化、协议适配和跨模块契约；测试文件按被测能力命名。

## 推荐阅读路径

`main.py` → `onebot/ws_client.py` → `agent/handler.py` → `agent/conversation_tracker.py` / `agent/context_builder.py` → `agent/personality.py` → `agent/memory.py` / `agent/store.py` → `agent/reply_pipeline.py`。

需要理解“糖糖为何会主动说话”时，再沿 `handler_autonomy.py`、`drives.py`、`interjection.py` 阅读；需要扩展模型能力时，从 `skills.py` 和对应工具模块进入。
