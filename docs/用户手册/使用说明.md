# 🍬 小糖糖 使用说明书

> QQ 群智能体 · 猫娘少女 · AI 驱动。适合新手，看完就能上手操作。

---

## 一、快速开始

### 1. 安装

新机器（笔记本 / 换机）用**统一安装向导**——双击 `安装糖糖.bat`（或 `tools/安装糖糖.py`，同一程序两个入口）：

```
🍬 小糖糖 安装/维护工具
  1. 安装依赖 — 功能选择安装（含环境/目录检测、配置调整）
  2. 打包记忆 — 跑完糖糖后导出最新记忆快照（换机前）
  3. 解包记忆 — 启动糖糖前应用另一台机器的快照
  4. 打包项目 — 生成部署 zip（给自己笔记本用，按功能瘦身）
  5. 发布项目 — 清理个人数据后生成分享文件夹（发给别人）
  6. 检查状态 — 环境 + 快照总览
  7. 体检 — 换机功能对比（❌=缺失 ⚠=留意，两台机器各跑一遍对照）
```

选「1 安装依赖」→ 按需勾选功能（聊天+记忆 / 语音 / 识图 / 唱歌 / 读文档 / 控制台），依赖按功能分组安装——**不装的组只会让对应功能不可用，不会崩**。也可以直接装全部：

```bash
pip install -r requirements.txt
```

> 识图和语音**按需独立配置**（不再绑定"全能/简约"模式）：
> - 👁 **识图方式**：`local`（本地 MiniCPM-V）/ `api`（云端千问 VL）——选中的优先，另一个自动兜底
> - 🎤 **语音引擎**：GPT-SoVITS（固定；CosyVoice 已收敛移除）

> ⚠ **语音依赖 MSVC 前置**（2026-09-05）：GPT-SoVITS 分词加速 `jieba-fast` 在 Windows 常需源码编译——先装 VS2022 Build Tools（C++ 桌面开发工作负载，含 Windows SDK），装完**重开终端**再装依赖。没有 MSVC 也能跑：启动器自动回退纯 Python `jieba`（较慢但可用）。安装向导会检测 `cl.exe` 并提示。

### 2. 配置

双击 `启动控制台.bat` → 控制台 → **设置页**：
- 🤖 机器人 → 填入机器人 QQ 号和你的 QQ 号
- 🧠 AI模型 → 填入 DeepSeek 或 Claude 的 API Key
- 👥 群管理 → 添加你的群号

点「💾 保存设置」。不用手动编辑 config.yaml，控制台里就能填。

### 3. 启动 SnowLuma

仪表盘 → 点「启动 SnowLuma」→ 在弹出的 QQ 窗口中登录机器人 QQ。

登录后进入 QQ 设置 → WeUI → 配置反向 WebSocket：`ws://127.0.0.1:3001`，HTTP：`http://127.0.0.1:3000`。首次使用也可运行 `python tools/配置SnowLuma.py` 自动配置。

### 4. 启动糖糖

SnowLuma 在线后 → 点「🍬 启动小糖糖」→ 等待日志显示「小糖糖已上线」。

```bash
# 方式一：命令行
python 糖糖控制台_qt.py

# 方式二：双击
启动控制台.bat
```

打开后看到四个标签页：**仪表盘、设置、图库、日志**。

## 二、仪表盘 — 启动和监控

### 启动流程

```
1. 点「启动 SnowLuma」→ QQ 登录窗口弹出 → 登录机器人 QQ
2. QQ 设置 → WeUI → 配置反向 WS 和 HTTP 地址
3. 等状态变为「✅ SnowLuma 在线」
3. 点「🍬 启动小糖糖」→ 日志开始滚动
4. 看到「小糖糖已上线」→ 糖糖上线 ✅
```

### 控制按钮

| 按钮 | 作用 |
|------|------|
| 启动 SnowLuma | 启动 QQ 协议客户端，弹出窗口登录 |
| 🍬 启动小糖糖 | 启动 AI 机器人 |
| ⏹ 停止 | 停止糖糖进程，自动向活跃群发离线通知 |
| 🔄 重启 | 先停止再启动 |
| 🌙 后台静默运行 | 关闭窗口时最小化到托盘 |

> 🕐 **每天 6:00 自动重启**：糖糖退出后控制台会自动拉起新进程（防内存泄漏，无需手动操作）。任何方式停止糖糖时，控制台还会**自动打包记忆快照**（数据没变化时跳过），换机前无需手动导出。

### 状态指示

| 状态 | 含义 |
|------|------|
| 🟢 在线 | SnowLuma + QQ 正常 |
| 🟠 QQ 离线 | QQ 掉线但 SnowLuma 还在（心跳检测到连续失败） |
| 🔴 异常 | 糖糖进程崩溃 |
| ● 离线 | 糖糖未启动 |

### 统计卡片

顶部四张卡片显示实时数据：**群友数、记忆数、聊天数、表情包数**。

点击任意卡片展开数据浏览面板：

| 卡片 | 展开后能看什么 |
|------|-------------|
| 👥 群友 | 所有群友的 QQ、昵称、亲密度、发言数，支持搜索 |
| 🧠 记忆 | 糖糖记住的所有事，支持搜索 |
| 💬 聊天 | 最近的聊天记录 |
| 🖼 表情包 | 表情包总数，点「🏷 重打标签」扫描新表情 |

### 诊断

点「🔍 诊断」自动分析日志和数据库，检测常见问题（测试模式未关、API 失败率高等）。

## 三、设置 — 修改配置

左侧 15 个分类，点任意一个切换。每个字段下面都有灰色说明文字。

### 必须配置的

| 分类 | 关键字段 | 说明 |
|------|---------|------|
| 🤖 机器人 | QQ号、主人QQ | 糖糖的 QQ 号和你的 QQ 号 |
| 🧠 AI | API Key | **必填**，否则糖糖不会说话 |
| 🧠 记忆 | 自动 | 糖糖会自动记住群友说过的事，越聊越了解你 |
| 👁 识图 | 识图方式 + API Key | 想让糖糖看懂图片就要填（local=本地MiniCPM-V | api=云端千问VL，选中的优先、另一个自动兜底） |
| 👥 群管理 | 添加群 | 只有这里列的群糖糖才会回复 |

### 行为调整

| 字段 | 作用 | 建议值 |
|------|------|--------|
| 仅回复这些人 | 白名单模式，留空=回复所有人 | 一行一个 QQ 号 |
| 主动插话 | 糖糖会在群聊中主动参与对话 | 开启 |
| 插话饥渴度 | 0=沉默 1=话痨。基于客观信号（提问/消息长度/亲密度/随机），不用关键词 | 0.4-0.8 |
| 插话冷却 | 两次插话最少间隔秒数 | 60-300 |
| 测试模式 | **只回复主人**，其他人消息跳过 LLM 不消耗 token | 正常使用请关闭 |

> 🆕 插话不再用关键词打分——糖糖是否接话只取决于：有没有人提问、消息长度、亲密度、是否主人、随机心情。LLM 自己判断内容是否值得回应。

### 群场景配置

在群管理编辑框中可以为每个群设置糖糖的角色：

| 场景 | 类型 | 说明 |
|------|------|------|
| 💬 日常闲聊 | 默认 | 完整的猫娘人格 |
| 🧠 心理陪伴 | 叠加 | 猫娘人格 + 敏感度提示，不追问、正常聊=陪伴 |
| 📋 活动管理者 | 替换 | 裁剪猫娘撒娇，专注活动策划与通知 |

**精准指定**：可以在「场景目标用户」中按 QQ 号单独设置场景（如只对某个人启用心理陪伴模式）。

私聊场景在群管理区域下方的「私聊场景目标用户」中设置。

> 📖 场景系统详细设计见 `docs/开发规划/ROADMAP.md`

### 图片分享

| 字段 | 作用 | 建议值 |
|------|------|--------|
| 启用分享 | 定时发图开关 | 开启 |
| 间隔(分钟) | 多久发一张 | 60-240 |
| 每日上限 | 防止刷屏 | 6-20 |
| 仅本地图库 | 只发自己上传的图 | 开启 |
| 播放模式 | random=随机 sequential=按顺序 | sequential |
| 播放分类 | 只播某个文件夹 | 留空=全部 |

### 外观定制 (🎨)

在设置页最下面。

- **字体大小**：9-24，改完全局生效
- **颜色**：8 种颜色可分别调。点色块弹出取色器，带透明度滑条
- **背景图**：选本地图片做窗口背景，有不透明度滑条
- **使用方法**：调完参数 → 点「👁 实时预览」看效果 → 满意了点「💾 保存设置」

### 🎤 语音 — 文字转语音 & 角色声音

> 2026-07-29 更新：双模式语音方案

**语音引擎**（设置 → 语音 → 语音引擎，按需选择）：

| 引擎 | 音色 | 角色切换 | 适用 |
|------|------|---------|------|
| gpt-sovits | 糖糖、丛雨（日语）、米雪儿 三种角色音 | ✅ 支持 | 本地推理，需 GPU |
| cosyvoice | CosyVoice 本地 TTS | 按注册音色 | 本地推理 |
| edge-tts | 糖糖单一温柔女声 | ❌ 不支持 | 微软免费云端，零依赖 |

**本地引擎三种音色（独立角色卡）**：

| 角色 | 语言 | 声音特点 | 切换方式 |
|------|------|---------|---------|
| 糖糖 | 中文 | 丛雨参考音 + 通用 V4 | `/角色 糖糖` |
| 丛雨 | 日语 | 丛雨参考音 + 通用 V4 | `/角色 丛雨` |
| 米雪儿 | 中文 | 中文情绪参考音 + 米雪儿专属模型 | `/角色 米雪儿` |

**语音行为**：
- 糖糖通过 Tool Calling 自主决定发不发语音——不再用关键词检测
- 想听语音说"发个语音"就行
- `/语音` 切换持久语音模式（每条都发语音），`/语音 off` 关掉
- `/角色 丛雨/米雪儿/糖糖` 同步切换身份卡、参考音和模型——命令本身不发语音
- ⚠️ edge-tts 引擎下 `/角色` 切换无效——只有糖糖一种声音

## 四、歌唱工作室

> 📍 在设置页 → 🎤 唱歌 分类下方

### 点歌

群友说「唱个晴天」「来首勇气」即可触发。糖糖会从曲库中匹配歌名，LLM 自动选择最合适的段落。

- 支持口语化表达（"唱个""来首""那个"等）
- 支持模糊歌名匹配
- 私聊点歌会自动在私聊唱

> ⚠️ **当前唱歌 = 播放提前录制好的歌**：糖糖唱的是 `songs/audio/歌名/段落名.wav` 里已渲染好的音频（LLM 用 `[SING:段落]` 标记直接播放）。曲库中只有**已渲染段落的歌**能唱——没有音频的段落会提示唱不了。

### DiffSinger 歌声合成（手动渲染工具）

> 📍 在设置页 → 🎵 曲库 分类下方

- 查看每首歌的段落状态（哪些段落已合成、哪些待生成）
- 支持逐段渲染或全部渲染——用歌词 + 曲谱生成新的歌声文件
- **需要先启动 DiffSinger MiniEngine 服务**（未启动时渲染不可用）
- 生成的歌声存入 `songs/audio/歌名/段落名.wav`，渲染完成后糖糖才能唱这首歌

> 📌 注意：DiffSinger 合成**不是糖糖自动唱歌的路径**——它只是"提前制作歌曲"的工具。糖糖唱歌始终播放制作好的音频，不会实时合成。

## 六、日志 — 查看运行状态

实时显示糖糖的所有输出日志。日志很多时可以用过滤器快速定位。

### 内容过滤

点击分类按钮只看某一类日志，**多选叠加**。鼠标悬停看说明：

| 按钮 | 作用 | 点击后只看 |
|------|------|-----------|
| **消息** | 群聊和私聊的收发消息 | 收发消息、回复内容 |
| **LLM** | AI 调用记录 | LLM API 请求/响应/耗时 |
| **搜索** | 联网搜索相关 | Bing 搜索查询与结果 |
| **技能** | 技能调用记录 | 计算、翻译、天气、时间等 |
| **记忆** | 记忆系统操作 | 记忆提取、召回、存储 |
| **语音** | 语音合成记录 | TTS 语音合成与播放 |
| **协议** | SnowLuma 底层协议数据 | 原始JSON、心跳、戳一戳等（调试用，平时建议排除） |
| **HTTP** | HTTP 请求详情 | API 调用的底层 HTTP 日志 |
| **系统** | 系统事件 | 启动/停止/连接/诊断 |

- 不点任何按钮 = 显示全部
- 点一个 = 只看那一类
- 点多个 = 叠加显示（如同时看「消息」+「LLM」）
- 右边「排除」输入框：输入关键词（逗号分隔），隐藏含这些词的日志。常用于屏蔽 `heartbeat`、`RAW` 等高频无关日志

### 目标过滤

按群或用户过滤，**从群管理配置自动读取可选列表**：

- 点 `▾ 显示全部` → 勾选想看的群/人 → 只显示涉及这些 ID 的日志
- 点 `▾ 不过滤` → 勾选想隐藏的群/人 → 不显示涉及这些 ID 的日志
- 白名单和黑名单**互斥**（勾选一边自动取消另一边）
- 不含群号/QQ号的系统日志（启动、LLM调用等）不受影响，正常显示
- 右侧显示已过滤条数

### 其他

- 往上翻看历史日志时，新消息**不会**把你拽回底部
- 点「清空」清除当前显示
- 点「🔍 诊断」自动分析日志和数据库，检测常见问题（测试模式未关、API 失败率高等）

## 七、表情包管理

### 查看

仪表盘点「🖼 表情包」卡片 → 显示总数。

### 打标签

点「🏷 重打标签」→ 确认 → 按控制台「识图方式」配置选后端（本地不可用自动切云端），扫描 4 个贴图目录（默认/CG/丛雨/米雪儿）打情绪标签。

已打标签的图片（以情绪词开头，如 `开心_撒娇_xxx.jpg`）自动跳过。命令行也可单独跑：`python tools/标注贴图情绪.py [目录名]`。

### 使用

糖糖在聊天中会自动用 `[贴图:情绪]` 触发匹配表情包。

## 九、记忆系统

### 三层架构

糖糖的记忆分三层，各司其职：

| 层 | 存什么 | 怎么用 |
|----|--------|--------|
| 事实簇 (fact_clusters) | 按人×主题整理的结构化事实（健康、喜好、经历等） | 对话中 LLM 优先检索这一层 |
| 聊天索引 (chat_index) | 14 万条清洗后的聊天记录 + BGE 向量 | 事实簇找不到时兜底搜索 |
| 记忆碎片 (memories) | 零散的偏好和事实 | 注入系统提示词做背景 |

### 事实簇构建

糖糖运行时自动构建与增量更新——每约 50 条新消息触发一次，新事实自动合并到已有簇，无需手动操作。系统重启后会自动回填积压的历史消息。

### 记忆检索

糖糖在对话中通过 tool calling 自主检索记忆。优先搜索事实簇（结构化），找不到再搜索聊天记录（原始消息）。不需要手动触发。

## 十、常见问题

### 糖糖不说话

1. SnowLuma 是否在线？（看仪表盘状态）
2. 测试模式是否关了？（测试模式只回复主人）
3. 群是否在白名单里？
4. 黑名单里有没有这个群？
5. API Key 填了没、余额够不够？
6. 是不是有人说了"别说话"触发了静默模式？（`/状态` 查看）

### 私信发不出去

糖糖需要是对方好友，否则走群临时会话（需要和对方在同一个群）。

### 控制台打不开

```bash
pip install pyside6 PyYAML
python 糖糖控制台_qt.py
```

### 图片发不出去

1. 图库里有图吗？（看图库页）
2. 图片分享开关开了吗？
3. 间隔设置是否太长？

### 修改配置后没生效

- 控制台改的 → 点「保存」→ 重启糖糖（部分配置需要）
- 直接改 config.yaml → 重启糖糖
- QQ 遥控指令（`/人格`、`/插话` 等）改的参数即时生效但重启后丢失

### 表情包太多垃圾

设置 → 行为 → 关闭「自动偷表情包」。或保持开启，大于 2MB 的照片会自动跳过。

### 点歌没反应

糖糖通过 LLM + Tool Calling 理解点歌意图——不需要精确关键词。"唱个晴天""来首勇气""放首歌"都能识别。如果没反应，检查曲库中是否有这首歌（`/歌单` 查看）。

### 笔记本也想跑糖糖？

见 📡 [文件同步指南](文件同步指南.md) — 完整的新机安装、记忆同步和踩坑记录。要点：

1. 整个项目文件夹同步到笔记本（Syncthing，`memory.db` 已在 .stignore 排除）
2. 双击 `安装糖糖.bat` → 菜单 1 装依赖（按功能勾选）
3. 菜单 3「解包记忆」应用台式机的最新记忆（**糖糖须未运行**）
4. 启动 SnowLuma 扫码登录 → 启动糖糖

> ⚠️ 同一个 QQ 号**不能两台电脑同时在线**——笔记本登录会把台式机的糖糖顶下线，反之亦然。切换机器前先停止另一台的糖糖。

### 识图和语音怎么配（笔记本/低配机器）？

不再有"全能/简约"二选一——**识图和语音分别独立配置**：

| 能力 | 配置位置 | 本地方案 | 云端方案（低配友好） |
|------|---------|---------|-------------------|
| 识图 | 设置 → 👁 识图 → 识图方式 | local（MiniCPM-V，需 GPU） | api（千问 VL，零本地依赖） |
| 语音 | 设置 → 🎤 语音 → 语音引擎 | gpt-sovits（需 GPU） | edge-tts（微软云端） |

选中的优先，**另一个自动兜底**（比如选 local 但 Ollama 没启动 → 自动切云端）。笔记本推荐：识图 api + 语音 edge-tts，零 GPU 依赖。

## 十二、2026-07-29 更新说明

### 🧠 LLM 更聪明了

糖糖现在通过 **原生 Tool Calling** 自主调用能力——不再需要系统替她判断"该不该搜索""该不该发语音"。她能自己决定：

- 搜索互联网查实时信息
- 搜索聊天记录回忆群友说过的事
- 唱歌、发语音、分析图片
- 计算、翻译、查天气、看时间

所有能力统一为工具，LLM 自己选择何时调用。

### ⚡ 回复更快了

流式输出替代了伪造的打字延迟。LLM 的真实生成速度 = 最自然的回复节奏。不再有多余的等待。

### 🖥📱 双模式运行

控制台新增**运行模式**切换：全能（台式机+GPU）和简约（笔记本+云端）。切换后自动联动语音引擎和识图方案——全能启动本地 GPT-SoVITS，简约走微软 edge-tts 云端。每天凌晨 6:00 自动重启防内存泄漏。

> 📌 2026-08-09 起已演进为**识图/语音独立配置**（不再二选一），见第十三节。

### 🧹 架构清理

- 删除了从未使用的 framework/ 和 plugins/ 目录
- 移除了基于关键词的自动记忆提取（准确率低，噪音大）
- 统一了双套工具调用系统为一套 Native Tool Calling
- 环境变量 `.env` 支持密钥管理
- JSON 文件持久化迁移到 SQLite（kv_store）
- 7 处关键词检测点移除，LLM 自主决策所有行为

### 📊 已知限制

- 本地语音（gpt-sovits/cosyvoice）需要 GPU 与服务运行；edge-tts 零本地依赖
- 本地识图需要 Ollama + MiniCPM-V 模型；选云端则零本地依赖（选中的优先，另一个自动兜底）
- **唱歌只能播放预渲染好的音频**——DiffSinger 合成需要手动启动服务并渲染（见第四节），糖糖不会实时合成歌声
- 记忆系统待加入反馈闭环（感知引擎已部署，持续收集中）
- handler.py 仍偏大（~7000 行），后续将继续模块化

> 📌 注：2026-08-09 起识图/语音已改为**独立配置**（不再有"全能/简约"二选一）——见上文「识图和语音怎么配」。

> 详细技术评估见 `docs/开发规划/系统评估_20260729.md`

## 十三、2026-08-09 更新说明

### 🔄 定时重启不再"假死"

每天 6:00 自动重启后，控制台会在 3 秒内自动拉起新进程（此前重启后需要手动启动，可能宕机一整天）。糖糖退出时还会自动打包记忆快照。

### 📦 统一安装/维护工具

新机器不再用零散脚本——双击 `安装糖糖.bat` 一个入口全搞定：按功能安装依赖、打包/解包记忆、生成部署包、发布给他人、检查状态。旧的 `一键安装.bat` 已退役。

### 🧠 记忆跨机器同步

`memory.db` 是 WAL 模式数据库，直接同步会损坏/丢数据（历史上产生过 10 个冲突文件）。现在：
- 换机用 `同步记忆.py`（打包 → Syncthing 同步快照 → 解包）
- 糖糖停止时**自动打包**，不怕忘
- `.stignore` 让 Syncthing 不再碰数据库本体和运行状态文件

### 👁 识图统一

「识图方式」配置（local/api）现在真正生效：糖糖运行时识图、贴图标注工具都走同一个路由，选中的模型优先，另一个自动兜底（本地挂 → 云端，云端挂 → 本地）。GIF 支持多帧情绪感知。
