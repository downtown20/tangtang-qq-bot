## 一、快速开始

### 1. 安装

双击 `安装糖糖.bat`（等价于 `python tools/安装糖糖.py`，同一程序两个入口）：

```
小糖糖 安装/维护工具
  1. 安装依赖 — 功能选择安装（含环境/目录检测、配置调整）
  2. 打包记忆 — 跑完糖糖后导出最新记忆快照（换机前）
  3. 解包记忆 — 启动糖糖前应用另一台机器的快照
  4. 打包项目 — 生成部署 zip（给自己笔记本用，按功能瘦身）
  5. 发布项目 — 清理个人数据后生成分享文件夹（发给别人）
  6. 检查状态 — 环境 + 快照总览
  7. 体检 — 换机功能对比（[×]=缺失 [!]=留意，两台机器各跑一遍对照）
```

> 状态标记用的是 `[√] [ ] [×] [!]` 这套方括号符号，不是 emoji——因为 Windows 10 自带终端
> 的字体里没有 emoji 字形，`✅ ⬜ ❌` 会全部渲染成空心方框（Win11 默认终端没这个问题）。

选「1 安装依赖」→ 按需勾选 **8 个功能**：

| 功能 | 说明 |
|---|---|
| 聊天+高质量记忆 | 核心——LLM、记忆、知识库、BGE 向量（**必装**） |
| 发语音+听懂语音消息 | 听懂别人的语音 + GPT-SoVITS 发声；模型约 6G，安装时自动下载 |
| 本地识图 | 本地 MiniCPM-V（约 2.5G，需 Ollama）；不选则用云端千问 VL |
| 唱歌 | 点歌即播 41 首预录成品；已随包自带 |
| 读文档 | docx / pdf 解析 |
| 图形控制台 | PySide6 界面——强烈建议 |
| 测试工具 | pytest 开发测试 |
| 运维工具 | runtime_observer 观察器、体检 / 语音质检脚本 |

默认已勾好「聊天+记忆 / 唱歌 / 图形控制台」。**不装的组只会让对应功能不可用，不会崩。**

安装程序会把对应的配置开关**双向接好线**：勾了的打开，没勾的干净关掉，装完还会告诉你还差什么。

> ⚠️ **语音依赖 MSVC 前置**：GPT-SoVITS 分词加速 `jieba-fast` 在 Windows 常需源码编译——
> 先装 VS2022 Build Tools（C++ 桌面开发工作负载，含 Windows SDK），装完**重开终端**再装依赖。
> 没有 MSVC 也能跑：启动器自动回退纯 Python `jieba`（较慢但可用）。安装向导会检测 `cl.exe` 并提示。

> ⚠️ **SnowLuma 需要你自己下载一次**。它是连接 QQ 的协议端，属于第三方项目，其许可协议
> 不允许随本项目分发或由安装器代下。安装程序开头会给出官方发布页链接，控制台点
> 「启动 SnowLuma」而没装时也会再提醒一次。也可用任意其他 OneBot 11 反向 WebSocket 实现替代。
>
> ⚠️ **别和项目根目录的 `onebot/` 搞混**：那个是糖糖**自己**的适配层代码，随包自带、不用你管；
> `SnowLuma/` 才是要你放第三方程序的地方。连接方向是**糖糖开服务端、SnowLuma 连过来**。

### 2. 配置

双击 `启动控制台.bat` → 控制台 → **设置页**：

- 🤖 **机器人** → 机器人 QQ 号和你的 QQ 号
- 🧠 **AI模型** → DeepSeek 或 Claude 的 API Key
- 👥 **群管理** → 添加你的群号

点「💾 保存设置」。不用手动编辑 `config.yaml`，控制台里就能填。

> 从发布包解压出来的目录里**只有 `config.example.yaml` 和 `.env.example` 两个模板**，
> 没有 `config.yaml` / `.env`——真实的这两个文件在 `.gitignore` 里，安装程序首次运行时会
> 自动从模板复制生成。（自己 clone 主仓时同理。）

### 3. 启动 SnowLuma

仪表盘 → 点「启动 SnowLuma」→ 在弹出的 QQ 窗口中登录机器人 QQ。

登录后进入 QQ 设置 → WeUI → 配置反向 WebSocket：`ws://127.0.0.1:3001`，HTTP：`http://127.0.0.1:3000`。
首次使用也可运行 `python tools/配置SnowLuma.py` 自动配置。

### 4. 启动糖糖

SnowLuma 在线后 → 点「🍬 启动小糖糖」→ 等日志出现「小糖糖已上线」。

```bash
python 糖糖控制台_qt.py     # 命令行
启动控制台.bat               # 或双击
```

控制台是**左侧导航栏 + 四个页面**：**仪表盘、设置、图库、日志**。

## 二、仪表盘 — 启动和监控

### 启动流程

```
1. 点「启动 SnowLuma」→ QQ 登录窗口弹出 → 登录机器人 QQ
2. QQ 设置 → WeUI → 配置反向 WS 和 HTTP 地址
3. 等状态变为「🟢 在线」
4. 点「🍬 启动小糖糖」→ 日志开始滚动
5. 看到「小糖糖已上线」→ 糖糖上线
```

### 控制按钮

| 按钮 | 作用 |
|------|------|
| 启动 SnowLuma | 启动 QQ 协议客户端，弹出窗口登录 |
| 🍬 启动小糖糖 | 启动 AI 机器人（运行中该按钮会变成「运行中」） |
| 停止 | 停止糖糖进程，自动向活跃群发离线通知 |
| 重启 | 先停止再启动 |
| ☐ 后台静默运行 | **复选框**，勾上后关闭窗口时最小化到托盘 |

> 🕐 **每天 6:00 自动重启**：糖糖以退出码 42 退出后，控制台会在 3 秒内自动拉起新进程
> （防内存泄漏，无需手动操作）。任何方式停止糖糖时，控制台还会**自动打包记忆快照**
> （数据没变化时跳过），换机前无需手动导出。

### 状态指示

| 状态 | 含义 |
|------|------|
| 🟢 在线 | SnowLuma + QQ 正常 |
| 🟡 启动中 | 进程已拉起，还在等连接 |
| 🟠 QQ离线 | QQ 掉线但 SnowLuma 还在（心跳检测到连续失败） |
| 🔴 异常 | 糖糖进程崩溃 |
| ● 离线 | 糖糖未启动 |

（卡片上的短文案是另一套：运行中 / QQ离线 / 异常 / 已停止。）

### 统计卡片

顶部四张卡片显示实时数据：**群友数、记忆数、聊天数、表情包数**。

点击任意卡片展开数据浏览面板：

| 卡片 | 展开后能看什么 |
|------|-------------|
| 群友 | 所有群友的 QQ、昵称、亲密度、发言数，支持搜索 |
| 🧠 记忆 | 糖糖记住的所有事，支持搜索 |
| 💬 聊天 | 最近的聊天记录，支持搜索 |
| 🖼 表情包 | 表情包总数，点「🏷 重打标签」扫描新表情（此卡不显示搜索框） |

### 诊断

点「🔍 诊断」自动分析日志和数据库，检测常见问题（测试模式未关、API 失败率高等）。

## 三、设置 — 修改配置

左侧 **20 个分类**，点任意一个切换。每个字段下面都有灰色说明文字。

**核心配置**：机器人 · SnowLuma · 群管理 · 黑名单 · 记忆
**AI 引擎**：AI模型 · 识图 · 搜索
**人格行为**：人格 · 行为 · 情绪
**扩展功能**：⏰提醒可靠性 · 图片分享 · 语音 · 曲库 · 每日播报 · 每日点赞 · AI画图
**外观**  ·  **密钥管理**

### 必须配置的

| 分类 | 关键字段 | 说明 |
|------|---------|------|
| 🤖 机器人 | QQ号、主人QQ | 糖糖的 QQ 号和你的 QQ 号 |
| 🧠 AI模型 | API Key | **必填**，否则糖糖不会说话 |
| 👁 识图 | 识图方式 + API Key | `local`=本地 MiniCPM-V ｜ `api`=云端千问 VL。选中的优先，另一个自动兜底 |
| 👥 群管理 | 添加群 | 只有这里列的群糖糖才会回复 |

### 行为调整

| 字段 | 作用 | 建议值 |
|------|------|--------|
| 仅回复这些人 | 白名单模式，留空=回复所有人 | 一行一个 QQ 号 |
| 主动插话 | 糖糖会在群聊中主动参与对话 | 开启 |
| 插话饥渴度 | **0.0–1.0**，0=沉默 1=话痨 | 0.4–0.8 |
| 插话冷却 | 两次插话最少间隔秒数（10–300） | 60–300 |
| 测试模式 | **拦截所有群消息**（只回私聊），不消耗 token。正常使用请关闭 | 关闭 |
| 自动偷图 | 开启后糖糖会自动保存群里发的表情包 | 按喜好 |

> 🆕 插话不用关键词打分——糖糖是否接话只取决于客观信号：有没有人提问、消息长度、亲密度、
> 是否主人、随机心情。LLM 自己判断内容是否值得回应。

### 群场景配置

在群管理编辑框中可以为每个群设置糖糖的角色：

| 场景 | 类型 | 说明 |
|------|------|------|
| 💬 日常闲聊 | 默认 | 完整的猫娘人格 |
| 🧠 心理陪伴 | 叠加 | 猫娘人格 + 敏感度提示，不追问、不评判 |
| 📋 活动管理者 | 替换 | 裁剪猫娘撒娇，专注活动策划与通知 |

**精准指定**：可以在「场景目标用户」中按 QQ 号单独设置场景（如只对某个人启用心理陪伴模式）。

私聊场景在群管理区域下方的「私聊场景目标用户」中设置。

> 📖 场景系统详细设计见 [docs/开发规划/ROADMAP.md](../开发规划/ROADMAP.md)

### 图片分享

| 字段 | 作用 | 建议值 |
|------|------|--------|
| 启用分享 | 定时发图开关 | 开启 |
| 间隔(分钟) | 多久发一张 | 60–240 |
| 每日上限 | 防止刷屏 | 6–20 |
| 仅本地图库 | 只发自己上传的图 | 开启 |

### 外观定制 (🎨)

2026-09-06 起定稿为**极简三项**：

- **主题拨杆**：深色 / 浅色一键切换
- **配色方案**：5×2 圆色卡，**10 种**预设（玫瑰雾 / 琥珀 / 星野 / 薄荷 / 极光 / 珊瑚 / 冰川 / 常青 / 石墨 / 玫红）
- **自定义颜色**：点彩虹圆点打开取色面板

> 早先版本有「字体大小滑条」「8 种颜色分别调」「背景图 + 不透明度」「实时预览」——
> 这些控件在 2026-09-06 改版时已移除。字体大小仍可在 `config.yaml` 里改 `appearance.font_size`，只是没有界面。

### 🎤 语音

**语音引擎固定为 GPT-SoVITS**（控制台里是只读标签，没有下拉框）。CosyVoice 已收敛移除，edge-tts 只剩代码兜底、界面不给选。

三种角色音（独立角色卡）：

| 角色 | 语言 | 切换方式 |
|------|------|---------|
| 糖糖 | 中文 | `/角色 糖糖` |
| 丛雨 | 日语 | `/角色 丛雨` |
| 米雪儿 | 中文 | `/角色 米雪儿` |

**语音行为**：

- 糖糖通过 Tool Calling 自主决定发不发语音——不用关键词检测。想听就说「发个语音」
- `/语音` 切换持久语音模式（每条都发语音），`/语音 off` 关掉
- `/角色 丛雨/米雪儿/糖糖` 同步切换身份卡、参考音和模型
- 群里任何人说「别发语音了」/「可以发语音了」可以按会话关掉或恢复

> ⚠️ **`/角色` 有个已知行为**：语音引擎是 GPT-SoVITS 但服务没起来时，`switch_model` 会失败，
> 此时**整个人格卡和表情包都不会切**（提示「语音模型切换失败，角色保持不变」）。

> 📌 **「只听不说」**：配置里有 `voice.asr_enabled` 这一项——关掉 `voice.enabled` 但保留
> `asr_enabled=true`，糖糖就不会发语音、但仍然听得懂别人发的语音消息。**控制台暂时没有这个
> 开关的界面**，需要直接改 `config.yaml`。安装器勾「发语音+听懂语音消息」时两个键一起打开。

## 四、曲库与歌唱工作室

> 📍 设置页 → 🎵 曲库

### 曲库管理

列表 + 编辑器：新建歌曲、删除选中、保存当前；歌名 / 歌手 / 歌词三个输入框。

`/歌单` 列的是**曲库条目**（当前 45 条），其中**有音频能唱的 41 首**——没音频的那几首是
只写了歌词还没录。

### 点歌

群友说「唱个晴天」「来首勇气」即可触发。糖糖会从曲库匹配歌名，LLM 自动选择最合适的段落。

- 支持口语化表达（"唱个""来首""那个"）
- 支持模糊歌名匹配
- 私聊点歌会自动在私聊唱

> ⚠️ **唱歌 = 播放提前录制好的音频**，不是实时合成。曲库里只有**已有音频的歌**能唱——
> 没有音频的会诚实说不会。

### 两种声音版本

每首歌都有两版，说「**原声**」「**原唱**」「放原版」就切到原唱那一版：

| 版本 | 存放位置 | 发布包里 |
|---|---|---|
| 糖糖声线（默认） | `songs/audio/歌名.wav` | 无损 WAV |
| 原声（原唱人声） | `songs/covers/separated/歌名_FINAL.wav` | **转码后的 mp3**（同目录换后缀） |

> 为什么原声在包里是有损格式：唱歌是通过 `[CQ:record]` 发出去的，也就是 **QQ 语音消息**，
> QQ 侧本来就会把它转成 SILK 这类低码率语音编码。存无损 WAV 等于白背 1.5 GB（1.78G → 242M）。
> 开发机上仍保留无损源文件，代码两种后缀都认。

### 🎙 歌唱工作室

曲库页下方，用来**制作**新歌（不是糖糖现场合成）：

- **添加翻唱**：喂一个音频文件
- **一键全流程**：人声分离(demucs) → RVC 音色转换(HuTao) → 切除静音 → 输出到 `songs/audio/`
- **模型**：选择 RVC 音色模型

> 📌 早先版本这里的 DiffSinger 逐段渲染工具已从控制台移除。DiffSinger 仍作为
> 后端服务存在（`agent/diff_singer.py`，启动时预热），但没有界面入口。

## 六、日志 — 查看运行状态

实时显示糖糖的所有输出日志。日志很多时可以用过滤器快速定位。

### 内容过滤

点击分类按钮只看某一类日志，**多选叠加**：

| 按钮 | 点击后只看 |
|------|-----------|
| **消息** | 收发消息、回复内容 |
| **LLM** | LLM API 请求/响应/耗时 |
| **搜索** | Bing 搜索查询与结果 |
| **技能** | 计算、翻译、天气、时间等 |
| **记忆** | 记忆提取、召回、存储 |
| **语音** | TTS 语音合成与播放 |
| **协议** | 原始 JSON、心跳、戳一戳等（调试用，平时建议排除） |
| **HTTP** | API 调用的底层 HTTP 日志 |
| **系统** | 启动 / 停止 / 连接 / 诊断 |

- 不点任何按钮 = 显示全部；点一个 = 只看那一类；点多个 = 叠加
- 右边「排除」输入框：输入关键词（逗号分隔），隐藏含这些词的日志。常用于屏蔽 `heartbeat`、`RAW`

### 目标过滤

按群或用户过滤，**从群管理配置自动读取可选列表**：

- 点 `▾ 显示全部` → 勾选想看的群/人
- 点 `▾ 不过滤` → 勾选想隐藏的群/人
- 白名单和黑名单**互斥**（勾选一边自动取消另一边）
- 不含群号/QQ号的系统日志不受影响

### 其他

- 往上翻看历史日志时，新消息**不会**把你拽回底部
- 点「清空」清除当前显示
- 点「🔍 诊断」自动分析日志和数据库

## 七、表情包管理

### 查看

仪表盘点「🖼 表情包」卡片 → 显示总数。

### 打标签

点「🏷 重打标签」→ 确认 → 按控制台「识图方式」配置选后端（本地不可用自动切云端），
扫描 **4 个**贴图目录打情绪标签：**默认(糖糖) / CG(色色) / 丛雨(murasame) / 米雪儿(michele)**。

已打标签的图片（以情绪词开头，如 `开心_撒娇_xxx.jpg`）自动跳过。
命令行也可单独跑：`python tools/标注贴图情绪.py [目录名]`。

### 使用

糖糖在聊天中会自动用 `[贴图:情绪]` 触发匹配表情包。

| "今天天气怎么样" | 联网搜索（糖糖自己决定是否搜索） |
| "发个语音" / "说句话" | 糖糖会发语音消息 |
| "发个表情包" | 糖糖可以发表情包 |

### 糖糖的能力边界

**能做的**：群发言、私聊、唱歌、戳一戳、点赞、传话、开关插话、调活跃度、联网搜索、发语音、
发表情包、记忆检索、读合并转发内容、接受好友申请与群邀请

**不能做的**：

- ❌ 主动加群——只能等别人邀请
- ❌ 主动加好友——只能等别人申请
- ❌ **自己**踢人 / 禁言 / 撤回别人的消息（她没有这些工具）——但主人/群主可以用
  `/禁言` `/踢` `/头衔` `/全员禁言` 这些命令让她去执行

### 好友申请 & 群邀请

- **别人加糖糖好友** → 主人秒过；命中垃圾号关键词秒拒；其余自动同意，并发 LLM 生成的欢迎消息
- **别人邀请糖糖进群** → 主人或亲密度 ≥20 的熟人自动同意；陌生人邀请忽略；同意后会私聊通知主人
- 糖糖不能主动加别人，只能接受邀请/申请

### 静默模式（群内任何人可用）

| 说法 | 效果 |
|------|------|
| "糖糖别说话了" / "安静点" | 🤫 静默模式：关插话，仅 @ 或叫名字才回复 |
| "可以说话了" / "继续聊天" | 恢复正常 |
| "别发语音了" | 关闭该会话的语音回复 |
| "可以发语音了" | 恢复语音回复 |

> 📌 这四组短语是**全串精确匹配**（`fullmatch`），不是模糊关键词——它们是代码里登记在案的
> 「有原则的例外」：语义空间极小、用户期待即时生效，交给 LLM 反而会慢和不确定。
> 注意短语表里是「不要**说话**了」，说「不要**讲话**了」不生效。

## 九、记忆系统

### 三层架构

| 层 | 存什么 | 怎么用 |
|----|--------|--------|
| 事实簇 (`fact_clusters` / `cluster_facts`) | 按人×主题整理的结构化事实（健康、喜好、经历等） | 对话中 LLM 优先检索这一层 |
| 聊天索引 (`chat_index`) | 清洗后的聊天记录 + BGE 向量（当前约 14 万条） | 事实簇找不到时兜底搜索 |
| 记忆碎片 (`memories`) | 零散的偏好和事实 | 注入系统提示词做背景 |

### 事实簇构建

糖糖运行时自动构建与增量更新——每约 50 条新消息触发一次，新事实自动合并到已有簇。
系统重启后会自动回填积压的历史消息。

### 记忆检索

糖糖在对话中通过 tool calling 自主检索。优先搜索事实簇（结构化），找不到再搜索聊天记录
（原始消息）。不需要手动触发。

## 十、常见问题

### 糖糖不说话

1. SnowLuma 是否在线？（看仪表盘状态）
2. 测试模式是否关了？（测试模式**拦截所有群消息**，只回私聊）
3. 群是否在白名单里？
4. 黑名单里有没有这个群？
5. API Key 填了没、余额够不够？
6. 是不是有人说了"别说话"触发了静默模式？（`/状态` 查看，需要主人/群主权限）

### 私信发不出去

糖糖需要是对方好友，否则走群临时会话（需要和对方在同一个群）。

### 控制台打不开

```bash
pip install pyside6 PyYAML
python 糖糖控制台_qt.py
```

### 图片发不出去

1. 图库里有图吗？（看图库页）
2. 图片分享开关开了吗？
3. 间隔设置是否太长？

### 修改配置后没生效

- 控制台改的 → 点「保存」→ 重启糖糖（部分配置需要）
- 直接改 config.yaml → 重启糖糖
- QQ 遥控指令（`/人格`、`/插话` 等）改的参数即时生效但重启后丢失

### 表情包太多垃圾

设置 → 行为 → 关闭「**自动偷图**」。或保持开启，大于 2MB 的照片会自动跳过。

### 点歌没反应

糖糖通过 LLM + Tool Calling 理解点歌意图——不需要精确关键词。"唱个晴天""来首勇气"都能识别。
如果没反应，检查曲库中是否有这首歌（`/歌单` 查看）。

### 「原声」放出来还是糖糖的声音？

按设计会降级：请求的版本没有音频时，糖糖会放另一版（比没声音好）。
`/歌单` 里的歌不一定两版都有。

### 笔记本也想跑糖糖？

见 📡 [文件同步指南](文件同步指南.md) —— 完整的新机安装、记忆同步和踩坑记录。要点：

1. 整个项目文件夹同步到笔记本（Syncthing，`memory.db` 已在 `.stignore` 排除）
2. 双击 `安装糖糖.bat` → 菜单 1 装依赖（按功能勾选）
3. 菜单 3「解包记忆」应用台式机的最新记忆（**糖糖须未运行**）
4. 启动 SnowLuma 扫码登录 → 启动糖糖

> ⚠️ 同一个 QQ 号**不能两台电脑同时在线**——笔记本登录会把台式机的糖糖顶下线，反之亦然。
> 切换机器前先停止另一台的糖糖。

### 识图和语音怎么配（笔记本/低配机器）？

**识图和语音分别独立配置**，没有"全能/简约"二选一：

| 能力 | 配置位置 | 本地方案 | 云端方案（低配友好） |
|------|---------|---------|-------------------|
| 识图 | 设置 → 👁 识图 → 识图方式 | `local`（MiniCPM-V，需 GPU） | `api`（千问 VL，零本地依赖） |
| 语音 | 设置 → 🎤 语音 | GPT-SoVITS（需 GPU） | 代码层有 edge-tts 兜底，但控制台不给选 |

选中的优先，**另一个自动兜底**（比如选 local 但 Ollama 没启动 → 自动切云端）。
