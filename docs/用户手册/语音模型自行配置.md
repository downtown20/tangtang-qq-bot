# 语音模型自行配置

糖糖说话只用一个引擎：**GPT-SoVITS**。

发布包**只带私有部分**（米雪儿的声线 + 各情绪的参考音，共 237 MB）——这些是我们自己微调的，
外面下不到。**公开底模 3.7 GB 需要你自己下**：它是第三方开源模型，官方仓库就有，
没必要再走我们的仓库（那会让安装包从 0.7 GB 涨到 4.4 GB）。

> 不想折腾也没关系：不配语音，糖糖照常聊天，只是不发语音。桌面端「设置 → 语音」里可以随时开关。

---

## 一、包里自带了什么

解压后就位，不用你动：

```text
gpt-sovits/
  models/michele/
    MiXueErV3-e10.ckpt        147.9 MB    米雪儿的 GPT 权重
    MiXueErV3_e100_s4900.pth   81.0 MB    米雪儿的 SoVITS 权重
  speakers/
    normal/ref.wav  等 15 个情绪参考音     8 MB
```

`speakers/` 是每句话开始时喂给模型的「参考音」——**它决定音色和语气**。缺了它，任何角色都合成不出来
（TTS 请求里 `ref_audio_path` 为空会直接报错）。

---

## 二、你要补的是公开底模（约 3.7 GB）

全部来自 GPT-SoVITS 官方。**把下面这些放进 `gpt-sovits/GPT_SoVITS/pretrained_models/` 下**，
目录名要保持原样：

| 目录 / 文件 | 体积 | 说明 |
|---|---|---|
| `chinese-hubert-base/` | 180 MB | 语义特征提取 |
| `chinese-roberta-wwm-ext-large/` | 621 MB | 中文文本特征 |
| `s1v3.ckpt` | 148 MB | GPT 底座（默认角色用） |
| `gsv-v4-pretrained/` | 789 MB | v4 SoVITS 权重 + `vocoder.pth` |
| `s2Gv3.pth` | 733 MB | v3 SoVITS 权重 |
| `sv/` | 103 MB | 说话人验证 |
| `fast_langdetect/` | 125 MB | 语种检测 |
| `models--nvidia--bigvgan_v2_24khz_100band_256x/` | 429 MB | v2ProPlus 的声码器（见下方说明） |

外加中文注音模型（**不放上面那格**）：

| 目录 | 体积 | 放在 |
|---|---|---|
| `G2PWModel/` | 608 MB | `gpt-sovits/GPT_SoVITS/text/G2PWModel/` |

### 下载地址（官方原文）

1. **模型总仓**：<https://huggingface.co/lj1995/GPT-SoVITS>
   —— 里面平铺着 `gsv-v4-pretrained/`、`s2Gv3.pth`、`s1v3.ckpt`、`chinese-hubert-base/` 等，
   对应上表。**最省事的做法是整仓下载**（会多出 v2Pro / v2final 等 2 GB 你没用的东西，无害），
   然后整个拷进 `pretrained_models/`。

   ```powershell
   pip install -U huggingface_hub
   huggingface-cli download lj1995/GPT-SoVITS --local-dir gpt-sovits/GPT_SoVITS/pretrained_models
   ```

   国内慢的话加镜像：`$env:HF_ENDPOINT="https://hf-mirror.com"`，或者用 ModelScope 上的同步仓库。

2. **中文注音 G2PWModel**：
   - HuggingFace：<https://huggingface.co/XXXXRT/GPT-SoVITS-Pretrained/resolve/main/G2PWModel.zip>
   - ModelScope（国内快）：<https://www.modelscope.cn/models/XXXXRT/GPT-SoVITS-Pretrained/resolve/master/G2PWModel.zip>

   下完解压，文件夹**重命名成 `G2PWModel`**，放进 `gpt-sovits/GPT_SoVITS/text/`。

3. **完全不想用命令行**：下官方 Windows 整合包
   <https://huggingface.co/lj1995/GPT-SoVITS-windows-package/resolve/main/GPT-SoVITS-v3lora-20250228.7z>，
   解压后把里面的 `GPT_SoVITS/pretrained_models/` 整个拷到我们的 `gpt-sovits/GPT_SoVITS/` 下即可。
   国内镜像入口在官方 README 里（语雀那一栏）。

> **关于 `models--nvidia--bigvgan_v2_24khz_100band_256x`**：这个名字是 Hugging Face 的**缓存目录格式**，
> 不是官方仓库里的普通文件夹。它是 v2ProPlus 声码器要用的，糖糖默认走 `gsv-v4-pretrained/vocoder.pth`，
> 所以**先不放也能跑**。只有当合成报「vocoder / bigvgan 找不到」时才需要补：
>
> ```powershell
> huggingface-cli download nvidia/bigvgan_v2_24khz_100band_256x
> # 默认落在 ~/.cache/huggingface/hub/models--nvidia--bigvgan_v2_24khz_100band_256x
> # 把整个目录拷到 gpt-sovits/GPT_SoVITS/pretrained_models/ 下
> ```

## 三、米雪儿的声线是**自动切换**的

这一节单独讲，因为它决定「为什么包里必须带米雪儿那 229 MB」。

`agent/voice.py` 里有两套权重，各有名字：

```python
MODEL_PROFILES = {
    "default": {
        "gpt":    ".../pretrained_models/s1v3.ckpt",                 # 公开底模
        "sovits": ".../pretrained_models/gsv-v4-pretrained/s2Gv4.pth",
    },
    "michele": {                                                     # ← 米雪儿
        "gpt":    "models/michele/MiXueErV3-e10.ckpt",               # 随包自带
        "sovits": "models/michele/MiXueErV3_e100_s4900.pth",         # 随包自带
    },
}
```

**你在桌面端把角色切到「米雪儿」时，程序会自动做三件事**（`switch_model("michele")`）：

1. 调 GPT-SoVITS 的 `/set_gpt_weights?weights_path=models/michele/MiXueErV3-e10.ckpt`
2. 调 `/set_sovits_weights?weights_path=models/michele/MiXueErV3_e100_s4900.pth`
3. 把参考音与 prompt 文本换成米雪儿对应的那一套（`speakers/normal/ref.wav` + 对应台词）

切走时（切到别的角色或默认）会自动换回 `s1v3.ckpt` + `s2Gv4.pth`。

**所以两套权重必须都在位**：

| 情况 | 结果 |
|---|---|
| 两套齐全（你按上面下完底模） | 米雪儿、默认角色都能说话 |
| 只下底模、删了 `models/michele/` | 米雪儿角色 → `/set_gpt_weights` 失败 → **降级为纯文字**，其它角色正常 |
| 只带米雪儿、缺底模 | 米雪儿**也**起不来——它仍需要 `chinese-hubert-base`、`chinese-roberta-wwm-ext-large`、`G2PWModel` 做文本前端 |

**不要手动改 `tts_infer.yaml`**：糖糖走的是运行期 `set_*_weights` 切换，改配置文件反而会和它打架。

## 四、装好之后怎么验

命令行验（最直接）：

```powershell
cd gpt-sovits
python start_api_patched.py
# 等它打印监听 127.0.0.1:9880（首次加载 GPU 模型约 1 分钟）
```

另开一个窗口合成一句：

```powershell
$body = @{
  text = "你好呀，我是米雪儿。"
  text_lang = "zh"
  ref_audio_path = "speakers/normal/ref.wav"
  prompt_text = "正义是一种信念，我理想中的搜查官应该要有拯救世界的觉悟。可是我究竟还要多久，才能成为那样的人呢？"
  prompt_lang = "zh"
  text_split_method = "cut0"; batch_size = 1; media_type = "wav"; streaming_mode = $false
} | ConvertTo-Json
Invoke-WebRequest -Uri http://127.0.0.1:9880/tts -Method Post -Body $body `
  -ContentType "application/json" -OutFile "$env:TEMP\tts_check.wav"
```

`tts_check.wav` 能正常播放 = 装好了。约 200 KB、3 秒左右。

也可以直接在桌面端「设置 → 语音」点试听（前提是糖糖已经跑起来、supervisor 把引擎拉起来了）。

## 五、故障对照

| 现象 | 大概是 |
|---|---|
| 启动就退出，`No such file: .../chinese-hubert-base` | 底模没放全，按第二节表对一遍 |
| 启动退出，`G2PWModel` 相关报错 | 中文注音模型没放，注意它是放 `text/` 不是 `pretrained_models/` |
| 能启动，合成报「ref_audio_path」 | `speakers/` 缺失（包里自带，除非你手动删了） |
| 切到米雪儿没声、其它角色正常 | `models/michele/` 缺失 |
| 合成报 vocoder / bigvgan | 补 `models--nvidia--bigvgan_v2_24khz_100band_256x`（见第二节末尾） |
| 全部就位但没声 | 看 `日志/tangtang.log` 里 `GPT-SoVITS` 那几行；桌面端「概览」页能看到引擎进程状态 |

## 六、为什么不做「一键自动下载」

做过评估，没做，理由是**确定性**：

自动下载意味着用户点的「安装」要额外依赖第三方仓库，我们无法锁定对方哪天改结构、删文件。
装到一半对不上，用户得到的是一个「看起来装好了但起不来」的语音服务——比明确告诉他
「这 3.7 GB 要你自己下」更糟。

所以这一版选择：**私有部分我们给全，公开部分给你准确地址**。将来如果真有人抱怨麻烦，
再考虑加自动下载，那时也有真实反馈来验证下载链路。
