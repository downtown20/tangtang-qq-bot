# 素材摆放说明（仓库里没有的大件资源）

本仓库只放**代码、配置模板与文档**。音频、表情包、语音模型、QQ 协议端体积大，  
或者有单独的许可条款，都不在仓库里，需要你自己准备，放进下面这些固定位置。

> 大部分目录程序会**首次运行时自动创建**（`songs/`、`stickers/`、`stickers_murasame/`、  
> `stickers_michele/`、`voice_cache/`），也可以先手动新建。放好之后**不用重装**——  
> 歌曲按「生效方式」重载，表情包重启糖糖即可。

| 目录                        | 放什么                                   | 来源                      | 生效方式              |
| ------------------------- | ------------------------------------- | ----------------------- | ----------------- |
| `songs/audio/`            | 糖糖声线的成品，`歌名.wav`（也认 `.mp3`）           | 自备 / 发布包                | `/歌单 重载`          |
| `songs/covers/separated/` | 原唱版，`歌名_FINAL.wav`（也认 `.mp3`）         | 自备 / 发布包                | `/歌单 重载`          |
| `stickers/`               | 默认表情包图片（`.png` `.jpg` `.gif` `.webp`） | 自备 / 发布包                | 重启糖糖              |

## 点歌：目录约定

- 糖糖声线：`songs/audio/歌名.wav`（或 `.mp3`）——点歌时默认播这一份
- 原唱版：`songs/covers/separated/歌名_FINAL.wav`（或 `.mp3`）——没有糖糖声线时自动退回它
- **两边的 `歌名` 必须完全一致**，才算同一首歌。例：`audio/晴天.wav` ↔ `covers/separated/晴天_FINAL.wav`
- 歌词文件**不会**被读取（2026-10-15 起不再读歌词）：`songs/audio/歌名.txt` 放了也没用
- 放好之后在 QQ 里发 `/歌单 重载`（或重启糖糖），新歌立刻出现在歌单里

仓库里只随带了几首示例歌曲（在 `songs/audio/` 下），完整曲库不在仓库里——见发布页说明。

## 表情包：目录约定与打标签

- 图片直接放进对应目录即可，子目录也会被扫描
- 情绪标签存在同目录的 `metadata.json` 里（控制台「图库」页加标签时会写这个文件）
- 没有 `metadata.json` 也能发图：此时按文件名的情绪前缀挑选（如 `开心_001.png`）
- 推荐做法：控制台 → 图库 → 批量选择 → 加情绪标签；标签越准，LLM 用 `[贴图:关键词]`  
  挑到的图越贴切

## 为什么不把这些放进仓库

体积（完整曲库 5.58 GB、四套表情包 1 GB 级）、素材本身有各自的著作权、  
而且每次更新都要重传一遍——仓库只该放「源头」。缺任何一个目录都不会让糖糖挂掉，  
功能会降级（没有歌就不唱、没有贴图就纯文字），装回素材后重启即恢复。
