## 第 3 步 归因（边界缺失，不是逻辑错）

提取 prompt 的 🚫 清单里有：

> 「引用转述——消息里转述/引用别人的话（「他说」「XX说」、引号里的他人言论）不是用户自述」

它覆盖的是**引用别人的话**，不覆盖**「主语是第三方的描述」**：

- 「他说他很累」→ 引用（旧边界覆盖 ✅）
- 「**他实际是高一新生**」→ 关于别人的陈述（**旧边界不覆盖** ❌）

而最凶的场景恰恰是「帮 XX 修正记忆」——用户转述第三方的信息，让糖糖去写库。
提取器看到一句有主语、有事实、有 evidence 的陈述，就记成了当前用户的事。

**推广到普遍现象**：抽 2000 条有证据的 extracted 记忆，**192 条（9.6%）的
证据原文里出现「他/她」**。绝大多数主语仍是本人（「我比他快」「跟她闹了矛盾」），
所以**不能一刀切成「有他/她就跳过」**——那样会误杀大量正常自述。

---

## 第 4 步 修复

`agent/memory.py` 提取 prompt 的 🚫 清单里，在「引用转述」之后加一条：

```
- 关于别人的陈述——**主语是第三方**的句子（「他今年高一」「她不喜欢抽烟」
  「XX 是我同事」）说的是**那个人**，不是当前用户自述。
  尤其当用户让你「修正/记一下 XX 的事」时，那句事实属于 XX —— 记到当前用户名下
  就是张冠李戴（2026-10-25 现场：主人让你修正「穷到吃外卖」的记忆，
  说「他实际是高一新生」，结果第二天这句话被提取成了主人自己的身份记忆）。
  判据**看主语，不看句子里有没有「他/她」**：
  ✅「我老婆叫米雪儿」「我妈是医生」——主语是「我」，是自述
  🚫「她叫米雪儿」「他今年高一」——主语是第三方，说的是别人
```

**同时钉住反例**（这是本轮的设计要点）：光说「有第三方就跳过」会误杀正常自述，
所以 prompt 里必须带「我老婆叫米雪儿」这个正例，规则才是**判主语**而不是**判词**。

对话回复不行（有状态、有随机性），提取可以。
