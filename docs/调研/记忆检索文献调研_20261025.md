## 0. 一页结论（给赶时间的人）

1. **双强度模型可以直接落地，但必须换一个用法**：Bjork 的 retrieval strength（RS）会随时间下降，
   但下降只应作为**排序信号**，不能作为**删除/降权信号**——这样既不违反「不做遗忘」，又能解释
   「为什么刚提过的事更容易被想起」。可用的衰减公式有三套：Ebbinghaus 幂律、指数 `R=e^{-t/S}`、
   FSRS 幂律 `R(t,S)`；工程上最推荐 FSRS-4.5 的形状（有开源公式、可解释、无需训练）。
2. **前瞻记忆是本项目「主动提起未完成的事」最直接的依据**：event-based（cue 触发）显著优于
   time-based（时钟触发），自然情境下意图完成率的最佳预测因子是**重要性 / 是否用外部记忆辅助 /
   社会价值 / 距形成日天数**——这四条可以直接变成排序权重。
3. **LLM 长期记忆的评测已经标准化到可以借**：LongMemEval 的**五能力**（信息抽取 / 跨会话推理 /
   时间推理 / 知识更新 / abstention）几乎逐条对应本项目的判据；LoCoMo 的**四类问题 + LLM-as-judge +
   成本指标**适合当回归基准。
4. **人类基线有数字的只有两条线**：守诺率（63% / 54% / 52%，对照 22%）和遗忘曲线（20 分钟约 42% 遗忘）。
   **「前瞻记忆完成率」的绝对值未找到可靠来源**——这是本调研最大的缺口，不要编。
5. **「胜过人」的可操作定义**：只在有数字的维度（守诺兑现、跨天不遗忘）上比；「检索命中率」没有人类
   对应基线，任何阈值都是工程约定，必须标为推断。

## 1. 问题一：双强度模型（New Theory of Disuse）怎么在工程上落地

### 1.1 理论：两个强度的分工

Bjork & Bjork 的 New Theory of Disuse 把记忆强度拆成两个正交量：

- **storage strength（SS）**：学得多深，**只增不减**，不会随时间衰减；
- **retrieval strength（RS）**：此刻有多容易取出来，**随提取而上升、随时间与干扰而下降**。

原始文献：Bjork & Bjork (1992), *A new theory of disuse and an old theory of stimulus fluctuation*，
PDF 在 UCLA Bjork Lab：<https://bjorklab.psych.ucla.edu/wp-content/uploads/sites/13/2016/07/RBjork_EBjork_1992.pdf>

二手综述给出的关键操作性表述（**注意：二手**）：
「重新学习时，storage strength 的增量与当前 retrieval strength **成反比**——当前越难想起，
重新学会后的 SS 增长越多」——Learning Scientists 客座博文
<https://www.learningscientists.org/blog/2016/5/10-1>（原文抽取失败，仅据检索摘要引用）；
同义表述见 <https://www.structural-learning.com/post/storage-strength-retrieval-strength>（二手）。

> **对本项目最重要的一句话**：RS 下降 **不等于** 遗忘。RS 是「此刻的取用概率」，不是「还存不存在」。
> 主人的「不做自然遗忘」约束的是 **SS 与数据本身**；RS 只允许参与**排序**。

### 1.2 可直接抄的衰减 / 间隔公式（按可用性排序）

**（A）Ebbinghaus 原始幂律**（1885，保留率-时间）
来源：<https://en.wikipedia.org/wiki/Forgetting_curve>

```
b = 100·k / ( (log t)^c + k )      k = 1.84, c = 1.25, t 以分钟计, b = 节省率(%)
```

同页给出的简化指数形式与**重要警告**：

```
R = e^(-t/S)        R=可提取性, S=记忆稳定性, t=时间
```

> Wikipedia 明确写：「Simple equations such as this one were **not found to provide a good fit**
> to the available data.」——**不要直接用纯指数**。

**（B）SM-2 间隔调度公式**（1987，Wozniak 原文，可直接抄）
来源：<https://www-beta.supermemo.com/archives1990-2015/english/ol/sm2>

```
I(1) := 1
I(2) := 6
I(n) := I(n-1) * EF          (n > 2, 单位：天，小数向上取整)

EF' := EF + (0.1 - (5-q) * (0.08 + (5-q) * 0.02))
其中 q ∈ {0..5} 为作答质量；q=4 时 EF 不变；EF 下限 1.3；初始 EF = 2.5
```

同一页面给出作者自测数据：学习 10255 条、每天 41 分钟、**总保留率 89.3%**，
剔除 3 周内的新条目后 **92%**（作者自报告，非独立复现）。

**（C）FSRS 的 R(t,S) 与间隔反解**（开源、可解释、无需训练；最推荐抄形状）
来源：<https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm>

FSRS-4.5 遗忘曲线（`R=0.9` 当 `t=S`）：

```
R(t,S) = ( 1 + FACTOR * t/S ) ^ DECAY
   FSRS-4.5: DECAY = -0.5, FACTOR = 19/81
   FSRS v4 : DECAY = -1,   FACTOR = 1/9

反解目标保留率 r 的间隔：
I(r,S) = (S / FACTOR) * ( r^(1/DECAY) - 1 )
```

FSRS-6 把衰减变成可训练参数（`w20`）：

```
R(t,S) = ( 1 + factor * t/S ) ^ (-w20)
factor = 0.9^(-1/w20) - 1        （保证 R(S,S)=90%）
```

**成功提取后稳定性如何增长**（FSRS v4，最接近 Bjork「提取使强度上升且与 R 成反比」的量化版）：

```
S'_r(D,S,R,G) = S * ( e^w8 * (11-D) * S^(-w9) * (e^(w10*(1-R)) - 1)
                      * w15(if G=2) * w16(if G=4) + 1 )
```

该页给出四条性质（**这就是可直接用的工程结论**）：
1. D 越大，稳定性增量越小；
2. S 越大，稳定性增量越小（越高越难再提高）；
3. **R 越小，稳定性增量越大 —— 间隔效应（spacing effect）的量化形式**；
4. 成功复习时增量恒 ≥ 1。

### 1.3 映射到本项目（建议，不是代码）

| 理论量 | 本项目的候选载体 | 用法 |
|---|---|---|
| storage strength | `memories.importance` + 被使用次数（见下） | **只增不减**的排序基底 |
| retrieval strength | `last_recalled` 派生的时间衰减项 | **仅参与排序**，永不用于删除/降权 |
| 提取增益 | 每次被真正采用（被想起/被提起/被兑现） | 增量与 `(1-R)` 成正比 |

关键判断：**`last_recalled` 是 RS 的载体，而它 2026-09 起生产不再被调用（第 11 轮已修回写）**。
在它恢复之前，任何基于 RS 的公式都是空转——这正是本仓教训 #41「监控一个恒为常量的量等于没有监控」的同族。
落地前必须先确认该字段**真的在变**（对比两个时间点的分布，而不是看代码里有赋值语句）。

### 1.4 不能照搬的部分

- **RS 的「衰减」绝不能接淘汰/降权分支**。SM-2 的「q<3 就从 I(1) 重来」是为学习卡设计的，
  本项目没有「重学」动作，接上去等价于变相遗忘。
- **不要用纯指数 `R=e^{-t/S}`**（Wikipedia 明确说拟合差），要用幂律（FSRS-4.5 形状）。
- FSRS 的 **D（difficulty）没有对应物**：它衡量「卡片本身有多难」，而对话记忆的「难度」
  取决于检索语境而非内容本身；强行映射会引入不可解释的参数。

## 2. 问题二：前瞻记忆（prospective memory）——「还没做的事」怎么被想起来

### 2.1 核心概念

**定义**：记住在未来某个时点执行某个计划动作，即「记得去记得」（remembering to remember）。
与回溯记忆的区别是它关心**何时做**而非**做什么**。
来源：<https://en.wikipedia.org/wiki/Prospective_memory>

**两分法**（本项目最需要的切分）：

- **event-based PM**：当特定情境出现时执行（路过图书馆想起还书）；
- **time-based PM**：在特定时刻执行（看到 22:00 想起追剧）。

**实证结论（定性）**：event-based 表现**优于** time-based，且「外部 cue 比内部 cue 更能触发动作」——
Sellen et al. (1997) 实验，转引自 Wikipedia 同页。

### 2.2 三个理论，哪个能工程化

| 理论 | 一句话 | 工程可用性 |
|---|---|---|
| PAM（preparatory attentional and memory） | 意图需要持续占用注意资源去监控 | **低**——要求常驻监控，成本高，且被 Reese & Cherry (2002) 反证（仅 2% 被试在被打断时还在想原意图） |
| reflexive-associative | cue 与动作之间形成关联，cue 出现→自动联想唤起 | **高**——这就是「cue 设计」的理论基础 |
| multi-process（McDaniel & Einstein 2005） | 监控与自发提取并存，多数日常场景靠自发提取 | **最高**——允许「不常驻监控、靠 cue 触发」 |

来源：以上三条均见 <https://en.wikipedia.org/wiki/Prospective_memory>（含 PAM 的 2% 反证数据）。

### 2.3 cue 设计的可工程化清单

multi-process 框架给出的**自发提取四条件**（转引自 Wikipedia 同页）：

1. **cue 与目标动作高度关联**；
2. **cue 显著**（salient）；
3. 期间进行的**其他加工会把注意引向 cue 的相关特征**（task appropriate processing）；
4. **目标动作简单**。

→ 对本项目的直接含义：想让糖糖「在合适时机提起未完成的事」，必须让「线索」出现在
**正常对话流里**（提到的人、地点、时间、事件词），而不是仅靠定时器在固定时刻推送。

**提醒（reminders）的作用**：McDaniel et al. (2004) 发现「延迟执行」任务中，
打断/插入任务会损害正确率，而**给提醒可以消除这种损害**（转引自同一 Wikipedia 页）。
→ 含义：不需要「让她更小心」（本仓教训 #2 禁止的修法），只需要**在被打断的语境里补一次 cue**。

### 2.4 自然情境下的真实预测因子（最有价值的一张表）

Rummel et al. (2022), *Prospective memories in the wild*（预注册田野研究：让被试列出未来 5 天
的意图，5 天后回报哪些真的完成了）
来源：<https://pmc.ncbi.nlm.nih.gov/articles/PMC9765353/>

显著预测因子（原文 Discussion）：

| 因子 | 方向 | 可否工程化 |
|---|---|---|
| 主观重要性（perceived importance） | 越重要越易完成，**重要性排名第一** | 可 → `importance` 权重 |
| 是否使用外部记忆辅助（external memory aids） | 用了更易完成，**排名第二** | **可 → 这就是「AI 帮人记事」的合法性依据** |
| 意图的社会价值（social value） | 有社会价值更易完成 | 可 → 涉及他人的承诺加权 |
| 距形成日天数 | 越长越难完成 | 可 → 时间衰减项 |
| 意图相关思维频率 | 想得越多完成越多（但相对重要性较低） | 可 → 反思/自忆时复述承诺 |

原文还报告：**59% 的未来导向思维指向 24 小时内**的事件；**45% 的未来思维**发生在
「正在形成新意图或更新旧意图」时。→ 含义：主动提起的最佳窗口在**近期**，而不是久远的事。

### 2.5 未找到的部分（诚实标注）

- **前瞻记忆完成率的绝对百分比**：本调研未找到可靠、可引用的数字。
  Rummel 2022 的主效应是**相对预测力**（回归系数/优势分析），摘要与正文未给总体完成率百分比。
  → 需要该数字时，**不要编**；若要，应回到原文 Table 1/附录表取数（本调研未获取）。
- 实验室 PM 任务的典型正确率区间：未找到权威来源（检索到的 Aberle 2010 / Koo 2021 是年龄差异研究，
  摘要未给可直接引用的一般人群基线）。

### 3.2 哪些指标可以搬进本项目当判据

按「本项目有没有对应物」筛：

| 指标 | 定义 | 本项目映射 | 建议 |
|---|---|---|---|
| **命中率（Recall@k）** | 标注为「该被提起」的条目，有多少进了候选 | 记忆检索 `recall()` 的候选集 | 必上，作为主指标 |
| **时间推理准确率** | 能否正确归因「哪天/多久以前」 | 自忆/记忆块里的日期前缀 | 必上（本仓第 8/10 轮已暴露时间元数据问题） |
| **跨会话一致性** | 同一事实两次提及不矛盾 | 画像/事实簇 vs 记忆 | 可上，但要防「复读」 |
| **abstention（该说不知道就说不知道）** | 材料里没有时不编 | 反面即**幻觉率 = 1 − abstention** | 必上，本仓教训 #22 已有「材料外细节不编」契约 |
| **知识更新** | 新信息覆盖旧信息 | `status=superseded/retracted` 机制 | 已有基建，可接入评测 |
| **成本（token / p95 延迟）** | 每次召回的开销 | 上下文预算 + 注入块 token 日志 | 必上（本仓 #40 已证「同预算装几条」才是效率） |

**不建议搬的**：BLEU/ROUGE 这类 n-gram 相似度——本项目的产出是「自然提起」而非「复述答案」，
n-gram 分数会把「说得好」和「记得对」混在一起。

## 4. 问题四：「胜过人的记忆」怎么量化

### 4.2 B 类：**合理推断**（明确标注，不当证据用）

1. **「与人相当」的守诺基线可以取 54%–63%**：这是人类在「有承诺、有兴趣、可验证」条件下的兑现率。
   若糖糖对「承诺过的事」在合适时机提起并兑现的比率进入该区间，可称「与人相当」。
   —— 推断：人类守诺实验的任务是**单次、明确、短期**的，陪伴场景的承诺更模糊、跨度更长，
   真实人类基线大概率**低于** 63%。
2. **「胜过人」只能在有数字的维度上定义**：守诺兑现率、跨天不遗忘（对照遗忘曲线）、
   承诺措辞效应（22%→63%）。**「检索命中率」没有人类对应基线**——人类不会被要求
   「从 10 万条记忆里 Recall@5」，任何阈值（0.8 / 0.9）都是工程约定，不是「胜过人」。
3. **24 小时遗忘约 67%** 可以反向用作「AI 应该做得更好的地方」：如果一条记忆 24 小时后
   仍然可被准确检索，那在这个维度上就胜过了 Ebbinghaus 曲线描述的普通人。
   —— 推断：Ebbinghaus 测的是无意义音节，日常有意义事件的遗忘**慢得多**，这个对比是宽松的。
4. **「该提起时提起」的召回率目标**：建议先测出当前实际值，再谈目标；在拿到基线前设任何
   绝对阈值（如 ≥80%）都属于拍脑袋。

### 4.3 统计口径

本调研共 4 个问题、约 **18 条**明确结论：其中 **11 条**有可点击文献来源支撑
（含 4 条「二手转述」标注）、**4 条**标为合理推断、**3 条**标为「未找到可靠来源」。
大致比例 ≈ **有文献支持 61% : 推断/缺口 39%**。

## 5. 用不上 / 别照搬的

1. **把 RS 衰减接进降权/淘汰**——这是 SM-2/FSRS 的默认用法，但在本项目等价于**变相遗忘**，
   直接违反主人 2026-10-25 的价值决策。RS 只能用来看「此刻多容易取出」，不能用来判「该不该留」。
2. **SM-2 / FSRS 的整套复习调度**——它们的隐含前提是「每个条目都要被反复复习到记住」，
   需要用户配合复习。本项目没有「复习」这个动作，只有「被检索/被使用」。**只借曲线形状，
   不借调度器**。
3. **MemGPT 的 OS 分页 / 上下文换出（eviction）**——把记忆换出快慢两级，本质是有损的，
   与「不做遗忘」冲突。
4. **Mem0 的自动 update/delete 合并**——它会把新事实写回并删改旧条目，**丢原文**。
   本仓已有 `status=active/retracted/superseded` 的真值生命周期，不需要再叠一层不可审计的自动改写。
   来源：<https://arxiv.org/abs/2504.19413>（摘要：dynamically extracting, consolidating,
   and retrieving）。
5. **A-MEM 的 memory evolution**（新记忆自动改写旧记忆的上下文属性）——会让历史表示被覆写、
   不可追溯，与本仓「真值生命周期 + 纠正可撤销」的治理工程冲突。
6. **需要重训/微调模型的方案**（BGE 微调、reranker 训练、FSRS 参数拟合到个人数据）——
   本仓没有训练管线，且训练数据量不足；会引入不可控变量。**用现成开源参数即可**。
7. **任何「按比例删减 / 类型限流 / 抑制记录」的工程实践**——红线，即使论文里有效。

## 6. 待主诊医师裁定的接口（只写建议，不写代码）

> 每条都是「如果采纳，需要改哪个模块的哪个行为」。请主诊医师逐条裁定采纳/否决/延后。

1. **`agent/memory.py` 的 retrieval strength 计算方式**
   若采纳幂律衰减，需要决定：RS 用 FSRS-4.5 形状（`R=(1+19/81·t/S)^-0.5`）还是更简单的分段衰减；
   以及 `S`（稳定性）从哪个字段派生——现在没有这个字段，只有 `last_recalled`。
   **风险**：`last_recalled` 刚从「9 月起重构掉了调用点」修好（第 11 轮），先确认它真的在变，再谈公式。

2. **「未完成事项」的存储形态**
   前瞻记忆需要一个「意图」实体：内容 + cue + 到期条件 + 是否兑现。
   需要裁定：是在 `memories` 表加列（改动小，但要动 `agent/store.py` 的迁移与所有消费方），
   还是新建独立表（干净，但要动检索链路）。**这条决定后面所有评测怎么标。**

3. **「主动提起」的触发点归谁**
   是接进 `interjection.py` 的评分（与现有主动插话配额共享），还是独立定时器 + cue 扫描。
   需要裁定：走前者会消耗插话配额，可能挤掉「想说话」；走后者会新增一条并发写路径。

4. **评测闸门的形态与成本**
   是否在 `tests/` 增加固定标注集 + 命中率/时间推理/幻觉率回归（参照 LongMemEval 五能力切分）。
   需要裁定：**允不允许用 LLM-as-judge**（LoCoMo/Mem0 都用它），因为这会引入非确定性，
   与本仓「测试必须可复现」的纪律冲突；替代方案是人工标 100~200 条做金标。

5. **`last_recalled` 的语义边界**
   目前它是「被检索到」，但 Bjork 的 RS 更新要求的是「被**成功提取使用**」（被想起/被提起/被兑现）。
   需要裁定：是否区分「进了候选」和「真的被用上」两个信号——
   这直接决定 RS 的更新方向，也决定「高价值」的判定路径（主人已定：只看它有没有真被用上）。
