## 边界与未决项

1. 单次快照不等于真实生产 2h/12h 认证；2 小时观察器已于 04:05 启动，PID `21724`，输出为 `artifacts/production_monitor/observer-20260828-040545.*.log`。
2. v2 `event_key` 已纳入消息类型、作用域、事件时间、行为者与平台消息 ID；无平台消息 ID 的事件不制造假键。平台没有提供比这些字段更强的全局 UUID，因此极端同秒完全复用仍是可接受且需监测的边界。
3. quarantine 依据 batcher 的确定性前缀匹配，标记可回滚；任何“全部历史已净化”的结论必须以运行时计数重新验证。
4. 当前 Qt 控制台仍持有旧日志文件，导致本次轮转降级为续写；数据面已恢复，但控制台持锁来源仍列为待验证运维债务，不能把降级当作正常轮转成功。
5. 当前日志不可写缓冲是进程内有界缓冲；若磁盘/权限故障持续到进程崩溃，尚未补写的记录仍可能丢失。控制台输出与告警可帮助发现，但长期方案仍应消除共享文件锁。
