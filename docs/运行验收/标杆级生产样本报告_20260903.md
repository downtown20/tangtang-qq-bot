## 未触发/待采样清单

- 真实确定失败、迟到确认、重复送达的 ADR-005 回放；保持 feature-off，不制造失败。
- scheduler/autonomy/birthday 主动事件及引用开窗的完整生产 lifecycle。
- H2/H6-R3 后的聊天图片、唱歌、定时图片、CG 实际 receipt；其中 `/唱歌` command 仍走 legacy wrapper，不能纳入新链路成功数。
- 亲密模式 CG 的“工具目录出现→实际 ActionPlan”样本。
- H5-R2 驱动力有界保存、feedback cursor 的新 boot ≥12h 样本。
- 窗口 `reply/skip/fade` 每类 ≥100；语音 A/B；事件循环/embedding/网络/outbox 的端到端 p99。

## 使用规则

1. 新样本必须记录 boot/时间窗、触发、实际用户可见结果、脱敏日志和只读 DB/receipt 状态。
2. “未触发”与“INSUFFICIENT”不是通过；“confirmed”必须有真实 receipt 或平台确认。
3. 生产自然样本应追加到本报告或继任版本，不能回写为虚构的 H8 数字。
