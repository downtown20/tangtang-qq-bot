# 标杆级能力评分（2026-09-03）

> 版本：H8 发布回填。评级只使用“达成 / 部分 / 未达成”，不以源码存在、离线探针或端口在线替代真实运行。晋级标准来自已归档的[标杆级工程计划](../开发规划/归档/标杆级工程计划_20260828.md)。最新正式质量门禁是主负责人 H7 复跑的 `1882 passed, 3 warnings, 265.77s`（[`裁决_H7.md`](../协作/rulings/裁决_H7.md)），不是本报告重跑所得。

## 总览

| Phase | 晋级标准 | 判定 | 结论 |
|---|---|---|---|
| 0 工程底座 | 观察器从日志和只读 DB 还原请求完整生命周期，且不保存正文、QQ、群号 | **达成** | H1 的脱敏 `interaction_lifecycle` 和生日主动路径通过主负责人独立复核。持续运行覆盖仍按后续阶段风险跟踪。 |
| 1 消息与副作用可靠性 | 重投、发送超时、强杀、工具二次回合均有确定性测试与回放报告 | **达成** | H4/H7 故障矩阵覆盖上述恢复/死信边界；但 `/唱歌` 仍有旧 wrapper 直达路径，影响“所有媒体已统一”的更高主张。 |
| 2 记忆真值与长期容量 | 黄金集全绿；真实窗口积压不发散、最老任务年龄下降；未知记忆不入可信注入 | **部分** | 黄金集 70/70、legacy trusted selector=0 已达；生产服务率/最老年龄的长期收敛和 lock/embedding 证据不足。 |
| 3 单脑自治与关系状态 | 各类真实样本 ≥100，再每次只调一个变量；无刷屏/重复打扰/反馈错配 | **未达成** | 统计和有界持久化已修复，但自然样本量未达门槛且本阶段未做自治调参。 |
| 4 多模态与体验 | 每功能域具成功/失败/未触发三态证据，不能用服务端口替代端到端 | **部分** | typed receipt 迁移与六域 canary 清单具备；真实六域 canary、语音 A/B 未完成，且 `/唱歌` 命令仍走旧路径。 |
| 5 性能、容量与运维 | ≥12h soak 中 service_rate > arrival_rate，积压/最老年龄下降，前后台延迟满足 SLO | **未达成** | 已有 SQLite/隔离 outbox/LLM 基线、九域故障演练与 runbook；关键 p99 和 ≥12h 因果观测仍缺。 |

**发布结论：工程资料可发布，标杆认证不可发布。** Phase 0–1 的既定晋级证据已形成；Phase 2–5 仍受真实样本、长期容量和可观测性门槛限制。

## 逐项证据

### Phase 0：达成

- **标准**：观察器可从日志和只读 DB 还原完整生命周期，且脱敏。
- **证据**：[`裁决_H1.md`](../协作/rulings/裁决_H1.md) 确认 `ReadOnlyStore.get_runtime_observer_snapshot()` 的入站→聊天→DecisionRun→确认动作关联只输出计数，不输出 event key、正文、QQ、群号、run id 或回执载荷；生日路径按 `record → claim → executing → LLM → DecisionRun → bind → send → finish` 走主动状态机。H1 定向 151 项与全量 1863 项门禁已由主负责人确认。
- **边界**：Phase 0 的长期观察政策仍需以单 boot 窗口补样本；这不推翻已达成的“生命周期可还原且脱敏”晋级标准。

### Phase 1：达成（但媒体统一边界存在已知例外）

- **标准**：重复投递、发送超时、进程强杀、工具二次回合具确定性测试与回放报告。
- **证据**：[`裁决_H4.md`](../协作/rulings/裁决_H4.md) 确认提取链路 429/5xx/超时/非法 JSON/空/断线、半写、kill、过期 lease 的恢复矩阵；[`裁决_H7.md`](../协作/rulings/裁决_H7.md) 确认 LLM、数据、网络、发送中 kill、结算 pre-commit kill 九域故障矩阵 `passed=true`。H2/H6-R3 已为聊天图片、CG、唱歌主路径、定时图片建立 typed ActionPlan/receipt。
- **已知例外**：`agent/handler_commands.py:1354` 的 `/唱歌` 仍调用 `_send_singing_reply`，未走 `_send_singing_actions`；详见[风险登记](标杆级风险登记_20260903.md)。这不否定上述故障测试门槛，但禁止把 Phase 1 表述为“所有媒体路径已经统一”。

### Phase 2：部分

- **已达成**：[`裁决_H3.md`](../协作/rulings/裁决_H3.md) 确认七维黄金集 70/70；只读存量清点为 legacy 12090、`legacy_in_trusted_selector=0`、synthetic chat 14065 且全 quarantined；离线 `legacy→verified→legacy` 回退演练通过。
- **未达成部分**：[`裁决_H4.md`](../协作/rulings/裁决_H4.md) 的生产快照虽为 5389 done/0 open，但缺显式 lock-wait 和 embedding 预算，观察窗口的全部积压为 deferred，不能从 `created_at→updated_at` 外推 worker 服务率或最老任务年龄趋降。

### Phase 3：未达成

- **已完成基础**：[`裁决_H5.md`](../协作/rulings/裁决_H5.md) 确认 `DecisionRun` 终态是窗口分类的单一来源；H5-R2 将 drives 变更的重启丢失控制为有界，并将 feedback 读侧改为可推进 id cursor。
- **缺口**：计划要求 `reply/skip/fade` 各至少 100 条真实样本后才调整一个变量。[`阶段总结_20260902.md`](阶段总结_20260902.md) 仍将窗口自然度采样列为待办，故本报告不把代码或少量 canary 外推为自治质量认证。

### Phase 4：部分

- **已完成基础**：[`裁决_H2.md`](../协作/rulings/裁决_H2.md) 确认图片、唱歌、回合 ordinal 与 CG 资产映射的迁移；[`裁决_H6-R2.md`](../协作/rulings/裁决_H6-R2.md) 确认定时图片保持“配文+图一条 QQ 消息”的用户可见行为并写 terminal receipt。[多模态 canary 清单](多模态canary清单_20260903.md) 已为知识、识图、角色、语音入/出、唱歌提供触发、取证和三态判据。
- **未达成部分**：六域真实 QQ canary 和语音 A/B 尚未执行；`/唱歌` 旧 command 路径是尚未统一的实际调用点。

### Phase 5：未达成

- **已完成基础**：[`裁决_H7.md`](../协作/rulings/裁决_H7.md) 确认 SQLite 读 p95=56.8ms、隔离 8-worker 的 LLM p95=517.911ms/锁等待 p95=259.706ms、九域故障矩阵和六节 runbook；本批未据此调参。
- **未达成部分**：事件循环、embedding、网络发送、outbox 端到端尚无 p99；也没有满足 `service_rate > arrival_rate`、积压与 oldest age 下降的 ≥12h 单 boot soak。故不能宣称满足路线图 SLO。

## 评分使用约束

- 这是 2026-09-03 的证据快照；任一新 boot、配置、迁移或外部依赖改变后，应重新取样。
- `待 canary` 与 `未达成` 不是失败归因；它们表示现有材料不足以满足对应晋级标准。
