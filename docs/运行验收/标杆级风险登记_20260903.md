## 优先处理原则

1. 先让 R1 的代码在可控 boot 加载，并在不制造失败的前提下收集 R2/R3/R5 自然样本。
2. R4 需要单独的行为迁移授权；它不是“删除死代码”清理。
3. R7 的观测先于任何性能调参；R8 历史记录不用于当前故障率推断。

## 发布边界

本登记不要求打开 feature flag、重启 bot、写入生产数据库或删除任何代码。它只定义每类风险的可验证关闭条件。
