## Minecraft 基础入门

Minecraft（我的世界）是 Mojang 开发的沙盒游戏，核心玩法：生存、建造、探索、红石、战斗。分为 Java 版和基岩版。

**开局生存第一步**：
1. 先撸树：空手打树干获得原木
2. 做工作台：背包里四格合成，原木→木板→工作台
3. 做木镐：工作台里木板+木棍
4. 挖石头：用木镐挖至少 3 块圆石
5. 做石镐+石斧+石剑+熔炉
6. 天黑前搭个庇护所（泥土/木头都行，插火把防刷怪）

**第一天天黑前清单**：
- ✅ 工作台 + 熔炉
- ✅ 石制工具三件套（镐斧剑）
- ✅ 至少 10 个火把（木炭=熔炉烧原木）
- ✅ 简易庇护所（5×5 方块空间，有门）
- ✅ 食物（杀猪/牛/羊，肉放熔炉烤熟）
- ✅ 一张床（杀 3 只羊拿羊毛+木板）

## Minecraft 进阶技巧

**挖矿指南**：
- 钻石在 Y=-58 层最多（1.18+ 版本）
- 鱼骨挖矿法：主通道 + 每隔 2 格开分支
- 铁在 Y=16 层最多，铜在 Y=48 层
- 远古残骸（下界合金）：下界 Y=15 层，用床炸最快
- 必须带：至少 3 把铁镐、64 个火把、食物一叠、水桶

**附魔攻略**：
- 效率 V + 精准采集 → 挖矿用
- 效率 V + 时运 III → 刷钻石用
- 锋利 V / 亡灵杀手 V → 战斗用（亡灵杀手专门打僵尸骷髅凋零骷髅）
- 保护 IV → 全套盔甲必备
- 经验修补 → 最优先，配合经验农场装备永不报废
- 村民交易是获取顶级附魔书的最快途径，刷图书管理员直到出好书

**村民交易 & 刷铁机**：
- 僵尸村民可用虚弱药水+金苹果治愈，交易价格大降
- 图书管理员 → 附魔书（反复拆放讲台刷新交易）
- 农民 → 南瓜/西瓜换绿宝石
- 造铁机：3 个村民 + 1 只僵尸恐吓 → 无限刷铁傀儡

**地狱交通快速出行**：
- 地狱 1 格 = 主世界 8 格
- 主世界坐标 ÷ 8 = 地狱对应坐标
- 在地狱顶层（Y=120+）挖冰道 + 船，时速可达 70m/s

## Minecraft 红石入门

**基础元件**：
- 红石粉：传输信号，最多 15 格
- 红石火把：信号源 + 非门
- 中继器：延长信号 + 延迟（右键调档 1-4 tick）
- 比较器：检测容器满度 + 信号减法
- 观察者：检测前方方块更新，输出 1 tick 脉冲

**实用电路**：
- 自动门：压力板 + 红石通到门下方
- 自动瓜田：观察者对向瓜的位置 → 连到活塞
- 物品分类机：漏斗链 + 比较器检测 + 红石锁漏斗
- 2×2 活塞门：4 个粘性活塞 + 红石线路（需要一点时序）

**刷怪塔原理**：
- 利用高度落差或水流把怪集中
- 离玩家 24-32 格才会刷怪
- 刷怪上限 70 只，用火把压制周围洞穴提高效率
- 最佳刷怪高度：Y=-54 以下的洞穴刷怪场（1.18+）

## Minecraft 建筑技巧

**基础比例**：
- 门高 2 格 → 房间层高至少 3-4 格才不压抑
- 墙壁厚度：大型建筑用 2 格厚墙更有厚重感
- 屋顶：楼梯+半砖交替做出层次
- 柱子间距：奇数间距（3/5/7）做对称更方便

**装饰技巧**：
- 用楼梯、半砖、活板门增加表面细节
- 不同木材混搭做出层次感
- 树叶块当灌木丛，骨粉催花草点缀
- 画框 + 压力板/按钮 = 伪家具
- 地毯盖在光源上隐藏火把/萤石
- 深板岩 + 凝灰岩 + 苔石混搭 = 废墟风

**常用调色板**：
- 中世纪：橡木原木 + 白桦木板 + 石砖 + 深色橡木楼梯
- 现代风：石英 + 白色混凝土 + 玻璃板 + 深色橡木
- 日式：深色橡木 + 砂岩 + 云杉木活板门 + 杜鹃树叶
- 暗黑风：深板岩 + 黑石 + 玄武岩 + 灵魂灯笼

## Minecraft Boss 攻略

**末影龙**：
- 带：满附魔钻石/下界合金装备、弓箭（力量 V + 无限）、缓降药水、金苹果、末影珍珠、水桶
- 先射水晶（铁栏杆保护的从侧面射），等龙栖息时近战输出
- 龙息伤害很高，别站紫色粒子里
- 用床炸龙有奇效（只在龙靠近时放），但会炸到自己

**凋零**：
- 最安全的打法：在地下 Y=-54 层狭窄隧道里召唤，凋零会被卡住
- 先射到半血（半血后免疫弓箭），然后用剑近战
- 凋零效果 = 持续扣血，带牛奶桶解
- 召唤需要的凋零骷髅头：下界要塞刷，用抢夺 III 剑提高掉率

**循声守卫（Warden）**：
- 不打死也能通关，潜行绕过去是最优解
- 如果硬刚：保护 IV 全套、力量 II 药水、金苹果拉满
- 远程用弓消耗，但 Warden 有音波攻击穿墙
- 每 7 秒只能攻击一次，利用间隔输出

## Minecraft 常见问题

**Q: 找不到钻石？**
Y=-58 层鱼骨挖，用效率 V 镐。或者去大型洞穴和废弃矿井，钻石裸露概率高。实在找不到就村民交易钻石装备。

**Q: 附魔怎么效率最高？**
造村民交易大厅 + 刷铁机 → 无限绿宝石 → 从图书管理员买附魔书 → 铁砧组合。比附魔台快几十倍。

**Q: 被苦力怕炸家怎么办？**
睡前必插满火把。养猫（苦力怕怕猫）。重要建筑周围铺半砖防刷怪。

**Q: 怎么快速升级（经验）？**
- 末地小黑塔：最简单有效的经验农场
- 猪人塔：下界金块上方的猪人自动农场，经验+金子双收
- 仙人掌经验炉（基岩版）：熔炉经验存储，一次取可升几十级

**Q: Java 版和基岩版选哪个？**
- Java 版：模组多、红石逻辑更精确、社区大
- 基岩版：跨平台联机（手机/PC/主机互通）、性能好
- 和小伙伴联机建议统一版本即可
