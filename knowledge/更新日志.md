## 2026-07-27 — 记忆系统：从关键词到 Tool Calling

### 问题
糖糖对高亲密度群友频繁编造记忆——把游戏内容当成真实回忆说出来。根源：LLM 不知道自己的记忆边界。

### 方案演变（七次迭代，一次范式转换）
关键词匹配 → n-gram调参 → jieba 分词 → BGE 语义向量 → 关系档案 → 被动注入 → **Tool Calling**

前六步都在优化同一个前提：「系统替 LLM 决定该查什么」。第七步换了一个范式：「LLM 自己决定查什么，自己去查」。

### Tool Calling（核心更新）
- DeepSeek V4 原生 function calling，`tool_choice: "auto"`
- LLM 收到 `search_chat_history` 和 `search_memories` 两个工具
- LLM 自己判断要不要查、查什么——系统只负责执行
- 无门槛：群聊私聊、任何亲密度都可用

### 记忆系统其他更新
- **自贬过滤**：`auto_learn` 不再存储「我是废物」「我是坏孩子」等自我否定陈述
- **置信度过滤**：`extract_semantic_memories` 丢弃 confidence<0.5 的记忆
- **合成记忆降权**：LLM 推断的 profile/fact 以 importance=4 存储（之前是 8-9）
- **聊天记录质量过滤**：`get_earliest_chats` 扫描前50条，过滤纯图/单字寒暄
- **按需检索**：`search_chat_history` 剥离 CQ 码，过滤短句，去重后最多 8 条

### 关系档案系统
- 每 80 条私聊触发一次 LLM 合成
- 存储「我和这个人的关系是怎样的」：怎么认识的、喜欢什么称呼、有什么偏好
- 每轮对话注入 system prompt，形成稳定认知

### 中文分词：jieba 替代 n-gram
- 知识库关键词提取改用 jieba 分词
- 插话关键词检测改用 jieba 词边界匹配
- n-gram 产生的垃圾关键词不再出现

### 心情追踪
- StructBERT 模型，仅追踪挂了「心理陪伴」场景的用户
- 每日平均分，三种告警：连续3天走低、单日骤降、持续低迷

### 其他
- 好友/群邀请自动处理
- `_allowed_groups` 初始化排除黑名单
- 角色卡更新：自称「我」或「糖糖」，老群友从容人设
- 配置修复：interjection_thirst 0.4，mood 阈值修复

### 新增文件
- `agent/embeddings.py` — BGE 语义向量引擎
- `agent/mood_tracker.py` — StructBERT 心情追踪
- `agent/relationship.py` — 关系档案管理器
- `knowledge/丛雨风格_对话范例.md` — H 场景参考

### 删除
- `_llm_intent_recognition()` — 被 CMD 标签协议替代
