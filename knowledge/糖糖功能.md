## 聊天与主动行为能力

糖糖的社交功能和主动行为，像个真人在群里：

**聊天互动**
- 在群里自然聊天，会主动插话（基于提问、消息长度、亲密度等客观信号，不用关键词）
- 被 @ 或提到名字优先回复
- 记得每个人的事——用结构化记忆系统，按人×主题整理事实（健康、喜好、经历、关系等）
- 对话中自动检索记忆——优先查事实簇，找不到再搜聊天记录，认真回应不编造
- 对每个人有不同亲密度，越熟越亲近
- 能感知情绪——从上下文理解，不用关键词判断
- 自己也有心情——三维模型（精力/心情/耐心），自然波动

**主动行为**
- 💌 私聊主动关心：按亲密度和活跃度调频（活跃的每天可聊一次，冷场的少打扰），心情告警优先
- 🖼 定时分享自己图库（share_images/）里设定的图，自己配文
- 👍 回复后自动点赞，高亲密度还会戳你

## 工具技能能力

糖糖能帮群友解决实际问题的工具：

- 🕐 **获取时间**：知道现在几点、星期几、日期
- 🌤 **查天气**：查任意城市实时天气（温度、湿度、风速）
- 🌐 **联网搜索**：糖糖自己判断要不要搜——对话式提问（"你能看到吗"）不搜，需要实时信息（"今天天气"）才搜
- 🧮 **精确计算**：大数乘除、乘方开方，比 LLM 心算准
- 📐 **单位换算**：温度/距离/重量/体积/面积/速度/货币（50+ 种）
- 🌍 **翻译**：多语言互译
- 🖼 **分享图片**：分享自己图库（share_images/）里设定的图，自己配文
- 🔮 **抽签占卜**：求签、塔罗牌
- 🎮 **猜数字**：陪群友玩猜数字小游戏
- 🎤 **唱歌**：41 首有录音的歌，每首双版本——糖糖声线（默认）和原声（原唱）。说「原声/原唱」放原唱，不在列表里诚实说不会并推荐近似的
- 👁 **识图评价**：群友发图后糖糖自己决定是否评价——不再需要说特定关键词。台式机用本地识图模型，笔记本降级为云端识别
- 🎙 **语音回复**：糖糖自己判断什么时候发语音，可带情绪语气（开心/撒娇/温柔等 18 种）。台式机本地语音引擎可切糖糖/丛雨/米雪儿；糖糖和丛雨使用通用 V4，米雪儿使用专属模型。笔记本降级为云端单音色
- 🎤 **声音克隆**：通过控制台注册参考音频，糖糖就能用那个声音说话。中日英等任意语言均可
- 🔗 **引用回复**：能读到对方引用的消息内容——被引用时直接回应对应的话，不猜
- 📋 **合并转发**：群里转发的聊天记录，糖糖能读取内容了

## 记忆系统

三层架构，各司其职：

| 层 | 说明 |
|----|------|
| 事实簇 | 按人×主题整理的结构化事实——LLM 对话中优先检索这一层，准确不编造 |
| 聊天索引 | 14 万条清洗后的聊天记录 + BGE 语义向量——事实簇没结果时兜底 |
| 记忆碎片 | 零散偏好和事实——注入系统提示词做背景参考 |

糖糖在对话中通过 tool calling 自主检索记忆。新消息自动增量提取事实，不需要手动操作。

> 📖 详细技术文档：[记忆系统技术文档](记忆系统技术文档.md) —— 数据库设计、提取/合并流程、调参踩坑记录。

## 其他能力

- 📛 **黑名单**：不想要的群或人直接拉黑，群管理和私聊都支持
- 🖥 **桌面控制台**：可视化配置所有设置，不需要手写 YAML
- 🎂 **生日祝福**：`/生日 设置 MM-DD` 设置生日，当天糖糖自动在群里送上 LLM 生成的祝福
- 💓 **情绪引擎**：三维心情（精力/心情/耐心），提供原始数值给 LLM 自己决定语气
- 🎙 **语音控制**：任何人说「别发语音了」就能关掉，「可以发语音了」恢复
- 🧠 **心理陪伴**：可通过控制台为特定人启用心理解场景（短回复、不戏剧化、不追问创伤）

**主人/群主专属**
- 私聊自然语言遥控，不用打 `/` 命令
- 通知群发言、私聊某人、改人设、调行为
- 所有配置可在桌面控制台修改
