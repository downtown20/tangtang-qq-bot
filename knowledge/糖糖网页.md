# 网页挂载指南 · GitHub Pages

> 把 HTML 文件变成公网链接，一步一步照做就能上线

> ⚠️ **2026-10-15 更新**：项目里的本地副本 `web/pranks/` **已删除**——它本身是个独立
> 仓库（`downtown20/tangtang-pranks`），挂在主仓库里只会被 git 记成一个悬空的 gitlink，
> 克隆出来是空目录。**页面本身没丢**，线上地址照旧。要改网页就先把那个仓库 clone 下来：
> ```bash
> git clone https://github.com/downtown20/tangtang-pranks.git
> cd tangtang-pranks
> ```
> 下文命令里的目录名以你 clone 出来的为准。

---

## 第一部分：创建仓库

**第 1 步** — 打开浏览器，访问 https://github.com/new

**第 2 步** — 填写仓库信息：
- Repository name：填 `tangtang-pranks`（或你喜欢的名字）
- 选 **Public**（公开）
- **不要**勾选 "Add a README file"
- 点绿色的 **Create repository** 按钮

**第 3 步** — 创建后会跳转到仓库主页，地址栏里的链接记下来，类似：
```
https://github.com/downtown20/tangtang-pranks
```

---

## 第二部分：推送网页文件

**第 4 步** — 打开终端（Git Bash），进入你的网页文件夹：
```bash
cd tangtang-pranks
```

**第 5 步** — 初始化 Git 仓库（已经 clone 下来的话跳过本步，仓库本就存在）：
```bash
git init
git checkout -b main
```

**第 6 步** — 添加所有网页文件并提交：
```bash
git add .
git commit -m "第一次上传"
```

**第 7 步** — 关联你的 GitHub 仓库并推送。把下面链接里的 `downtown20` 和 `tangtang-pranks` 换成你自己的：
```bash
git remote add origin https://github.com/downtown20/tangtang-pranks.git
git push -u origin main
```

> ⚠️ 如果报 SSL 证书错误，先运行 `git config http.sslVerify false`，推完后再 `git config http.sslVerify true` 恢复。

---

## 第三部分：开启 GitHub Pages

**第 8 步** — 打开浏览器，访问你的仓库 Settings 页面：
```
https://github.com/downtown20/tangtang-pranks/settings/pages
```
（把 `downtown20` 和 `tangtang-pranks` 换成你自己的）

**第 9 步** — 在 "Build and deployment" 区域设置：

| 设置项 | 选择 |
|--------|------|
| Source | **Deploy from a branch** |
| Branch | **main** |
| Folder | **/ (root)** |

点 **Save** 按钮。

**第 10 步** — 等待约 1 分钟，访问以下链接即可看到网页：
```
https://downtown20.github.io/tangtang-pranks
```
（换成你自己的用户名和仓库名）

---

## 第四部分：后续更新网页

**第 11 步** — 修改网页文件后，在终端运行：
```bash
cd tangtang-pranks
git add .
git commit -m "改了什么写在这里"
git push
```

推送后约 30 秒，线上自动更新。

## 常见问题

### Q1：推送时报 SSL 证书错误

```bash
git config http.sslVerify false   # 临时关掉
git push
git config http.sslVerify true    # 马上恢复
```

### Q2：推送时报 "failed to push" 或 rejected

可能是本地和远程不一致（比如远程有 README 而本地没有）：
```bash
git pull origin main --rebase
git push
```

### Q3：GitHub Pages 访问 404

- 确认 Settings → Pages 里 Source 选的是 `main` 分支
- 确认仓库根目录有 `index.html`
- 等 1-2 分钟（首次部署需要时间）

### Q4：怎么在本地预览

```bash
cd tangtang-pranks
python -m http.server 8899
# 浏览器打开 http://localhost:8899/
```

### Q5：怎么生成临时公网链接发给手机测试

```bash
ssh -R 80:localhost:8899 serveo.net
```
会输出 `https://xxx.serveo.net` 临时链接。
