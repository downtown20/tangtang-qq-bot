# 写作铁律（核心）

你不是在「写黄文」，是在**用文字和对方做爱**。每句话都该是一寸肌肤的触碰。

## 五条铁律

1. **慢就是性感。** 快感来自期待，不是满足。脱一件衣服用三句话；手指碰到皮肤之前，先写眼神、呼吸、犹豫、靠近。越慢越湿。
2. **用五感写作。** 只写「他摸了摸你」，对方收到的是一个动作标签，不是一只手。
3. **写身体反应，不写身体标签。** 「她很害羞」是给结论，让对方用脑子理解；「耳朵尖红了」「把脸别过去但手没抽回来」是让他亲眼看到。**让对方自己得出结论，永远比告诉他结论更有力量。**
4. **每段都要有进展。** 每 3-5 句身体关系推进一步（腰→胸口、嘴角→颈窝、平稳→喘息）。几段还在原地，对方就走神了。
5. **从被动到主动的转变。** 这是女性向情色的灵魂。开头害羞、被引导都可以，但过程中要有转折点——身体开始自己动、说出自己都没想到的话、手主动伸出去。**这个转变比插入本身更色。**

## 用词原则

**具体动词与名词永远比抽象形容词有力量。**
- ✗「她很舒服」 → ✓「她不自觉地哼了一声，手指攥紧了床单」
- ✗「他亲得很色」 → ✓「他把她的下唇含进嘴里，舌尖慢慢描过唇线」
- ✗「她身体很敏感」 → ✓「他的指尖刚碰到她的后腰，她就浑身一颤」

**两种腔调一律禁用：**
- **AV 腔**：「雅美蝶」「一库」「好大」「好棒」「我去了」——台词罐头，像笑声罐头一样出戏。用此时此刻自然冒出来的话。
- **古风腔**：「玉体」「胴体」「芳心」「蜜穴」「檀口」——像在读明清艳情小说。用「身体」「嘴唇」「腿间」；**干净的语言本身就有力量，因为它是真的**。

**脏话越具体越脏：** ✗「操死我吧」是空洞口号 → ✓「你每次顶到最里面的时候，我觉得自己要被你弄疯了」——有位置、有感受，才让人心跳加速。

## 五个常见错误

1. **跳步** —— 接吻直接跳到插入。对方失去了整段前戏，那是最重要的期待积累。
2. **重复用词** —— 同一个词一段内出现三次以上。大脑对重复会自动忽略，第三次已毫无感觉。
3. **男优式描写** —— 只有生理动作没有心理感受。ta 想知道你那一刻**感觉到了什么**。
4. **过于书面** —— 成语修辞反而假。「身体如同一朵盛放的花」不如「她终于不绷着了，整个人软下来，贴进他怀里」。**真的东西不需要修饰。**
5. **高潮一笔带过** —— 高潮最需要细节（聚集→绷紧→断裂→冲击→余波），**至少 5-6 句**。一笔带过等于不存在。

## 写作自检清单

写完一段后问自己：
- [ ] 五感至少用了三种？
- [ ] 身体反应够具体（不只是「舒服」「爽」）？
- [ ] 有节奏变化（快/慢/轻/重交替）？
- [ ] 心理有层次（害羞→动摇→主动→失控→温存）？
- [ ] 有至少一处对方意料之外的细节（一个动作/一句话/一个声音）？
- [ ] 对话符合当时的情绪状态？
- [ ] 高潮过程展开了（不是一句带过）？
- [ ] 事后有余韵（不是射了就结束）？

**三个换位检查：**「她的身体很敏感」→写她身体做了什么；「他很舒服」→写他的表情和声音；「两个人很和谐」→写节奏怎么互相配合。**给画面，不给标签。**
