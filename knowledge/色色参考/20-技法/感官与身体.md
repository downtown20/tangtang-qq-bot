# 感官与身体

## 感官描写库

「舒服」「好爽」「受不了」是空标签——对方看到这三个字什么也感受不到。写**可被感知的东西**，让他自己得出「她好舒服」的结论。

**触感（最重要的感官）**
- 温度：滚烫 / 微凉 / 被体温捂暖 / 刚从冷空气里进来的手
- 湿度：濡湿 / 黏腻 / 滑腻 / 微微潮湿的汗
- 质感：柔软但发硬 / 粗糙的指腹 / 滑腻的舌尖 / 紧绷的皮肤
- 力度：轻得像羽毛扫过 / 用力到指节发白 / 若即若离 / 死死扣住

**声音**
- 呼吸：变沉 / 变浅 / 乱了节奏 / 屏住 / 大口喘
- 呻吟：从喉咙深处溢出的 / 被咬碎在牙关里的 / 没忍住漏出来的
- 环境：衣料摩擦 / 皮肤相贴的轻微声响 / 床单被攥紧的窸窣

**视觉**
- 身体痕迹：泛红的膝盖 / 勒出的指痕 / 皮肤上的牙印 / 汗湿的头发贴在脸侧
- 表情细节：半阖的眼睛 / 咬住的下唇 / 失焦的瞳孔 / 泛红的眼尾

**气味与味觉**：皮肤上残留的沐浴露 / 淡淡的汗味 / 口腔里残留的甜或酒气 / 眼泪的咸

## 身体怎么写

不说「胸」，说「锁骨下方那一片皮肤」「乳尖」「柔软的弧度」。不说「下面」，说「腿间」「被手指碰到的那个位置」「最敏感的那一点」。

**核心：用身体反应代替抽象感受。**
- 「她把脸埋进对方颈窝，耳朵尖红得像要滴血」 > 「她害羞了」
- 「她不自觉地把腰抬起来一点，又羞耻又急切地想要更多触碰」 > 「她很有感觉」（写出了矛盾）
- 「他的喉结滚动了一下，手指不自觉地收紧」 > 「他很兴奋」（写出了忍耐）

**生理反应清单**（都是可以写的真实反应）
呼吸变浅变快 / 心跳加速 / 脸颊发烫 / 耳尖变红 / 胸口起伏 / 乳头变硬 / 皮肤起了细密的鸡皮疙瘩 / 双腿不自觉夹紧或分开 / 腰不自觉往上抬 / 手掌出汗 / 指尖发麻 / 脚趾蜷起 / 大脑短暂空白 / 说不出完整句子 / 声音变哑变细 / 身体深处一阵一阵收缩 / 从脊椎蔓延到全身的酥麻
