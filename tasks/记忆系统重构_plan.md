# 千人长期记忆工程实施计划

**状态（2026-08-26）**：核心重构完成，功能门禁通过；真实 LLM 持续并发容量验收待执行。

## 目标

在约 1000 个不同 QQ 用户的群聊/私聊中，做到：作用域不串、派生事实有来源、正确时间可追溯、永久记忆不被自动破坏、崩溃可恢复、无关查询返回空，并让积压在持续流量下最终收敛。

## 决策与分工

- Codex：技术决策、全部业务代码、测试、迁移和交付。
- Claude Code：仅作为长期会话里的只读设计/反例助手，不修改项目。本轮恢复会话未在时限内产出结果，未将其视为验收证据。
- 只读子审查：源码/数据模型审查与 Reality Checker 发布门禁，不参与实现。
- 主人：产品目标和隐私/永久记忆语义仲裁。

## 实施结果

### Phase 0：契约与基线 — 完成

- [x] 冻结 `subject_qq + source_group_id + target_qq` 隔离模型。
- [x] 冻结 `verified/manual/corrected/legacy_unverified` 信任层。
- [x] 冻结 event/ingestion/validity 与 retention/status 正交语义。
- [x] 建立权限、负相关、崩溃、永久保留和千人合成验收。

### Phase 1：安全与真值 — 完成

- [x] 群/私原始历史、普通记忆、自忆、主动话题和生成型私聊全部显式绑定 scope。
- [x] 自动读路径只消费可信记忆；无来源存量保持隔离。
- [x] 群/私纠正只修改当前 scope，并按画像来源谱系置脏旧画像。
- [x] 旧反思整理退役为安全空操作，禁止 LLM 改写或物理删除记忆。

### Phase 2：事务提取与来源 — 完成

- [x] SQLite 持久化游标、冻结消息集合、租约、ready 重放、原子提交和 dead 重排。
- [x] 提取按 scope 分组、每 20 条确定性分块；父任务全部成功后才推进游标。
- [x] 证据验证绑定用户、会话和 bot/user 身份；event_time 取可信原文时间。
- [x] Episode 按 scope 聚合/存储/查询；旧无 scope Episode 隔离。
- [x] embedding 持续补齐；毒丸失败持久记录、指数退避且不阻塞后续 backlog。

### Phase 3：可拒绝检索 — 完成

- [x] 显式查询遍历完整可信作用域，消除 top-200 盲区。
- [x] 向量绝对阈值、jieba 词法负例、RRF 与相关性主导终排。
- [x] 无相关候选返回空；泛词重叠不再冒充记忆。
- [x] 检索返回来源、时间、置信度；群/私工具执行使用统一授权结果。

### Phase 4：规模与故障验收 — 部分完成

- [x] 1000 用户合成验收：隔离失败 0、召回失败 0、队列 1000/1000 完成。
- [x] 召回延迟：P50 1.66ms、P95 1.971ms、max 2.715ms。
- [x] 子进程强杀：ready 未半写；重启完成一次；再次重放 0 新增。
- [x] 695 项全量测试、undefined=0、迁移幂等复演、数据库 quick_check。
- [ ] 模拟真实 LLM 延迟的到达率—服务率 soak test。
- [ ] 多并发生产者、长时间运行下的 queue depth/oldest age 收敛验收。

## 未完成验收的判定边界

当前可以判定“功能正确性门禁通过、1000 用户合成规模可用”，不能判定“真实持续生产流量已完全认证”。现有约 20.55 jobs/s 是空 LLM 结果下的 SQLite 提交吞吐，不是端到端提取能力。
